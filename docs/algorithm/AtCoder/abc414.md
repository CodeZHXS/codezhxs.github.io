## [A - Streamer Takahashi](https://atcoder.jp/contests/abc414/tasks/abc414_a)

???+ Abstract "题目大意"

有一场 $L$ 时到 $R$ 时的直播。

有 $N$ 名观众，第 $i$ 名观众会在 $X_i$ 时到 $Y_i$ 时观看直播。

问: 有多少观众能够从头到尾完整观看直播？

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>

        using namespace std;

        int main()
        {
            int n, l, r;
            cin >> n >> l >> r;
            int ans = 0;
            while(n--)
            {
                int x, y;
                cin >> x >> y;
                ans += x <= l && y >= r;
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [B - String Too Long](https://atcoder.jp/contests/abc414/tasks/abc414_b)

???+ Abstract "题目大意"

你有一个空字符串 $S$。

有 $N(1 \le N \le 100)$ 个操作，每次操作有两个参数 $c_i$ 和 $l_i(1 \le l_i \le 10^{18})$，表示在 $S$ 的末尾添加 $l_i$ 个字符 $c_i$。

如果操作完成后字符串 $S$ 的长度不超过 $100$，输出 $S$；否则输出 `Too Long`。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <string>
        #include <vector>

        using namespace std;
        using LL = long long;

        int main()
        {
            int n;
            string s;
            cin >> n;
            vector<char> c(n);
            vector<LL> l(n);
            for (int i = 0; i < n; i++)
                cin >> c[i] >> l[i];
            for (int i = 0; i < n; i++)
            {
                if (l[i] > 100)
                {
                    cout << "Too Long" << endl;
                    return 0;
                }
                s += string(l[i], c[i]);
                if (s.size() > 100)
                {
                    cout << "Too Long" << endl;
                    return 0;
                }
            }
            cout << s << endl;
            return 0;
        }
        ```

## [C - Palindromic in Both Bases](https://atcoder.jp/contests/abc414/tasks/abc414_c)

???+ Abstract "题目大意"

$414$ 的十进制表示为 `414`，这是一个回文数。同时，$414$ 的八进制表示为 `636`，这也是一个回文数。基于此，回答以下问题。

给你两个正整数 $A(2 \le A \le 9)$ 和 $N(1 \le N \le 10^{12})$。请计算在 $1$ 到 $N$ 之间（包含 $1$ 和 $N$）的所有整数中，哪些数在十进制表示和 $A$ 进制表示下都是回文数，并求这些数的总和。

在本题的限制条件下，可以证明答案小于 $2^{63}$。

??? Note "解题思路"

直接枚举回文数的半边就好。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <cstdlib>
        #include <iostream>
        #include <string>

        using namespace std;
        using LL = long long;

        int main()
        {
            int a;
            LL n;
            cin >> a >> n;

            auto f = [](LL x, bool is_odd) -> LL
            {
                string s = to_string(x);
                string t = s;
                if (is_odd)
                    t.pop_back();
                reverse(t.begin(), t.end());
                s += t;
                return atoll(s.c_str());
            };

            auto check = [a](LL x) -> bool
            {
                string s;
                while (x)
                {
                    int t = x % a;
                    s += t + '0';
                    x /= a;
                }

                for (int i = 0, j = s.size() - 1; i <= j; i++, j--)
                    if (s[i] != s[j])
                        return false;
                return true;
            };

            LL sum = 0;
            for (LL x = 1;; x++)
            {
                LL y = f(x, true);
                if (y > n)
                    break;
                if (check(y))
                    sum += y;

                LL z = f(x, false);
                if (z <= n && check(z))
                    sum += z;
            }
            cout << sum << endl;
            return 0;
        }
        ```

## [D - Transmission Mission](https://atcoder.jp/contests/abc414/tasks/abc414_d)

???+ Abstract "题目大意"

在数轴上有 $N(1 \le N \le 5 \times 10^{5})$ 栋房子，第 i 栋房子位于坐标 $X_i$。可能有多栋房子位于同一坐标。

你需要在数轴上的任意实数坐标处放置 $M(1 \le M \le N)$ 个基站，并为每个基站设置一个非负整数的电波强度。

对于某个基站，如果其电波强度为 $x$，则该基站能覆盖的房子为与其距离不超过 $\frac{x}{2}$ 的房子。特别地，当 $x=0$ 时，该基站只能覆盖与其在同一坐标的房子。

请你选择基站的位置和电波强度，使得每一栋房子都至少被一个基站覆盖，并且所有基站的电波强度之和最小。输出这个最小的电波强度总和。

可以证明，对于任意满足条件的输入，答案都是整数。

??? Note "解题思路"

首先对 $X_i$ 排序。然后显然可以发现，所有的基站位置的位置要么是整数，要么是 $k + 0.5$ 这种形式。因为任意一个基站为了不浪费电波强度，覆盖的一定是某两个房子的中间位置。

下面考虑最优解如何构造。首先如果只能造一个基站，最优解一定是把基站放在 $X_1$ 和 $X_N$ 的中点，此时答案是 $X_N - X_1$。

如果有两个基站，不妨设第一个基站覆盖 $X_1$ 到 $X_k$，第二个基站覆盖 $X_{k+1}$ 到 $X_N$。那么第一个基站的电波强度是 $X_k - X_1$，第二个基站的电波强度是 $X_N - X_{k+1}$。因此总的电波强度是 $(X_k - X_1) + (X_N - X_{k+1}) = (X_N - X_1) - (X_{k+1} - X_k)$。可以发现，答案等于只有一个基站时的答案减去一个差值。

显然这里 $X_N$ 和 $X_1$ 是定值，然后减去一个最大的差值即可。所以对于 $M$ 个基站的情况，就是 $X_N - X_1$，然后减去 $M - 1$ 个最大的差值即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <iostream>
        #include <queue>
        #include <vector>

        using namespace std;
        using LL = long long;

        int main()
        {
            int n, m;
            cin >> n >> m;
            vector<LL> x(n);
            for (auto &xi : x)
            {
                cin >> xi;
                xi *= 2;
            }
            sort(x.begin(), x.end());
            x.erase(unique(x.begin(), x.end()), x.end());
            n = x.size();
            if(m >= n)
            {
                cout << 0 << endl;
                return 0;
            }

            LL ans = x[n - 1] - x[0];
            priority_queue<LL> heap;
            for(int i = 0; i + 1 < n; i++)
            {
                heap.push(x[i] - x[i + 1]);
                if((int)heap.size() > m - 1)
                    heap.pop();
            }
            while(!heap.empty())
            {
                ans += heap.top();
                heap.pop();
            }

            ans /= 2;
            cout << ans << endl;
            return 0;
        }
        ```

## [E - Count A%B=C](https://atcoder.jp/contests/abc414/tasks/abc414_e)

???+ Abstract "题目大意"

给你一个正整数 $N(3 \le N \le 10^{12})$， 计算满足以下条件的整数三元组 $(a,b,c)$ 的个数，结果对 $998244353$ 取模。

- $1 \le a, b, c \le N$。
- $a$，$b$ 和 $c$ 互不相同。
- $a$ 除以 $b$ 的余数等于 $c$。

??? Note "解题思路"

根据性质三可以推出 $1 \le c < b < a \le N$。

不妨先考虑有多少对数字满足 $1 \le b \le a \le N$，这其实很简单，只需要枚举 $b$ 即可，先假设 $b$ 枚举的 $i$ 范围是 $[1, N]$，那么对于一个 $i$，$a$ 一共有 $N - i + 1$ 种选法。

一旦确定了 $a$ 和 $b$，$c$ 就唯一确定了，但这里需要减去 $c = 0$ 的情况，也就是 $a$ 不能是 $b$ 的倍数。所以对于一个 $i$，不能选择 $i, 2i, 3i, \ldots$。

于是可以得到求和公式：

$$
\sum_{i=1}^{N} (N - i + 1 - \lfloor \frac{N}{i} \rfloor)
$$

上式给 $b$ 定的上下界是 $[1, N]$，但是代入 $i = 1$ 时上式为 $0$，带入 $i = N$ 上式也为 $0$。所以是不影响结果的，只是为了方便计算。

把这个式子拆成两部分：

$$
\sum_{i=1}^{N} (N - i + 1) - \sum_{i=1}^{N} \lfloor \frac{N}{i} \rfloor
$$

前半段是一个等差数列求和，求解，相当于：

$$
\frac{N(N+1)}{2} - \sum_{i=1}^{N} \lfloor \frac{N}{i} \rfloor
$$

后半段这里如果直接枚举是 $O(N)$ 复杂度，会超时。有两种求法：显然这是数列分块，不懂的看看 [数论分块](https://oi-wiki.org/math/number-theory/sqrt-decomposition/)。

另一种做法是平方根分解，不难发现，$\sum_{i=1}^{N} \lfloor \frac{N}{i} \rfloor$ 其实是在求所有满足 $i \times j \le N$ 的数对 $(i, j)$ 的数量。这是因为对于任意一个 $i$，$j$ 可以取 $1, 2, ... \lfloor \frac{N}{i} \rfloor$，一共有 $\lfloor \frac{N}{i} \rfloor$ 个。

设 $S = \lfloor \sqrt{N} \rfloor$，然后我们考虑 $i \times j \le N$，考虑三种情况：
- $P_1$：满足 $i \le S$ 且 $i \times j \le N$ 的 $(i, j)$ 对的数量。
- $P_2$：满足 $j \le S$ 且 $i \times j \le N$ 的 $(i, j)$ 对的数量。
- $P_3$：满足 $i \le S$ 且 $j \le S$ 且 $i \times j \le N$ 的 $(i, j)$ 对的数量。

由于对称性，$P_1 = P_2$。所以最终的答案就是 $P_1 + P_2 - P_3 = 2P_1 - P_3$

而 $P_3$ 可以轻松求出，就是 $S \times S$。$P_1$ 可以在 $O(S)$ 的时间内求出。

下面分别给出两种做法的代码。显然平方根分解的代码更简洁一些。

??? Success "参考代码"

    === "平方根分解"
    
        ```c++
        #include "atcoder/modint.hpp"
        #include <cmath>
        #include <iostream>

        using namespace std;
        using LL = long long;
        using mint = atcoder::modint998244353;

        int main()
        {
            LL n;
            cin >> n;
            mint ans = 0;
            LL s = sqrt(n);
            for(int i = 1; i <= s; i++)
                ans += n / i * 2;
            ans -= s * s;
            cout << ans.val();
            return 0;
        }
        ```
    === "数论分块"

        ```c++
        #include "atcoder/modint.hpp"
        #include <cmath>
        #include <iostream>

        using namespace std;
        using LL = long long;
        using mint = atcoder::modint998244353;

        int main()
        {
            LL n;
            cin >> n;
            mint ans = mint(n) * (n + 1) / 2;
            for (LL l = 1; l <= n;)
            {
                LL d = n / l;
                LL r = n / d;
                ans -= d * (r - l + 1);
                l = r + 1;
            }
            cout << ans.val();
            return 0;
        }
        ```
