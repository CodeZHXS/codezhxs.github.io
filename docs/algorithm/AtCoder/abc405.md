## [B - Not All](https://atcoder.jp/contests/abc405/tasks/abc405_b)

???+ Abstract "题目大意"

给你一个数列 $A = (A_1, A_2, \ldots, A_N)$ 和一个正整数 $M$。其中 $1 \le M \le N \le 100$

你可以执行若干次操作：删除 $A$ 的最后一个元素。求最少执行多少次操作，使得 $A$ 满足如下条件：

- 存在一个整数 $i \in [1,M]$，满足 $i$ 未在 $A$ 中出现。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <iostream>
        #include <vector>

        using namespace std;

        int main()
        {
            int n, m;
            cin >> n >> m;
            vector<int> a(n), cnt(m + 1);
            for (auto &x : a)
            {
                cin >> x;
                cnt[x]++;
            }
            bool quit = false;
            for (int i = 1; i <= m; i++)
                if (cnt[i] == 0)
                {
                    quit = true;
                    break;
                }
            if (quit)
            {
                cout << 0 << endl;
                return 0;
            }
            reverse(a.begin(), a.end());
            for (int i = 0; i < n; i++)
            {
                int x = a[i];
                if (--cnt[x] == 0)
                {
                    cout << i + 1 << endl;
                    return 0;
                }
            }
            return 0;
        }
        ```

## [C - Sum of Product](https://atcoder.jp/contests/abc405/tasks/abc405_c)

???+ Abstract "题目大意"

给你一个长度为 $N$ 的数列 $A = (A_1, A_2, \ldots, A_N)$。计算出 $\sum\limits_{1 \le i < j \le N} A_iA_j$

??? Note "解题思路"

相当于 $\sum\limits_{j = 1}^N\sum\limits_{i = 1}^{j-1} A_iA_j = \sum\limits_{j = 1}^N S[j-1]$，其中 $S[j]$ 表示前缀和。所以维护前缀和就好。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <vector>

        using namespace std;
        using LL = long long;

        int main()
        {
            int n;
            cin >> n;
            vector<LL> s(n + 1);
            for (int i = 1; i <= n; i++)
            {
                cin >> s[i];
                s[i] += s[i - 1];
            }
            LL ans = 0;
            for (int j = 1; j <= n; j++)
            {
                LL aj = s[j] - s[j - 1];
                LL prefix = s[j - 1];
                ans += aj * prefix;
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [D - Escape Route](https://atcoder.jp/contests/abc405/tasks/abc405_d)

???+ Abstract "题目大意"

给你一个 $H \times W$(2 \le H, W \le 1000) 列的网格，其中 `.` 表示空白地面，`#` 表示不可穿过的墙，`E` 表示安全出口。

在一个空白格子，可以用一步移动到（上下左右）相邻的非墙格子。

令从一个空白格子 $(i,j)$ 移动到任意一个安全出口需要的最小步数为 $d(i,j)$。
你需要在所有空白的格子上画上箭头（指向上下左右中的一个），使得从每一个空白格子 $(i,j)$ 开始，每次向当前所在格子的箭头方向走一步，恰好 $d(i,j)$ 步后将到达安全出口。

??? Note "解题思路"

从所有的安全出口开始 bfs 就好。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <queue>
        #include <string>
        #include <tuple>
        #include <utility>
        #include <vector>

        using namespace std;

        int main()
        {
            int h, w;
            cin >> h >> w;
            vector<string> g(h);
            const tuple<int, int, char> dir[] = {{-1, 0, 'v'}, {1, 0, '^'}, {0, -1, '>'}, {0, 1, '<'}};
            queue<pair<int, int>> q;
            for (auto &s : g)
                cin >> s;
            vector<vector<bool>> vis(h, vector<bool>(w));
            for (int r = 0; r < h; r++)
                for (int c = 0; c < w; c++)
                {
                    if (g[r][c] == 'E')
                    {
                        q.push({r, c});
                        vis[r][c] = true;
                    }
                }

            auto in_lim = [h, w](int r, int c) -> bool
            { return r >= 0 && r < h && c >= 0 && c < w; };

            while (!q.empty())
            {
                auto [r, c] = q.front();
                q.pop();
                for (auto [dr, dc, d] : dir)
                {
                    int nr = r + dr, nc = c + dc;
                    if (in_lim(nr, nc) && !vis[nr][nc] && g[nr][nc] != '#')
                    {
                        vis[nr][nc] = true;
                        q.push({nr, nc});
                        g[nr][nc] = d;
                    }
                }
            }
            for (auto &s : g)
                cout << s << endl;
            return 0;
        }
        ```

## [E - Fruit Lineup](https://atcoder.jp/contests/abc405/tasks/abc405_e)

???+ Abstract "题目大意"

你有 $A$ 个苹果，$B$ 个橙子，$C$ 串香蕉，$D$ 串葡萄。其中 $1 \le A, B, C, D \le 10^6$ 同种水果之间是完全相同的。

求把它们从左往右排成一排的方案数，方案需要满足：

- 所有的苹果都在所有的香蕉的左边；
- 所有的苹果都在所有的葡萄的左边；
- 所有的橙子都在所有的葡萄的左边。

答案对 998244353 取模。

??? Note "解题思路"

下面用字符 `A`、`B`、`C`、`D` 分别指代苹果、橙子、香蕉、葡萄，则约束等价于：
- 所有的 `A` 都在所有的 `C`的左边；
- 所有的 `A` 都在所有的 `D`的左边；
- 所有的 `B` 都在所有的 `D`的左边。

显然得枚举某个字符的起点。发现如果枚举 `D` 的起点的话，`D` 的左侧一定会有 $A$ 个 `A` 和 `B` 个 $B$，剩下的位置就都是 `C` 了。假设下标从 $0$ 开始，当前枚举的位置是 $i$。
- 考虑左侧，至少要有 $i \ge A + B$，因为至少要留下 $A + B$ 个位置给 `A` 和 `B`，还留有 $i - A - B$ 个位置给 `C`，进一步可以发现，如果 `B` 的位置确定了，则 $A$ 和 $C$ 的位置也会确定（因为所有的 $A$ 都在 $C$ 的左边）。而 $B$ 的位置一共有 $C_{i}^B$ 选法。
- 考虑右侧，令 $N = A + B + C + D$，则右侧还剩下 $N - i - 1$ 个位置，显然要有 $N - i - 1 \ge D - 1$，因为要保证 $D$ 能在后续全部装下。后续还留有 $D - 1$ 个位置给 `D`，剩下的位置给 `C`，有 $C_{N - i - 1}^{D-1}$ 种选法。

所以直接枚举 `D` 的起点就好，组合数提前处理出阶乘即可。参考代码枚举的是第一个 `D` 的左侧有多少个 `C`，是等价的。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include "atcoder/modint.hpp"
        #include <array>
        #include <iostream>

        using namespace std;
        using mint = atcoder::modint998244353;

        const int MAXN = 3E6;
        array<mint, MAXN + 1> fact = {1};

        int main()
        {
            int a, b, c, d;
            cin >> a >> b >> c >> d;
            for (int i = 1; i <= MAXN; i++)
                fact[i] = fact[i - 1] * i;

            auto comb = [](int n, int k) -> mint
            { return fact[n] / fact[k] / fact[n - k]; };

            mint ans = 0;
            for (int i = 0; i <= c; i++)
            {
                mint l = comb(a + b + i, b);
                mint r = comb(c - i + d - 1, d - 1);
                ans += l * r;
            }
            cout << ans.val() << endl;
            return 0;
        }
        ```

## [F - Chord Crossing](https://atcoder.jp/contests/abc405/tasks/abc405_f)

???+ Abstract "题目大意"

在一个圆上等距分布着 $2N(2 \le N \le 10 \times 10 ^ 6)$ 个点，顺时针编号为 $1,2,⋯,2N$。$2N$ 在顺时针方向的下一个点是 $1$。

圆上存在 $M(1 \le M \le \min(\lfloor\frac{N}{2}\rfloor, 2\times10^5)$ 条线段，第 $i$ 条线段的两个端点分别为 $A_i$ 和 $B_i$ ，并且这两个端点的编号是偶数。保证不会有两条线段共享一个端点。

接下来你要回答 $Q(1 \le Q \le 2 \times 10 ^ 5)$ 个询问，每次询问给出两个奇数 $C_j$ 和 $D_j$，你需要回答如果圆上新增了一条线段，两个端点分别是 $C_j,D_j$ ，那么这条新线段会和原有的 $M$ 条线段中的多少条相交。


??? Note "解题思路"

假设线段 1 是 $(a, b)$，线段 2 是 $(c, d)$，那么这两条线段相交的条件是：

- $1 \le a \le c \le b \le d \le 2N$ 或 $1 \le c \le a \le d \le b \le 2N$

这其实是二维数点，想象一下原有的线段 $(a, b)$ 是二维平面上的一个点，对于相交条件（前者），可以拆成：

$$
\left\{\begin{matrix}
1 \le a \le c \\
c \le b \le d
\end{matrix}\right.
$$

于是线段 $(c, d)$ 相当于一个左下角为 $(1, c)$，右上角为 $(c, d)$ 的矩形，答案就是矩形中有多少个点。

这其实就是扫描线的思路，把所有的横坐标离散化，然后点和边的纵坐标排序就可以了。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <iostream>
        #include <vector>

        using namespace std;

        struct Point
        {
            int x, y, op = 0, id = 0;
            bool operator<(const Point &other) const { return y < other.y || (y == other.y && op < other.op); }
        };

        template <typename T>
        class FenwickTree
        {
        public:
            FenwickTree(int n) : n(n), t(n) {}

            void add(int x, T k)
            {
                for (; x < n; x += lowbit(x))
                    t[x] += k;
            }

            T range(int l, int r) const { return prefix(r) - prefix(l - 1); }

        private:
            int n;
            vector<T> t;

            int lowbit(int x) const { return x & -x; }

            T prefix(int x) const
            {
                T ans = 0;
                for (; x; x -= lowbit(x))
                    ans += t[x];
                return ans;
            }
        };

        int main()
        {
            int n, m;
            cin >> n >> m;
            vector<int> xs;
            vector<Point> p;
            for (int i = 0; i < m; i++)
            {
                int x, y;
                cin >> x >> y;
                xs.push_back(x);
                p.push_back({x, y});
            }

            auto add_rec = [&xs, &p](int x1, int x2, int y1, int y2, int id) -> void
            {
                xs.push_back(x1 - 1);
                xs.push_back(x2);
                p.push_back({x1 - 1, y1 - 1, 1, id});
                p.push_back({x2, y2, 1, id});
                p.push_back({x1 - 1, y2, 2, id});
                p.push_back({x2, y1 - 1, 2, id});
            };

            int q;
            cin >> q;
            for (int i = 0; i < q; i++)
            {
                int c, d;
                cin >> c >> d;
                add_rec(1, c, c, d, i);
                add_rec(c, d, d, 2 * n, i);
            }

            sort(xs.begin(), xs.end());
            xs.erase(unique(xs.begin(), xs.end()), xs.end());
            for (auto &pp : p)
                pp.x = lower_bound(xs.begin(), xs.end(), pp.x) - xs.begin() + 1;

            sort(p.begin(), p.end());
            int len = xs.size();
            FenwickTree<int> t(len + 1);
            vector<int> ans(q);
            for (auto [x, _, op, id] : p)
            {
                if (op == 0)
                    t.add(x, 1);
                else if (op == 1)
                    ans[id] += t.range(1, x);
                else
                    ans[id] -= t.range(1, x);
            }
            for (auto x : ans)
                cout << x << '\n';
            return 0;
        }
        ```

## [G - Range Shuffle Query](https://atcoder.jp/contests/abc405/tasks/abc405_g)

???+ Abstract "题目大意"

给你一个长为 $N(1 \le N \le 2.5 \times 10 ^ 5)$ 的数列 $A=(A_1, A_2, ..., A_N)$，回答 $Q(1 \le Q \le 2.5 \times 10 ^ 5)$ 个询问。

每个询问有三个参数 $(L_i, R_i, X_i)$，你需要回答：

令 $B = (A_{L_i}, A_{L_i + 1}, \ldots, A_{R_i})$，删除 $B$ 中大于等于  $X_i$ 的所有元素后，通过重新排列 $B$ 的元素可以形成多少种不同的 $B$？

答案对 $998244353$ 取模。

??? Note "解题思路"

考虑如何回答某个询问 $(L_i, R_i, X_i)$，设 $k = R_i - L_i + 1$，如果能维护 $B_i$ 中所有小于 $X_i$ 的数字出现的次数，记为 $v_1, v_2, ... v_m$，则答案就是 $\frac{k!}{v_1! v_2! \cdots v_m!}$

换言之，我们需要维护一段区间每个数字出现的次数，观察数据范围，开根号是能过的，于是可以想到莫队。

但使用莫队需要注意，需要保证区间的转移是 $O(1)$ 的，而如果我们维护线段树，转移的时间复杂度就是 $O(\log n)$ 的，这样不行。

于是可以使用根号分块维护次数，这样可以在 $O(1)$ 时间转移。回答询问需要花费 $\sqrt{n}$ 的时间，但一共只有 $Q$ 个询问，所以整体复杂度是 $O((n + q) \sqrt{n})$。

这里还需要注意提前把每个阶乘的逆元处理出来，避免在转移的时候求逆元。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include "atcoder/modint.hpp"
        #include <algorithm>
        #include <cmath>
        #include <iostream>
        #include <vector>

        using namespace std;
        using LL = long long;
        using mint = atcoder::modint998244353;

        const LL MOD = 998244353;

        struct Query
        {
            int l, r, x, b, id;
            bool operator<(const Query &other) const { return b != other.b ? b < other.b : (r == other.r ? false : ((b & 1) ^ (r < other.r))); }
        };

        int main()
        {
            ios::sync_with_stdio(false);
            cin.tie(nullptr);
            int n, q;
            cin >> n >> q;
            int len = sqrt(n + 1);

            vector<mint> fact(n + 1), inv(n + 1);
            fact[0] = fact[1] = 1;
            inv[1] = 1;
            for (int i = 2; i <= n; i++)
            {
                fact[i] = fact[i - 1] * i;
                inv[i] = (MOD - MOD / i) * inv[MOD % i];
            }

            vector<int> a(n + 1);
            for (int i = 1; i <= n; i++)
                cin >> a[i];

            vector<Query> query(q);
            for (int i = 0; i < q; i++)
            {
                auto &[l, r, x, b, id] = query[i];
                cin >> l >> r >> x;
                b = l / len;
                id = i;
            }
            sort(query.begin(), query.end());

            vector<int> cnt(n + 1), bs(len + 1);
            vector<mint> bp(len + 1, 1);

            auto add = [&a, &cnt, &bs, &bp, len](int i) -> void
            {
                int x = a[i];
                int b = x / len;
                bs[b]++;
                cnt[x]++;
                bp[b] *= cnt[x];
            };

            auto del = [&a, &cnt, &bs, &bp, &inv, len](int i) -> void
            {
                int x = a[i];
                int b = x / len;
                bs[b]--;
                bp[b] *= inv[cnt[x]];
                cnt[x]--;
            };

            vector<int> ans(q);
            int l = 1, r = 0;
            for (auto [ql, qr, qx, _, qid] : query)
            {
                while (l > ql)
                    add(--l);
                while (r < qr)
                    add(++r);
                while (l < ql)
                    del(l++);
                while (r > qr)
                    del(r--);

                int s = 0;
                mint down = 1;
                int b = qx / len;
                for (int i = 0; i < b; i++)
                {
                    s += bs[i];
                    down *= bp[i];
                }
                for (int i = b * len; i < qx; i++)
                {
                    s += cnt[i];
                    down *= fact[cnt[i]];
                }
                mint up = fact[s];
                ans[qid] = (up / down).val();
            }
            for (auto x : ans)
                cout << x << '\n';
            return 0;
        }
        ```
