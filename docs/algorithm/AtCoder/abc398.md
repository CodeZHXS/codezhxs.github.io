## [A - Doors in the Center](https://atcoder.jp/contests/abc398/tasks/abc398_a)

???+ Abstract "题目大意"

给你一个整数 $N$，输出一个长度为 $N$ 且满足以下所有条件的字符串：
1. 字符串只包含字符 `-` 和 `=`。
2. 字符串是一个回文串。
3. 字符串恰好只包含 $1$ 个或者 $2$ 个 `=`，如果有两个 `=`，则这两个 `=` 必须相邻。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <string>

        using namespace std;

        int main()
        {
            int n;
            cin >> n;
            if (n % 2 == 0)
                cout << string(n/2-1, '-') << "==" << string(n/2-1, '-');
            else
                cout << string(n/2, '-') << "=" << string(n/2, '-');
            return 0;
        }
        ```

## [B - Full House 3](https://atcoder.jp/contests/abc398/tasks/abc398_b)

???+ Abstract "题目大意"

给你 $7$ 个数字，代表 $7$ 张牌。问：这 $7$ 张牌中能否选出 $5$ 张牌，满足以下条件：
- 这 $5$ 张牌只有两种数字，且其中一种数字的数量为 $3$，另一种数字的数量为 $2$。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <unordered_map>

        using namespace std;

        int main()
        {
            unordered_map<int, int> cnt;
            for(int i = 0; i < 7; i++)
            {
                int x;
                cin >> x;
                cnt[x]++;
            }
            bool two = false;
            bool three = false;
            for(auto [_, v] : cnt)
                if(v >= 3)
                {
                    if(!three)
                        three = true;
                    else
                        two = true;
                }
                else if(v == 2)
                    two = true;
            if(two && three)
                cout << "Yes" << endl;
            else
                cout << "No" << endl;
            return 0;
        }
        ```

## [C - Uniqueness](https://atcoder.jp/contests/abc398/tasks/abc398_c)

???+ Abstract "题目大意"

有 $N$ 个人，编号为 $1$ 至 $N$。第 $i$ 个人持有数值 $A_i$。

请找出满足以下条件的个体中持有数值最大的那个人的编号：

- 在除自己之外的 $N−1$ 人中，不存在持有相同数值的人。

如果不存在满足条件的人，则输出 `-1`。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <unordered_map>
        #include <vector>

        using namespace std;

        int main()
        {
            int n;
            cin >> n;
            unordered_map<int, int> cnt;
            vector<int> a(n);
            for (auto &x : a)
            {
                cin >> x;
                cnt[x]++;
            }
            int ma = -1, idx = -1;
            for (int i = 0; i < n; i++)
            {
                int x = a[i];
                if (cnt[x] == 1)
                {
                    if (x > ma)
                    {
                        ma = x;
                        idx = i + 1;
                    }
                }
            }
            cout << idx << endl;
            return 0;
        }
        ```

## [D - Bonfire](https://atcoder.jp/contests/abc398/tasks/abc398_d)

???+ Abstract "题目大意"

有一个无限大的二维网格， 在 $(0, 0)$ 位置还有一个篝火。在 $t = 0$ 时刻，篝火产生了一个烟雾，烟雾的位置同样在 $(0, 0)$。

给你一个长度为 $N$ 的字符串 `S`，其中每个字符是 `N`， `S`， `W`，`E`，在 $t = 1, 2, \ldots, N$ 时刻，根据 $S$ 的第 $t$ 个字符（用 $S_t$ 表示），会发生以下事件：
- 风吹来，所有的烟雾开始移动
  - 如果 $S_t$ 是 `N`，表示所有的烟雾向上移动一格。
  - 如果 $S_t$ 是 `S`，表示所有的烟雾向下移动一格。
  - 如果 $S_t$ 是 `W`，表示所有的烟雾向左移动一格。
  - 如果 $S_t$ 是 `E`，表示所有的烟雾向右移动一格。
- 然后，如果篝火所在的 $(0, 0)$ 位置没有烟雾，$(0, 0)$ 位置会产生一个新的烟雾。

你的位置是 $(R, C)$，对于每个整数 $1 \le t \le N$，你需要回答在 $t + 0.5$ 时刻，$(R, C)$ 位置是否有烟雾。

??? Note "解题思路"

显然，维护所有烟雾的位置变化是不行的。但是可以只记录烟雾产生的位置，然后只维护全体烟雾坐标的变化量 $dr$ 和 $dc$，相当于所有烟雾都移动了 $dr$ 和 $dc$。这样每次新增的烟雾实际就是 $(-dr, -dc)$。把烟雾坐标加入到 `set` 中，每次查找是否有 $(R - dr, C - dc)$ 即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <set>
        #include <utility>

        using namespace std;

        int main()
        {
            int n, r, c;
            cin >> n >> r >> c;
            int dr = 0, dc = 0;
            string dir;
            cin >> dir;
            set<pair<int, int>> s;
            s.insert({0, 0});
            for (auto ch : dir)
            {
                if (ch == 'N')
                    dr--;
                else if (ch == 'S')
                    dr++;
                else if (ch == 'W')
                    dc--;
                else
                    dc++;
                s.insert({-dr, -dc});
                cout << (s.contains({r - dr, c - dc}) ? "1" : "0");
            }
            return 0;
        }
        ```

## [E - Tree Game](https://atcoder.jp/contests/abc398/tasks/abc398_e)

???+ Abstract "题目大意"

这是一道交互题。

给你一颗 $N(1 \le N \le 100)$ 个点的树。你和 Alice 玩游戏，你可以决定游戏的先后手。然后，每个人轮流执行以下操作：
- 选择一对数字 $(i, j)$， 其中 $1 \le i < j \le N$，且 $(i, j)$ 需要满足以下条件，然后，连接一条 $i$ 到 $j$ 的边。
  - $(i, j)$ 不能是已经存在的边。
  - 在添加边之后，图中不能存在奇环（点的个数为奇数的环）。

如果轮到玩家行动时，无法选择一对数字 $(i, j)$，则该玩家输掉游戏。你可以决定游戏的先后手，你需要战胜 Alice。

??? Note "解题思路"

结论题。图中没有奇环等价于图是二分图。因为 $1 \le N \le 100$，每次能选的点一开始就已经固定了（即选择的边一定是二分图的左右部的连边，除去初始已经有的边），预处理出来之后就可以直接模拟。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <set>
        #include <utility>
        #include <vector>

        using namespace std;

        int main()
        {
            int n;
            cin >> n;
            vector<vector<int>> edge(n + 1);
            for (int i = 1; i < n; i++)
            {
                int u, v;
                cin >> u >> v;
                edge[u].push_back(v);
                edge[v].push_back(u);
            }
            vector<int> p[2];

            auto dfs = [&edge, &p](auto &self, int u, int fa, int i) -> void
            {
                p[i].push_back(u);
                for (auto v : edge[u])
                {
                    if (v == fa)
                        continue;
                    self(self, v, u, i ^ 1);
                }
            };

            dfs(dfs, 1, 0, 0);

            set<pair<int, int>> all_edge;
            for (auto u : p[0])
            {
                for (auto v : p[1])
                    u < v ? all_edge.insert({u, v}) : all_edge.insert({v, u});
                for (auto v : edge[u])
                    u < v ? all_edge.erase({u, v}) : all_edge.erase({v, u});
            }

            auto choose = [&all_edge]()
            {
                auto it = all_edge.begin();
                auto [u, v] = *it;
                cout << u << ' ' << v << endl;
                all_edge.erase(it);
            };

            if (all_edge.size() % 2 == 0)
                cout << "Second" << endl;
            else
            {
                cout << "First" << endl;
                choose();
            }

            int u, v;
            while (!all_edge.empty())
            {
                cin >> u >> v;
                all_edge.erase({u, v});
                choose();
            }

            cin >> u >> v;
            return 0;
        }
        ```

## [F - ABCBA](https://atcoder.jp/contests/abc398/tasks/abc398_f)

???+ Abstract "题目大意"

给你一个字符串 $S(1 \le |S| \le 500000)$，找到一个最短的字符串 $T$，满足：
- $T$ 是一个回文串。
- $S$ 是 $T$ 的前缀。

??? Note "解题思路"

为了让 $T$ 尽可能短，只需要找到 $S$ 的最长回文后缀。直接 manacher 算法即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <iostream>
        #include <string>
        #include <vector>

        using namespace std;

        string manacher(const string &s, char ch)
        {
            int n = s.size();
            int m = 2 * n + 1;
            string t(m, ch);
            for (int i = 0, j = 1; i < n; i++, j += 2)
                t[j] = s[i];
            vector<int> d(m);
            int prefix = m;
            for(int i = 0, l = 0, r = -1; i < m; i++)
            {
                int k = i > r ? 1 : min(d[l+r-i], r-i+1);
                while(i-k >= 0 && i + k < m && t[i-k] == t[i+k])
                    k++;
                d[i] = k;
                if(i + d[i] == m)
                    prefix = min(prefix, i-d[i]+1);
                if(i + k - 1 > r)
                {
                    r = i + k - 1;
                    l = i - k + 1;
                }
            }
            string left = t.substr(0, prefix);
            string right = left;
            reverse(right.begin(), right.end());
            string ans = left + t.substr(prefix, m - prefix) + right;
            int len = 0;
            for(int j = 1; j < (int)ans.size(); j += 2)
                ans[len++] = ans[j];
            ans.resize(len);
            return ans;
        }

        int main()
        {
            string s;
            cin >> s;
            cout << manacher(s, '#');
            return 0;
        }
        ```
