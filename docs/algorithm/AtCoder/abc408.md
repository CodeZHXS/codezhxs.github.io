## [A - Timeout ](https://atcoder.jp/contests/abc408/tasks/abc408_a)

???+ Abstract "题目大意"

有一个长老将要睡着。如果 $S+0.5$ 或更久的时间中没有人拍他的肩膀，他将会睡着。

时刻 $0$，长老是醒着的，并且侍从拍了他的肩膀。

接下来侍从将拍长老的肩膀 $N$ 次，第 $i$ 次在时刻 $T_i$。求时刻 $T_N$ 时长老是否还醒着。

注：如果长老已经睡着了，则拍肩膀也无法将他唤醒。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <vector>

        using namespace std;

        int main()
        {
            int n, s;
            cin >> n >> s;
            vector<int> t(n + 1);
            bool ok = true;
            for (int i = 1; i <= n; i++)
            {
                cin >> t[i];
                if (t[i] - t[i - 1] > s)
                    ok = false;
            }
            cout << (ok ? "Yes" : "No") << endl;
            return 0;
        }   
        ```

## [B - Compression](https://atcoder.jp/contests/abc408/tasks/abc408_b)

???+ Abstract "题目大意"

给你一个序列 $A=(A_1, A_2, \ldots, A_N)$。将 $A$ 排序并去掉大小相同的元素。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <iostream>
        #include <vector>

        using namespace std;

        int main()
        {
            int n;
            cin >> n;
            vector<int> a(n);
            for (auto &x : a)
                cin >> x;
            sort(a.begin(), a.end());
            a.erase(unique(a.begin(), a.end()), a.end());

            for (auto x : a)
                cout << x << ' ';
            return 0;
        }
        ```

## [C - Not All Covered](https://atcoder.jp/contests/abc408/tasks/abc408_c)

???+ Abstract "题目大意"

有 $N(1 \le N \le 10 ^ 6)$ 堵城墙和 $M(1 \le M \le 2 \times 10 ^ 5)$ 个炮塔。第 $i$ 个炮塔守卫着第 $L_i$ 到第 $R_i$ 堵城墙。

求至少摧毁多少个炮塔，才能使得至少一堵城墙没有被任何一个炮塔守卫。

??? Note "解题思路"

差分数组即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <limits>
        #include <vector>

        using namespace std;

        int main()
        {
            int n, m;
            cin >> n >> m;
            vector<int> b(n + 2);
            while (m--)
            {
                int l, r;
                cin >> l >> r;
                b[l]++;
                b[r + 1]--;
            }
            int ans = numeric_limits<int>::max();
            for(int i = 1; i <= n; i++)
            {
                b[i] += b[i - 1];
                ans = min(ans, b[i]);
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [D - Flip to Gather](https://atcoder.jp/contests/abc408/tasks/abc408_d)

???+ Abstract "题目大意"

给你一个长度为 $N(1 \le N \le 2 \times 10 ^ 5)$ 的 $01$ 字符串 $S$。

你可以执行以下操作任意次：
- 选择一个位置 $i$，将 $S_i$ 反转。

你的目标是让 $S$ 中的只有一段连续的 $1$，或者让 $S$ 中不存在 $1$。请找出需要的最小的操作次数。

??? Note "解题思路"

首先处理一个前缀和 $s[i]$ 表示 $[1, i]$ 里面 $1$ 的数量。

考虑保留 $[l, r]$ 区间中的所有 $1$ 作为答案，则答案就是 $[1, l-1]$ 和 $[r + 1, n]$ 中 $1$ 的数量，加上 $[l, r]$ 中 $0$ 的数量。也就是：

$$
\begin{align*}
& s[l-1] + s[n] - s[r] + (r - l + 1 - (s[r] - s[l-1])) \\
&= s[l-1] + s[n] - s[r] + r - l + 1 - s[r] + s[l-1] \\
& = s[n] + r - 2 * s[r] - (l - 1 - 2 * s[l - 1])
\end{align*}
$$

这个式子可以枚举 $r$，同时记住 $l - 1 - 2 \times s[l - 1]$ 的最大值即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <iostream>
        #include <string>
        #include <vector>

        using namespace std;

        void solve()
        {
            int n;
            cin >> n;
            string s;
            cin >> s;
            vector<int> pre(n + 1);
            for (int i = 0; i < n; i++)
                pre[i + 1] = pre[i] + s[i] - '0';

            int ans = pre[n], max_val = 0;

            auto cal = [&pre](int i) -> int
            { return i - 2 * pre[i]; };

            for (int r = 1; r <= n; r++)
            {
                max_val = max(max_val, cal(r - 1));
                ans = min(ans, pre[n] + cal(r) - max_val);
            }
            cout << ans << '\n';
        }

        int main()
        {
            int t;
            cin >> t;
            while (t--)
                solve();
            return 0;
        }
        ```

## [E - Minimum OR Path](https://atcoder.jp/contests/abc408/tasks/abc408_e)

???+ Abstract "题目大意"

给你一个 $N(2 \le N \le 2 \times 10^5)$ 个顶点和 $M(N - 1 \le M \le 2 \times 10^{5})$ 条边的无向连通图，图中无自环，每条边有一个边权值 $w_i(0 \le w_i < 2 ^ {30})$。

求出从点 $1$ 到点 $N$ 的所有简单路径中，边权值按位 OR 的最小值。

??? Note "解题思路"

因为 $w_i < 2 ^ {30}$，所以答案一定小于 $2 ^ {30}$。首先考虑最高位 $2 ^ {29}$，把边分为两类：
- $w_i$ 含有 $2 ^ {29}$ 的边。
- $w_i$ 不含有 $2 ^ {29}$ 的边。

首先尝试能否只通过第 2 类的边使得点 $1$ 到 $N$ 连通（并查集即可），如果可以，那么删掉第一类的边。如果不可以，那就说明必须使用第 1 类边才能使得点 $1$ 到 $N$ 连通，所以答案一定包含 $2 ^ {29}$。一直求到最低位就可以。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <array>
        #include <iostream>
        #include <unordered_map>
        #include <utility>
        #include <vector>

        using namespace std;

        const int MAXB = 30;

        class DSU
        {
        public:
            explicit DSU(int n) : parent_or_size(n, -1) {}

            int merge(int a, int b)
            {
                int x = leader(a), y = leader(b);
                if (x == y)
                    return x;
                if (-parent_or_size[x] < -parent_or_size[y])
                    swap(x, y);
                parent_or_size[x] += parent_or_size[y];
                parent_or_size[y] = x;
                return x;
            }

            int leader(int a) { return parent_or_size[a] < 0 ? a : parent_or_size[a] = leader(parent_or_size[a]); }

            bool same(int a, int b) { return leader(a) == leader(b); }

            int size(int a) { return -parent_or_size[leader(a)]; }

        private:
            vector<int> parent_or_size;
        };

        int main()
        {
            int n, m;
            cin >> n >> m;
            unordered_map<int, array<int, 3>> edge(m);
            for (int i = 0; i < m; i++)
            {
                int u, v, w;
                cin >> u >> v >> w;
                edge[i] = {u, v, w};
            }
            int ans = 0;
            for (int i = MAXB - 1; i >= 0; i--)
            {
                DSU dsu(n + 1);
                vector<int> ids;
                for (auto &[id, e] : edge)
                {
                    auto [u, v, w] = e;
                    if (w >> i & 1)
                        ids.push_back(id);
                    else
                        dsu.merge(u, v);
                }
                if (!dsu.same(1, n))
                    ans |= 1 << i;
                else
                {
                    for (auto id : ids)
                        edge.erase(id);
                }
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [F - Athletic](https://atcoder.jp/contests/abc408/tasks/abc408_f)

???+ Abstract "题目大意"

场上有 $N(1 \le N \le 5 \times 10^{5})$ 个脚手架，第 $i$ 个脚手架的高度为 $H_i$，$H_i$ 为 $1$ 到 $N$ 的排列。

你将用这些脚手架玩一个游戏。首先，你可以任意选定一个脚手架作为起点并持续移动到其他脚手架，从第 $i$ 个脚手架可以移动到第 $j$ 个脚手架的条件是：

- 当且仅当 $H_j \le H_i - D$ 且 $|i - j| \le R$。

其中，$1 \le D, R \le N$

问：最多可以移动几次？

??? Note "解题思路"

首先考虑暴力，因为脚手架的高度是 $1$ 到 $N$ 的排列，所以可以从 $H_i$ 最小的脚手架开始考虑。遍历 $i - R \le j \le i + R$ ，如果有 $H_j \le H_i - D$，那么 $H[i] = \max\{H[j]\} + 1$。显然这个算法的时间复杂度是 $O(NR)$，会超时。

像这种区间求最大值，显然可以想到线段树，这样可以解决 $i - R \le j \le i + R$ 遍历的问题，然后考虑如何满足 $H_j \le H_i - D$，显然 $H_i$ 的时候，$H_i - D$ 刚刚激活，所以只需要延迟每一个位置加入线段树的时间，没有加入的位置设置为 $-1$ 即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <bit>
        #include <iostream>
        #include <vector>

        using namespace std;

        template <class S, auto op, auto e>
        class SegTree
        {
        public:
            explicit SegTree(int n) : SegTree(vector<S>(n, e())) {}

            explicit SegTree(const vector<S> &v) : n(v.size())
            {
                size = bit_ceil((unsigned int)n);
                d = vector<S>(2 * size, e());
                for (int i = 0; i < n; i++)
                    d[size + i] = v[i];
                for (int i = size - 1; i >= 1; i--)
                    push_up(i);
            }

            void set(int p, S x)
            {
                p += size;
                d[p] = x;
                for (p >>= 1; p; p >>= 1)
                    push_up(p);
            }

            S get(int p) const { return d[p + size]; }

            S prod(int l, int r) const
            {
                S ansl = e(), ansr = e();
                for (l += size, r += size; l < r; l >>= 1, r >>= 1)
                {
                    if (l & 1)
                        ansl = op(ansl, d[l++]);
                    if (r & 1)
                        ansr = op(d[--r], ansr);
                }
                return op(ansl, ansr);
            }

            S all_prod() const { return d[1]; }

        private:
            int n, size;
            vector<S> d;

            void push_up(int k) { d[k] = op(d[2 * k], d[2 * k + 1]); }
        };

        using S = int;

        S op(S x, S y) { return max(x, y); }

        S e() { return -1; }

        int main()
        {
            int n, d, r;
            cin >> n >> d >> r;
            vector<int> pos(n + 1);
            for (int i = 0; i < n; i++)
            {
                int h;
                cin >> h;
                pos[h] = i;
            }
            SegTree<S, op, e> t(n);
            vector<int> dp(n);
            int ans = 0;
            for (int h = 1; h <= n; h++)
            {
                if (h - d >= 1)
                {
                    int j = pos[h - d];
                    t.set(j, dp[j]);
                }
                int i = pos[h];
                dp[i] = t.prod(max(0, i - r), min(n, i + r + 1)) + 1;
                ans = max(ans, dp[i]);
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [G - A/B < p/q < C/D](https://atcoder.jp/contests/abc408/tasks/abc408_g) 

???+ Abstract "题目大意"

给你四个正整数 $A,B,C,D$，满足 $\frac{A}{B} < \frac{C}{D}$，其中 $1 \le A, B, C, D \le 10^{18}$ 。请求出最小的正整数 $q$，满足存在一个正整数 $p$ 使得 $\frac{A}{B} < \frac{p}{q} < \frac{C}{D}$。

可以证明这样的 $q$ 一定存在。

??? Note "解题思路"

玄学题，参考 [这篇题解](https://www.luogu.com.cn/article/uj0tlcwf) 的做法。。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <utility>

        using namespace std;
        using LL = long long;

        pair<LL, LL> solve(LL a, LL b, LL c, LL d)
        {
            LL k = a / b;
            a -= k * b;
            c -= k * d;
            if (c > d)
                return {1 + k, 1};
            auto [p, q] = solve(d, c, b, a);
            return {q + k * p, p};
        }

        int main()
        {
            int T;
            cin >> T;
            while (T--)
            {
                LL a, b, c, d;
                cin >> a >> b >> c >> d;
                auto [p, q] = solve(a, b, c, d);
                cout << q << '\n';
            }
            return 0;
        }
        ```
