## [A - Not Acceptable](https://atcoder.jp/contests/abc406/tasks/abc406_a)

???+ Abstract "题目大意"

给你两个同一天的时间 $A$ 时 $B$ 分，和 $C$ 时 $D$ 分，问：$A$ 时 $B$ 分是否在 $C$ 时 $D$ 分之前？

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <utility>

        using namespace std;

        int main()
        {
            pair<int, int> ab, cd;

                cout << "Yes" << endl;
            else
                cout << "No" << endl; 
            return 0;
        }
        ```

## [B - Product Calculator](https://atcoder.jp/contests/abc406/tasks/abc406_b)

???+ Abstract "题目大意"

高桥有一台计算器，初始时计算器上显示的数为 $1$。

有 $N$ 次乘法操作。每一次操作给你一个正整数 $A_i$，表示将当前显示的数字乘以 $A_i$。不过，计算器最多只能显示 $K$ 位数字，每次操作后，如果结果有 $(K+1)$ 或者更多位，计算器会显示 1；否则，计算器显示正确结果。

请计算出计算器在这 N 次操作后显示的数字。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <cmath>
        #include <iostream>

        using namespace std;
        using LL = long long;

        int main()
        {
            int n, k;
            cin >> n >> k;
            __int128 p = pow(10, k);
            __int128 now = 1;
            while(n--)
            {
                LL a;
                cin >> a;
                now *= a;
                if(now >= p)
                    now = 1;
            }
            cout << (LL)now << endl;    
            return 0;
        }
        ```

## [C - ~](https://atcoder.jp/contests/abc406/tasks/abc406_c)

???+ Abstract "题目大意"

对于一个序列 $A = (A_1, A_2, ..., A_{|A|})$，$A$ 是波浪序列当且仅当以下条件被满足：

- $|A| \ge 4$
- $A_1 < A_2$
- 恰好存在一个 $2 \le i < M$，满足 $A_{i-1} < A_i > A_{i+1}$
- 恰好存在一个 $2 \le i < M$，满足 $A_{i-1} > A_i < A_{i+1}$。

给你一个 $1$ 到 $N(4 \le N \le 3 \times 10 ^ 5)$ 的排列，求 $P$ 有多少个连续子串是波浪序列。

??? Note "解题思路"

首先预处理一下每个位置 $i$ 满足条件 3 和条件 4 的位置，然后枚举起点就可以了。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <vector>

        using namespace std;
        using LL = long long;

        int main()
        {
            int n;
            cin >> n;
            vector<int> p(n);
            for (auto &x : p)
                cin >> x;
            vector<int> a, b;
            for (int i = 2; i < n; i++)
            {
                if (p[i - 2] < p[i - 1] && p[i - 1] > p[i])
                    a.push_back(i);
                if (p[i - 2] > p[i - 1] && p[i - 1] < p[i])
                    b.push_back(i);
            }
            a.push_back(n);
            b.push_back(n);
            LL ans = 0;
            for (int i = 0, j = 0, k = 0; i + 1 < n && a[j] < n && b[k] < n; i++)
            {
                if (p[i] < p[i + 1])
                {
                    int l = max(a[j], b[k]);
                    int r = min(a[j + 1], b[k + 1]);
                    if (l < r)
                        ans += r - l;
                }
                if (i + 2 == a[j])
                    j++;
                if (i + 2 == b[k])
                    k++;
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [D - Garbage Removal](https://atcoder.jp/contests/abc406/tasks/abc406_d)

???+ Abstract "题目大意"

有一个 $H \times W(1 \le H, W \le 2 \times 10 ^ 5)$ 的网格。网格上有 $N(1 \le N \le 2 \times 10 ^ 5)$ 个垃圾，第 $i$ 个垃圾在单元格 $(X_i, Y_i)$ 上。

给你 $Q(1 \le Q \le 2 \times 10 ^ 5)$ 个查询，查询有两种类型：

- `1 x`：求出网格第 $x$ 行的垃圾数量之和。然后，移除第 $x$ 行的所有垃圾。
- `2 y`：求出网格第 $y$ 列的垃圾数量之和。然后，移除第 $y$ 列的所有垃圾。

??? Note "解题思路"

用哈希表维护每一个行、每一列的垃圾就行。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <unordered_map>
        #include <unordered_set>

        using namespace std;

        int main()
        {
            int h, w, n;
            cin >> h >> w >> n;
            unordered_map<int, unordered_set<int>> row, col;
            while (n--)
            {
                int x, y;
                cin >> x >> y;
                row[x].insert(y);
                col[y].insert(x);
            }

            int q;
            cin >> q;
            while (q--)
            {
                int op, x, y;
                cin >> op;
                if (op == 1)
                {
                    cin >> x;
                    auto it = row.find(x);
                    if (it == row.end())
                    {
                        cout << 0 << '\n';
                        continue;
                    }
                    for (auto y : it->second)
                        col[y].erase(x);
                    cout << it->second.size() << '\n';
                    row.erase(it);
                }
                else
                {
                    cin >> y;
                    auto it = col.find(y);
                    if (it == col.end())
                    {
                        cout << 0 << '\n';
                        continue;
                    }
                    for (auto x : it->second)
                        row[x].erase(y);
                    cout << it->second.size() << '\n';
                    col.erase(it);
                }
            }
            return 0;
        }
        ```

## [E - Popcount Sum 3](https://atcoder.jp/contests/abc406/tasks/abc406_e)

???+ Abstract "题目大意"

给你两个正整数 $N(1 \le N < 2^{60})$ 和 $K(1 \le K \le 60)$。在所有小于等于 $N$ 的正整数中，求出满足以下条件的数字 $x$ 的总和：
- $x$ 的二进制表示恰好有 $K$ 个 $1$。
 
答案对 $998244353$ 取模。

??? Note "解题思路"

显然是一个数位 dp，首先需要预处理出来两个数组：

- $c[i][j]$ 表示在 $i$ 位中选 $j$ 个 $1$ 的方案数，这个其实就是组合数。
- $s[i][j]$ 表示在 $i$ 位中选 $j$ 个 $1$ 的所有方案的数字的总和，这个语出的方式和组合数一样，很容易推导出来 $s[i][j] = s[i-1][j] + 2^{i-1} \times c[i-1][j-1] + s[i-1][j-1]$。

然后考虑如何 dp，从最高位开始考虑：
- 假设某一位是 $0$，没有其他的选择，只能选 $0$，进入下一位。
- 假设某一位是 $1$，那么当前位可以是 $0$，这种情况下后面的位就是自由选择，假设前面已经选了 $\text{cnt}$ 个 $1$，后面的位就可以自由选出 $K - cnt$ 个 $1$，但是答案需要的是数字的和，所以不仅要维护 $\text{cnt}$（选了几个 $1$），还需要把前缀 $\text{prefix}$ 也记下来，所以答案就是 $\text{ans} = \text{ans} + s[i][k - \text{cnt}] + \text{prefix} \times c[i][k - \text{cnt}]$。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include "atcoder/modint.hpp"
        #include <array>
        #include <bitset>
        #include <iostream>

        using namespace std;
        using LL = long long;
        using mint = atcoder::modint998244353;

        const mint MOD = 998244353;
        const int MAXB = 61;

        int main()
        {
            array<array<mint, MAXB>, MAXB> c{};
            array<array<mint, MAXB>, MAXB> s{};
            c[0][0] = 1;
            for (int i = 1; i < MAXB; i++)
            {
                c[i][0] = 1;
                for (int j = 1; j <= i; j++)
                    c[i][j] = c[i - 1][j] + c[i - 1][j - 1];
            }
            for (int i = 1; i < MAXB; i++)
            {
                mint p = 1ll << (i - 1);
                s[i][0] = 0;
                for (int j = 1; j <= i; j++)
                    s[i][j] = s[i - 1][j] + p * c[i - 1][j - 1] + s[i - 1][j - 1];
            }

            auto cal = [&c, &s](LL x, int k) -> mint
            {
                bitset<MAXB> b(x);
                int cnt = 0;
                mint ans = 0;
                mint prefix = 0;
                for (int i = MAXB - 1; i >= 0; i--)
                {
                    if (cnt > k)
                        break;
                    if (b[i])
                    {
                        ans += s[i][k - cnt] + prefix * c[i][k - cnt];
                        cnt++;
                        prefix += 1ll << i;
                    }
                    if (i == 0 && cnt == k)
                        ans += prefix;
                }
                return ans;
            };

            int t;
            cin >> t;
            while (t--)
            {
                LL n;
                int k;
                cin >> n >> k;
                cout << cal(n, k).val() << '\n';
            }
            return 0;
        }
        ```

## [F - Compare Tree Weights ](https://atcoder.jp/contests/abc406/tasks/abc406_f)

???+ Abstract "题目大意"

给你一个 $N(2 \le N \le 3 \times 10 ^ 5)$ 个顶点的树 $T$。每个顶点都有一个权重，最初，所有顶点的权重都为 $1$。

给你 $Q(1 \le Q \le 3 \times 10 ^ 5)$ 个查询，查询有两种类型：
- `1 x w`：将顶点 $x$ 的权重增加 $w$。
- `2 y`：如果删除第 $y$ 条边，$T$ 将分裂成两个子树。将每个子树中的顶点的权重总和作为该子树的权重时，输出两个子树权重的差的绝对值。

请注意，第二种类型的查询实际上并没有删除边。

??? Note "解题思路"

显然可以轻松的用一个变量维护所有点的权重之和，记为 $S$ 。这样，对于询问 2，只要能求出任意一个子树的权重，假设是 $X$ ，那么答案其实就是 $|S - 2X|$。

所以其实只需要用 dfs 序遍历一下，维护每个点的子树大小，修改直接在树状数组上改就可以了。查询的时候，对于一条边 $(u, v)$，只需要求出深度较大的点的子树大小即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <utility>
        #include <vector>

        using namespace std;

        struct Graph
        {
            int n, ti = 1;
            vector<vector<int>> edge;
            vector<int> fa, son, dfn;

            Graph(int n) : n(n), edge(n), fa(n), son(n), dfn(n) {}

            void add(int u, int v) { edge[u].push_back(v); }

            void dfs(int u)
            {
                dfn[u] = ti++;
                son[u] = 1;
                for (int v : edge[u])
                {
                    if (v == fa[u])
                        continue;
                    fa[v] = u;
                    dfs(v);
                    son[u] += son[v];
                }
            }

            int get_dfn(int u) const { return dfn[u]; }
            pair<int, int> get_range(int u) const { return {dfn[u], dfn[u] + son[u] - 1}; }
        };

        struct FenwickTree
        {
            int n;
            vector<int> t;

            FenwickTree(int n) : n(n), t(n)
            {
                for (int i = 1; i < n; i++)
                {
                    t[i]++;
                    int j = i + lowbit(i);
                    if (j < n)
                        t[j] += t[i];
                }
            }

            int lowbit(int x) const { return x & -x; }

            void add(int x, int v)
            {
                for (int i = x; i < n; i += lowbit(i))
                    t[i] += v;
            }

            int prefix_sum(int x) const
            {
                int ans = 0;
                for (int i = x; i; i -= lowbit(i))
                    ans += t[i];
                return ans;
            }

            int range_sum(int l, int r) const { return prefix_sum(r) - prefix_sum(l - 1); }
        };

        int main()
        {
            int n;
            cin >> n;
            vector<pair<int, int>> edge(n - 1);
            Graph g(n + 1);
            for (auto &[u, v] : edge)
            {
                cin >> u >> v;
                g.add(u, v);
                g.add(v, u);
            }
            g.dfs(1);
            FenwickTree t(n + 1);
            int q;
            cin >> q;
            int total = n;
            while (q--)
            {
                int op;
                cin >> op;
                if (op == 1)
                {
                    int x, w;
                    cin >> x >> w;
                    x = g.get_dfn(x);
                    t.add(x, w);
                    total += w;
                }
                else
                {
                    int y;
                    cin >> y;
                    y--;
                    auto [u, v] = edge[y];
                    if (g.fa[u] == v)
                        swap(u, v);
                    auto [l, r] = g.get_range(v);
                    int ans = abs(total - 2 * t.range_sum(l, r));
                    cout << ans << endl;
                }
            }
            return 0;
        }
        ```
