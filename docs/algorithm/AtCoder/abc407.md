## [B - P(X or Y)](https://atcoder.jp/contests/abc407/tasks/abc407_b)

???+ Abstract "题目大意"

有两个每一面分别为 $1,2,3,4,5,6$ 的六面骰子，给你两个整数 $X$ 和 $Y$，然后投掷两个骰子，求出下面两个条件至少满足一个的概率。

- 两个骰子的点数之和大于或等于 $X$。
- 两个骰子点数之差的绝对值大于或等于 $Y$。

骰子每个面的可能性是相同的，两个骰子是独立的，一个骰子投出的点数不影响另一个骰子投出的点数

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iomanip>
        #include <ios>
        #include <iostream>

        using namespace std;

        int main()
        {
            int x, y;
            cin >> x >> y;
            int cnt = 0;
            for (int i = 1; i <= 6; i++)
                for (int j = 1; j <= 6; j++)
                    cnt += (i + j >= x) || (abs(i - j) >= y);
        ```

## [C - Security 2](https://atcoder.jp/contests/abc407/tasks/abc407_c)

???+ Abstract "题目大意"

有一个特殊的密码输入设备。该设备由一个显示一个字符串的屏幕和两个按钮组成。

屏幕上显示的字符串为 $t$ 。最初， $t$ 是空字符串。按下按钮后， $t$ 将发生如下变化：

- 按下按钮 A，在 $t$ 的末尾添加 `0`。
- 按下按钮 B， $t$ 中的每一位数字都会被替换为下一位数字，对于数字 `9`，下一位数字是 `0`。
 
例如，如果 $t$ 是 `1984` 并按下 A 按钮， $t$ 就变成了 `19840`；如果再按下 B 按钮， $t$ 就变成了 `20951`。

给你一个字符串 $S$ 。从空字符串开始，你可以按下 $0$ 次或更多次按钮，直到 $t$ 等于 $S$，问：求最少需要按多少次按钮？

??? Note "解题思路"

显然按钮 B 其实不会改变两个相邻数字的差，所以在按下 A 按钮之前，必须保证最后一位数字和 `0` 的差值最终相同，而调整这个差值就是通过 B 按钮实现的。只有最后一尾的差值一样的时候，才可以按下 A 按钮。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <string>

        using namespace std;

        int main()
        {
            string s;
            cin >> s;
            int n = s.size();
            int ans = n;
            for(int i = 1; i < n; i++)
            {
                int d = (s[i-1] - s[i] + 10) % 10;
                ans += d;
            }
            ans += s.back() - '0';
            cout << ans << endl;
            return 0;
        }
        ```

## [D - Domino Covering XOR](https://atcoder.jp/contests/abc407/tasks/abc407_d)

???+ Abstract "题目大意"

有一个 $H \times W(1 \le HW \le 20)$ 的网格，每个网格上都有一个非负整数 $A_{i,j}$ 。

你可以在网格上放置任意块 $1 \times 2$ 或者 $2 \times 1$ 的多米诺骨牌。每个网格至多只能被一块多米诺骨牌覆盖。

放置完成后，所有未被多米诺骨牌覆盖的单元格中的整数的按位 XOR （异或）的结果就是你的得分。求得分的最大值。

??? Note "解题思路"

直接 dfs 搜索就可以了。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <vector>

        using namespace std;
        using LL = long long;

        int main()
        {
            int h, w;
            cin >> h >> w;
            vector<vector<LL>> a(h, vector<LL>(w));
            vector<vector<bool>> vis(h, vector<bool>(w));
            for (int i = 0; i < h; i++)
                for (int j = 0; j < w; j++)
                    cin >> a[i][j];
            LL ans = 0;
            auto dfs = [h, w, &a, &vis, &ans](auto &&self, int i, int j, LL score) -> void
            {
                if (i == h)
                {
                    ans = max(ans, score);
                    return;
                }

                int ni = j == w - 1 ? i + 1 : i;
                int nj = j == w - 1 ? 0 : j + 1;
                if (vis[i][j])
                    self(self, ni, nj, score);
                else
                {
                    self(self, ni, nj, score ^ a[i][j]);

                    if (j + 1 < w && !vis[i][j + 1])
                    {
                        vis[i][j] = vis[i][j + 1] = true;
                        self(self, ni, nj, score);
                        vis[i][j] = vis[i][j + 1] = false;
                    }

                    if (i + 1 < h && !vis[i + 1][j])
                    {
                        vis[i][j] = vis[i + 1][j] = true;
                        self(self, ni, nj, score);
                        vis[i][j] = vis[i + 1][j] = false;
                    }
                }
            };

            dfs(dfs, 0, 0, 0);
            cout << ans << endl;

            return 0;
        }
        ```

## [E - Most Valuable Parentheses](https://atcoder.jp/contests/abc407/tasks/abc407_e)

???+ Abstract "题目大意"

给你一个长度为 $2N(1 \le N \le 2 \times 10 ^ 5)$ 的数列 $A = (A_1, A_2, \ldots, A_{2N})$。

定义一个长度为 $2N$ 的括号序列 $s$ 的得分：

- 对于所有 $s_i=$ `)` 的位置 $i$，将 $A_i$ 的值设置为 $0$。然后，$\sum\limits_{i = 1}^{2N}A_i$ 就是这个括号序列的得分。

求出最大得分的括号序列。

注：一个括号序列是合法的当且仅当它可以通过多次删去子段 () 变为空串。

??? Note "解题思路"

我们需要发掘括号序列的一些性质，首先很容易证明，任何括号序列的第一个位置一定是 `(`。所以 $A_1$ 一定会在答案中。

然后考虑第 $2$、$3$ 个位置，这两个位置不可能都是 `)`，也就是说至少会有一个 `(`，如果 $A_2 > A_3$，就选择 $A_2$，否则选择 $A_3$。至于另一个没有选择的数字，先加入候选集。

这里我们假设 $A_2 > A_3$，上一步选了 $A_2$。然后考虑第 $3$、$4$、$5$ 个位置，显然这里不可能全是 `)`，也就是还可以再选一个数字，肯定是选最大的数字，然后把剩下的数字加入候选集。

所以依次类推，每一次从候选集里面选一个最大的数字即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <queue>
        #include <vector>

        using namespace std;
        using LL = long long;

        void solve()
        {
            int n;
            cin >> n;
            vector<int> a(2 * n);
            for (int i = 0; i < 2 * n; i++)
                cin >> a[i];
            LL ans = a[0];
            priority_queue<int> heap;
            for (int i = 1; i < 2 * n - 1; i += 2)
            {
                heap.push(a[i]);
                heap.push(a[i + 1]);
                ans += heap.top();
                heap.pop();
            }
            cout << ans << '\n';
        }

        int main()
        {
            int t;
            cin >> t;
            while (t--)
                solve();
            return 0;
        }
        ```

## [F - Sums of Sliding Window Maximum](https://atcoder.jp/contests/abc407/tasks/abc407_f)

???+ Abstract "题目大意"

给你一个长度为 $N(1 \le N \le 2 \times 10 ^ 5)$ 的数列 $A = (A_1, A_2, \ldots, A_N)$。

对于每个 $1 \le k \le N$，求出 $A$ 中所有长度为 $k$ 的连续子序列的最大值的和。

??? Note "解题思路"

考虑求出每个位置的数字的贡献。处理出两个数组 $L_i$ 和 $R_i$，分别表示：
- $L_i$ 表示从 $i$ 开始向左找，第一个大于等于 $A_i$ 的数字的位置。
- $R_i$ 表示从 $i$ 开始向右找，第一个大于 $A_i$ 的数字的位置。

这样每个数字生效的窗口就是 $[L_i + 1, R_i - 1]$。不妨设 $L_i + 1 \le x \le i \le y \le R_i - 1$，那么对于这样的 $x$ 和 $y$，对应的连续子序列的最大值就是 $A_i$。

考虑累加贡献：
- 当 $x = i$ 时，$y$ 的取值范围是 $[i, R_i - 1]$。能贡献的区间长度就是 $1, 2, \ldots, R_i - i$。也就是为 $k = 1, 2, \ldots, R_i - i$ 贡献 $A_i$ 的答案。
- 当 $x = i - 1$ 时，同理，能贡献的区间长度就是 $2, 3, \ldots, R_i - i + 1$。
- $......$

可以将上面的操作用差分来处理，设 $d_k$ 表示长度为 $k$ 的答案的差分数组，则:

- 当 $x = 1$ 的时候，相当于给 $d_1$ 加上 $A_i$，给 $d_{R_i - i + 1}$ 减去 $A_i$。
- 当 $x = 2$ 的时候，相当于给 $d_2$ 加上 $A_i$，给 $d_{R_i - i + 2}$ 减去 $A_i$。
- 当 $x = 3$ 的时候，相当于给 $d_3$ 加上 $A_i$，给 $d_{R_i - i + 3}$ 减去 $A_i$。
- $......$

进一步可以发现，这相当于就是对差分数组做两次区间赋值，所以只需要维护差分的差分即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <stack>
        #include <vector>

        using namespace std;
        using LL = long long;

        int main()
        {
            ios::sync_with_stdio(false);
            cin.tie(nullptr);
            int n;
            cin >> n;
            vector<int> a(n), l(n), r(n);
            stack<int> st;
            for (int i = 0; i < n; i++)
            {
                cin >> a[i];
                while (!st.empty() && a[st.top()] < a[i])
                    st.pop();
                l[i] = st.empty() ? -1 : st.top();
                st.push(i);
            }
            st = {};
            for (int i = n - 1; i >= 0; i--)
            {
                while (!st.empty() && a[st.top()] <= a[i])
                    st.pop();
                r[i] = st.empty() ? n : st.top();
                st.push(i);
            }

            vector<LL> b(n + 3);
            auto add = [&b](int l, int r, int x) -> void
            {
                b[l] += x;
                b[r + 1] -= x;
            };

            for (int i = 0; i < n; i++)
            {
                add(1, i - l[i], a[i]);
                add(r[i] - i + 1, r[i] - l[i], -a[i]);
            }
            for (int i = 1; i <= n; i++)
                b[i] += b[i - 1];
            for (int i = 1; i <= n; i++)
            {
                b[i] += b[i - 1];
                cout << b[i] << '\n';
            }
            return 0;
        }
        ```

## 

???+ Abstract "题目大意"

有一个 $H \times W(1 \le HW \le 2000)$ 的网格，每个网格上都有一个整数 $A_{i,j}(-10^{12} \le A_{i,j} \le 10^{12})$ 。

你可以在网格上放置任意块 $1 \times 2$ 或者 $2 \times 1$ 的多米诺骨牌。每个网格至多只能被一块多米诺骨牌覆盖。

放置完成后，所有未被多米诺骨牌覆盖的单元格中的整数的和就是你的得分。求得分的最大值。

??? Note "解题思路"

显然是一个二分图上跑费用流的题，考虑如何建图。如果什么都不做，得分就是所有格子的数字之和。如果所有的数字都是正数，那这就是最优解。

因为有负数存在，所以我们希望减去一些值，假设所有数字的和是 $S$，减去的值是 $X$，则答案就是 $S-X$，也就是希望 $X$ 尽可能小。而减去的数字就是被多米诺骨牌覆盖的格子的数字之和。所以每一条边按照两点的和作为权重，建图即可。

但这里还有个问题，如果直接跑费用流，求的其实是最大流，但最大流对应的费用不一定是最小的。

但是我们可以跑多次增广路，只需要把每一次增广路得到的费用记下来，取最小值就可以了。tpe

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <limits>
        #include <queue>
        #include <utility>
        #include <vector>

        using namespace std;
        using LL = long long;

        template <typename Cost = int>
        class Network
        {
        public:
            Network(int n) : n(n), edge(n), h(n, MAX_COST) {}

            void add_edge(int u, int v, int f, Cost c)
            {
                int ui = edge[u].size();
                int vi = edge[v].size();
                edge[u].push_back({v, f, c, vi});
                edge[v].push_back({u, 0, -c, ui});
            }

            // spfa
            void init(int s)
            {
                h[s] = 0;
                queue<int> q;
                q.push(s);
                while (!q.empty())
                {
                    int u = q.front();
                    q.pop();
                    Cost d = h[u];
                    for (auto e : edge[u])
                    {
                        int v = e.to;
                        if (e.flow && d + e.cost < h[v])
                        {
                            h[v] = d + e.cost;
                            q.push(v);
                        }
                    }
                }
            }

            pair<Cost, int> slope(int s, int t)
            {
                vector<Cost> dis(n, MAX_COST);
                vector<Edge *> from(n);

                auto dijkstra = [&]() -> bool
                {
                    struct Node
                    {
                        int u;
                        Cost d;
                        bool operator>(const Node &other) const { return d > other.d; }
                    };

                    dis.assign(n, MAX_COST);
                    dis[s] = 0;
                    priority_queue<Node, vector<Node>, greater<Node>> heap;
                    heap.push({s, 0});
                    while (!heap.empty())
                    {
                        auto [u, d] = heap.top();
                        heap.pop();
                        if (d > dis[u])
                            continue;
                        for (auto &e : edge[u])
                        {
                            int v = e.to;
                            Cost c = e.cost + h[u] - h[v];
                            if (e.flow && d + c < dis[v])
                            {
                                dis[v] = d + c;
                                heap.push({v, dis[v]});
                                from[v] = &e;
                            }
                        }
                    }
                    return dis[t] != MAX_COST;
                };

                if (!dijkstra())
                    return {0, 0};

                Cost mincost = 0;
                int maxflow = 0;
                for (int u = 0; u < n; u++)
                    h[u] += dis[u];
                int flow = numeric_limits<int>::max();
                for (Edge *p = from[t]; p;)
                {
                    flow = min(flow, p->flow);
                    int v = p->to, rev_idx = p->rev_idx;
                    Edge *r = &edge[v][rev_idx];
                    p = from[r->to];
                }
                for (Edge *p = from[t]; p;)
                {
                    int v = p->to, rev_idx = p->rev_idx;
                    Edge *r = &edge[v][rev_idx];
                    p->flow -= flow;
                    r->flow += flow;
                    p = from[r->to];
                }
                mincost += h[t] * flow;
                maxflow += flow;
                return {mincost, maxflow};
            }

            pair<Cost, int> mcmf(int s, int t)
            {
                init(s);
                Cost mincost = 0;
                int maxflow = 0;
                while (true)
                {
                    auto [cost, flow] = slope(s, t);
                    if (flow == 0)
                        break;
                    mincost += cost;
                    maxflow += flow;
                }
                return {mincost, maxflow};
            }

        private:
            const Cost MAX_COST = numeric_limits<Cost>::max();

            struct Edge
            {
                int to, flow;
                Cost cost;
                int rev_idx;
            };

            int n;
            vector<vector<Edge>> edge;
            vector<Cost> h;
        };

        int main()
        {
            int h, w;
            cin >> h >> w;
            int s = h * w, t = s + 1;
            vector<vector<LL>> a(h, vector<LL>(w));
            Network<LL> g(t + 1);

            auto get_id = [w](int i, int j) -> int
            { return i * w + j; };

            for (int i = 0; i < h; i++)
                for (int j = 0; j < w; j++)
                    cin >> a[i][j];
            LL total = 0;
            for (int i = 0; i < h; i++)
                for (int j = 0; j < w; j++)
                {
                    total += a[i][j];
                    if ((i + j) & 1)
                    {
                        int v = get_id(i, j);
                        g.add_edge(v, t, 1, 0);
                        if (i + 1 < h)
                        {
                            int u = get_id(i + 1, j);
                            g.add_edge(u, v, 1, a[i][j] + a[i + 1][j]);
                        }
                        if (j + 1 < w)
                        {
                            int u = get_id(i, j + 1);
                            g.add_edge(u, v, 1, a[i][j] + a[i][j + 1]);
                        }
                    }
                    else
                    {
                        int u = get_id(i, j);
                        g.add_edge(s, u, 1, 0);
                        if (i + 1 < h)
                        {
                            int v = get_id(i + 1, j);
                            g.add_edge(u, v, 1, a[i][j] + a[i + 1][j]);
                        }
                        if (j + 1 < w)
                        {
                            int v = get_id(i, j + 1);
                            g.add_edge(u, v, 1, a[i][j] + a[i][j + 1]);
                        }
                    }
                }
            LL ans = total;
            g.init(s);
            while (true)
            {
                auto [mincost, maxflow] = g.slope(s, t);
                if (maxflow == 0)
                    break;
                total -= mincost;
                ans = max(ans, total);
            }
            cout << ans << endl;
            return 0;
        }
        ```
