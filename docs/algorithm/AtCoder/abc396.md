## [A - Triple Four](https://atcoder.jp/contests/abc396/tasks/abc396_a)

???+ Abstract "题目大意"

给你一个长度为 $N$ 的数组 $A = (A_1, A_2, ..., A_N)$，判断是否有长度为 $3$ 的连续子数组所有数字都一样。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <vector>
    
        using namespace std;
    
        int main()
        {
            int n;
            cin >> n;
            vector<int> a(n);
            for(int i = 0; i < n; i++)
                cin >> a[i];
            for(int i = 2; i < n; i++)
                if(i >= 2 && a[i] == a[i-1] && a[i] == a[i-2])
                {
                    cout << "Yes" << endl;
                    return 0;
                }
            cout << "No" << endl;
            return 0;
        }
        ```

## [B - Card Pile](https://atcoder.jp/contests/abc396/tasks/abc396_b)

???+ Abstract "题目大意"

你需要维护一个栈，初始的时候，栈中有 $100$ 个数字 $0$。

有两种操作：

-   `1 x`：向栈中加入数字 $x$。
-   `2`：弹出栈顶的数字，并输出。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <stack>
    
        using namespace std;
    
        int main()
        {
            stack<int> st;
            for (int i = 0; i < 100; i++)
                st.push(0);
            int q;
            cin >> q;
            while (q--)
            {
                int op, x;
                cin >> op;
                if (op == 1)
                {
                    cin >> x;
                    st.push(x);
                }
                else
                {
                    cout << st.top() << endl;
                    st.pop();
                }
            }
            return 0;
        }
        ```

## [C - Buy Balls](https://atcoder.jp/contests/abc396/tasks/abc396_c)

???+ Abstract "题目大意"

有 $N(1 \le N \le 2 \times 10 ^ 5)$ 个黑球和 $M(1 \le M \le 2 \times 10 ^ 5)$ 个白球，第 $i$ 个黑球的价值是 $B_i(-10 ^ 9 \le B_i \le 10 ^ 9)$，第 $j$ 个白球的价值是 $W_j(-10 ^ 9 \le W_j \le 10 ^ 9)$。

你可以选择任意个球，使得所选黑色球的数量不少于白色球的数量。求所选球的价值总和的最大可能值。

??? Note "解题思路"

显然需要排个序，然后所有的大于等于 $0$ 的黑球是必选的。接下来枚举白球的数量，一旦白球数量大于黑球，就补一个黑球。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <functional>
        #include <iostream>
        #include <vector>

        using namespace std;
        using LL = long long;

        int main()
        {
            int n, m;
            cin >> n >> m;
            vector<LL> b(n), w(m);
            for (int i = 0; i < n; i++)
                cin >> b[i];
            for (int i = 0; i < m; i++)
                cin >> w[i];
            sort(b.begin(), b.end(), greater<LL>());
            sort(w.begin(), w.end(), greater<LL>());
            LL sum = 0;
            for (int i = 0; i < n && b[i] >= 0; i++)
                sum += b[i];
            LL ans = sum;
            for (int i = 0; i < n && i < m; i++)
            {
                if (b[i] < 0)
                    sum += b[i];
                sum += w[i];
                ans = max(ans, sum);
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [D - Minimum XOR Path](https://atcoder.jp/contests/abc396/tasks/abc396_d)

???+ Abstract "题目大意"

给你一个 $N(1 \le N \le 10)$ 个点 $M(N - 1 \le M \le \frac{N(N - 1)}{2})$ 条边的简单无向连通图，每条边有一个权值 $w_i$。

定义一条路径的权值为路径上所有边权的异或和。求从点 $1$ 到点 $N$ 的路径的权值的最小值。

??? Note "解题思路"

只有 $10$ 个点，直接 dfs 枚举所有路径即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <iostream>
        #include <limits>
        #include <utility>
        #include <vector>

        using namespace std;
        using LL = long long;

        int main()
        {
            int n, m;
            cin >> n >> m;
            vector<vector<pair<int, LL>>> edge(n + 1);
            while (m--)
            {
                int u, v;
                LL w;
                cin >> u >> v >> w;
                edge[v].push_back({u, w});
                edge[u].push_back({v, w});
            }
            vector<bool> vis(n + 1);
            LL ans = numeric_limits<LL>::max();
            auto dfs = [n, &vis, &edge, &ans](auto &&self, int u, LL s)
            {
                if (u == n)
                {
                    ans = min(ans, s);
                    return;
                }
                vis[u] = true;
                for (auto [v, w] : edge[u])
                {
                    if (vis[v])
                        continue;
                    self(self, v, s ^ w);
                }
                vis[u] = false;
            };

            dfs(dfs, 1, 0);
            cout << ans << endl;
            return 0;
        }
        ```

## [E - Min of Restricted Sum](https://atcoder.jp/contests/abc396/tasks/abc396_e)

???+ Abstract "题目大意"

给你两个整数 $N$ 和 $M$，然后给你三个长度为 $M(0 \le M \le 10 ^ 5)$ 的数组 $X = (X_1, X_2, ..., X_M)$，$Y = (Y_1, Y_2, ..., Y_M)$ 和 $Z = (Z_1, Z_2, ..., Z_M)$，其中 $1 \le X_i, Y_i \le N$，$0 \le Z_i \le 10 ^ 9$。

如果一个长度为 $N$ 的序列 $A = (A_1, A_2, ..., A_N)$ 满足以下条件，就称它是一个“好”序列：

- 对于每个 $i(1 \le i \le M)$，$A_{X_i} \oplus A_{Y_i} = Z_i$。 

判断是否存在一个“好”序列 $A$，如果存在，输出 $\sum\limits_{i = 1}^{N}A_i$ 的最小值。如果不存在，输出 `-1`。

??? Note "解题思路"

可以构造一个 $N$ 个点的图，图中每个点有一个权值，对于一组 $(X_i, Y_i, Z_i)$，可以对应一条无向有权边 。这样图会被分割成若干个连通分量，连通分量中只要确定一个点的值就能确定其他点的值。下面考虑如何构造最小值，因为 $0 \le Z_i \le 10 ^ 9$，所以每个点的权值至多有 $30$ 位。依次考虑每一位填 $0$ 还是填 $1$ 就好，选择 $1$ 最少的方案即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <unordered_map>
        #include <utility>
        #include <vector>

        using namespace std;
        using LL = long long;

        int main()
        {
            int n, m;
            cin >> n >> m;
            vector<vector<pair<int, int>>> edge(n + 1);

            while (m--)
            {
                int x, y, z;
                cin >> x >> y >> z;
                edge[x].push_back({y, z});
                edge[y].push_back({x, z});
            }

            unordered_map<int, int> s;

            auto dfs = [&edge, &s](auto &self, int u, int fa, int flag, int bit) -> pair<int, int>
            {
                s[u] = flag;
                int sum = flag;
                int cnt = 1;
                for (auto [v, z] : edge[u])
                {
                    if (v == fa)
                        continue;
                    auto it = s.find(v);
                    if (it != s.end())
                    {
                        auto vf = it->second;
                        if ((vf ^ flag) != z >> bit)
                            return {-1, 0};
                    }
                    auto [sum_v, cnt_v] = self(self, v, u, (z >> bit) ^ flag, bit);
                    if (sum_v == -1)
                        return {-1, 0};
                    sum += sum_v;
                    cnt += cnt_v;
                }
                return {sum, cnt};
            };

            LL ans = 0;
            for (int u = 1; u <= n; u++)
            {
                if (s.contains(u))
                    continue;
                for (int i = 0; i < 30; i++)
                {
                    auto [sum, cnt] = dfs(dfs, u, 0, 0, i);
                    if(sum == -1)
                    {
                        cout << -1 << endl;
                        return 0;
                    }
                    cnt = min(cnt, sum - cnt);
                    
                    ans += cnt * (1ll << i);
                }
            }

            cout << ans << endl;
            return 0;
        }
        ```

## [F - Rotated Inversions](https://atcoder.jp/contests/abc396/tasks/abc396_f) 

???+ Abstract "题目大意"

给你两个正整数 $N$ 和 $M(1 \le N, M \le 2 \times 10^5)$，然后给你一个长度为 $N$ 的数组 $A = (A_1, A_2, ..., A_N)$，其中 $1 \le A_i \le M$。

对于 $k = 0, 1, ..., M - 1$，定义数组 $B = (B_1, B_2, ..., B_N)$，其中 $B_i = (A_i + k) \bmod M$。求出每个 $B$ 数组的逆序对的数量。

??? Note "解题思路"

首先求出 $k = 0$ 时的逆序对数量，下面考虑 $k = 1$ 的答案。显然，只有 $A_i = M - 1$ 的元素会影响逆序对的数量。对于每个 $A_i = M - 1$ 的元素，$B_i$ 都会变成 $0$。对于一个 $A_i = M - 1$ 的数字，在变成 $0$ 之后，会：

- 增加所有 $j < i$ 且 $B_j > 0$ 的元素形成逆序对。会增加 $i$ 个逆序对。
- 减少所有 $j > i$ 且 $B_j > 0$ 的元素（原本）形成的逆序对。会减少 $n - i + 1$ 个逆序对。

这里无需考虑 $B_j = 0$ 之间新增或减少的逆序对，因为增加的数量和减少的数量是相等的。（可以代入上述式子算一下，求和之后这一部分是等于 $0$ 的）。

因此对于每个数字，把对逆序对的变化累加起来，就能得到每个 $k$ 的答案。时间复杂度是 $O(n\log n)$，瓶颈在求初始的逆序对数量。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <vector>

        using namespace std;
        using LL = long long;

        template <typename T>
        class FenwickTree
        {
        public:
            FenwickTree(int n) : n(n), t(n + 1) {}

            void add(int x, T k)
            {
                for (; x <= n; x += lowbit(x))
                    t[x] += k;
            }

            T ask(int l, int r) const { return prefix(r) - prefix(l - 1); }

        private:
            int n;
            vector<T> t;

            int lowbit(int x) const { return x & -x; }

            T prefix(int x) const
            {
                T sum = 0;
                for (; x; x -= lowbit(x))
                    sum += t[x];
                return sum;
            }
        };

        int main()
        {
            int n, m;
            cin >> n >> m;
            FenwickTree<int> t(m);
            LL ans = 0;
            vector<LL> d(m + 1);
            for (int i = 0; i < n; i++)
            {
                int x;
                cin >> x;
                ans += t.ask(x + 2, m);
                d[x] += 2 * i + 1 - n;
                t.add(x + 1, 1);
            }
            cout << ans << '\n';
            for (int k = 1; k < m; k++)
            {
                ans += d[m - k];
                cout << ans << '\n';
            }
            return 0;
        }
        ```
