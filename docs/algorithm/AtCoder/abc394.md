## [D - Colorful Bracket Sequence](https://atcoder.jp/contests/abc394/tasks/abc394_d)

???+ Abstract "题目大意"

给你一个字符串 $S$，$S$ 可能的字符有：`(`，`)`， `[`， `]`， `<`， `>`。判断 $S$ 是否是一个合法的括号序列。

??? Note "解题思路"

解决这一类括号匹配的问题用栈就可以了。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <stack>
        #include <string>
    
        using namespace std;
    
        int main()
        {
            string s;
            cin >> s;
            int n = s.size();
            stack<char> st;
            for(int i = 0; i < n; i++)
            {
                if(s[i] == '[' || s[i] == '(' || s[i] == '<')
                    st.push(s[i]);
                else if(s[i] == ']')
                {
                    if(st.empty() || st.top() != '[')
                    {
                        cout << "No" << endl;
                        return 0;
                    }
                    st.pop();
                }
                else if(s[i] == ')')
                {
                    if(st.empty() || st.top() != '(')
                    {
                        cout << "No" << endl;
                        return 0;
                    }
                    st.pop();
                }
                else
                {
                    if(st.empty() || st.top() != '<')
                    {
                        cout << "No" << endl;
                        return 0;
                    }
                    st.pop();
                }
            }
            if(st.empty())
                cout << "Yes" << endl;
            else
                cout << "No" << endl;
            return 0;
        }
        ```

## [E - Palindromic Shortest Path](https://atcoder.jp/contests/abc394/tasks/abc394_e)

???+ Abstract "题目大意"

给你一个 $N(1 \le N \le 100)$ 个点的有向图。边的信息通过一个 $N \times N$ 的二维矩阵 $C$ 给出，矩阵的值是小写字母或者 `-`。如果 $C_{i, j}$ 是小写字母，表示有一条从 $i$ 到 $j$ 的边，且这条边的标签为 $C_{i, j}$。如果 $C_{i, j}$ 是 `-`，表示没有从 $i$ 到 $j$ 的边。

对于所有满足 $1 \le i,j \le N$ 的整数对 $(i,j)$，回答以下问题：

-   找出从顶点 $i$ 到顶点 $j$ 的路径（不要求是简单路径），使得路径上边标签按顺序组成回文字符串。在所有满足条件的路径中，输出最短路径的长度。若不存在这样的路径，输出 $−1$。

??? Note "解题思路"

利用回文串的性质：对于一个长度大于等于 $2$ 的回文串，去掉首尾字符之后仍然是字符串。

所以考虑记忆化搜索，可以很轻易处理出所有长度小于 $2$ 的字符串对应的答案。然后对于一个 $i,j$，设有边 $(i, x, a)$ 和 $(y, j, a)$，则 $dp[i][j] = \min(dp[i][j], dp[x][y] + 2)$，枚举状态的时间复杂度是 $O(N^2)$，一共有 $N^2$ 个状态，时间复杂度就是 $O(N^4)$，可以通过。

当然，因为每一条边的权值都是 $2$，所以从初始状态开始 bfs 也是可以的，时间复杂度仍然是 $O(N^4)$ 。

参考代码给出的就是 $O(N^4)$ 的 bfs 做法。还有一种 $O(N^3 + 26N^2)$ 的做法，见 [这里](https://atcoder.jp/contests/abc394/editorial/12292)

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <limits>
        #include <queue>
        #include <string>
        #include <utility>
        #include <vector>
    
        using namespace std;
    
        const int INF = numeric_limits<int>::max();
    
        int main()
        {
            int n;
            cin >> n;
            vector<string> c(n);
            for (auto &s : c)
                cin >> s;
            queue<pair<int, int>> q;
            vector<vector<int>> dis(n, vector<int>(n, INF));
            for (int i = 0; i < n; i++)
            {
                dis[i][i] = 0;
                q.push({i, i});
            }
            for (int i = 0; i < n; i++)
                for (int j = 0; j < n; j++)
                    if (c[i][j] != '-' && i != j)
                    {
                        dis[i][j] = 1;
                        q.push({i, j});
                    }
            while (!q.empty())
            {
                auto [i, j] = q.front();
                q.pop();
                int nd = dis[i][j] + 2;
                for (int x = 0; x < n; x++)
                    for (int y = 0; y < n; y++)
                        if (c[x][i] == c[j][y] && c[x][i] != '-' && nd < dis[x][y])
                        {
                            dis[x][y] = nd;
                            q.push({x, y});
                        }
            }
            for (int i = 0; i < n; i++, cout << endl)
                for (int j = 0; j < n; j++)
                    cout << (dis[i][j] == INF ? -1 : dis[i][j]) << ' ';
            return 0;
        }
        ```

## [F - Alkane](https://atcoder.jp/contests/abc394/tasks/abc394_f)

???+ Abstract "题目大意"

定义满足以下两个条件的图为**烷烃**：

-   该图是一棵无向树。
-   所有顶点的度数为 $1$ 或 $4$，且至少存在一个度数为 $4$ 的顶点。

给你一个 $N(1 \le N \le 2 \times 10 ^ 5)$ 个点的无向树。判断树中是否存在一个子图满足烷烃的定义，如果存在，求子图顶点数的最大值。若不存在，输出 $-1$。

??? Note "解题思路"

显然可以发现：

-   如果一个点的度数小于 $4$，则只可能成为烷烃中度数为 $1$ 的点。
-   如果一个点的度数大于等于 $4$，成为度数 $4$ 的点一定比成为度数为 $1$ 的点更优。

因此可以在每个度数大于等于 $4$ 的点上进行 dfs，也就是只搜索度数大于等于 $4$ 的点。

假设 $x$ 的子节点是 $y$，$y$ 的子节点集合是 $S(y)$，且这三个节点的度数都大于等于 $4$，下面考虑 $x$ 节点选与不选：

-   如果不选 $x$，则对于 $y$ ，还需要从 $S(y)$ 中选出 $4$ 个子节点（因为 $y$  的度数大于等于 $4$，所以需要选 $4$ 个子节点出来），显然，应该选节点数量最多的。但是对于 $S(y)$ 的节点来说，因为已经有一条边和 $y$ 连接了，所以 $S(y)$ 中的节点选 $3$ 个子节点。
-   如果选 $x$，因为 $y$ 会有一条边和 $x$ 相连，所以 $y$ 实际上也需要再从 $S(y)$ 中选 $3$ 个子节点。

经上可以发现，无论 $x$ 选与不选，$S(y)$ 中的节点反馈给 $y$ 的时候只需要考虑选 $3$ 个子节点的情况，所以 dfs 的时候每个节点只需要统计选 $3$ 个子节点能组成的最大子树，定义 $f[i]$ 表示选 $i$ 以及 $i$ 的 $3$ 个子节点做能组成的最大子树的大小 。对于不选 $x$ 的情况，实际就是选 $4$ 个，直接更新答案即可。而对于选 $x$ 的情况，$y$ 直接把答案更新在 $f[y]$ 中，保证 $x$ 递归结束之后能获得 $f[y]$ 的值即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <functional>
        #include <iostream>
        #include <numeric>
        #include <queue>
        #include <vector>
    
        using namespace std;
    
        int main()
        {
            int n;
            cin >> n;
            vector<vector<int>> edge(n + 1);
            vector<int> deg(n + 1);
            for (int i = 0; i < n - 1; i++)
            {
                int u, v;
                cin >> u >> v;
                edge[u].push_back(v);
                edge[v].push_back(u);
                deg[u]++;
                deg[v]++;
            }
            int ans = -1;
            vector<bool> vis(n + 1);
            auto dfs = [&edge, &ans, &vis, &deg](auto &self, int u, int fa) -> int
            {
                vis[u] = true;
                priority_queue<int, vector<int>, greater<int>> heap;
    
                for (auto v : edge[u])
                {
                    if (v == fa)
                        continue;
                    int fv = deg[v] >= 4 ? self(self, v, u) : 1;
                    heap.push(fv);
                    if (heap.size() > 4)
                        heap.pop();
                }
    
                int len = heap.size();
                vector<int> f(len);
                for (int i = len - 1; i >= 0; i--, heap.pop())
                    f[i] = heap.top();
    
                auto prefix = [&f](int idx) -> int
                { return accumulate(f.begin(), f.begin() + idx, 0); };
    
                if (len == 4)
                    ans = max(ans, 1 + prefix(4));
                return 1 + prefix(3);
            };
            for (int u = 1; u <= n; u++)
                if (deg[u] >= 4 && !vis[u])
                    dfs(dfs, u, -1);
            cout << ans << endl;
            return 0;
        }
        ```

## [G - Dense Buildings](https://atcoder.jp/contests/abc394/tasks/abc394_g)

???+ Abstract "题目大意"

有一个 $H \times W(1 \le H, W \le 500)$ 的二维网格，每个网格有一栋楼，每一栋楼都有一个层数，位于 $(i, j)$ 位置的楼一共有 $F_{i, j}(1 \le F_{i, j} \le 10 ^ 6)$ 层。有两种移动方式：

1.   利用电梯在同一栋楼中向上或向下移动 $1$ 层。例如当前在 $(i, j)$ 楼的第 $x$ 层，可以移动到 $(i, j)$ 楼的 $x + 1$ （ 前提是 $x + 1 \le F_{i, j}$） 层或者 $(i, j)$ 楼的 $x - 1$（前提是 $x - 1 \ge 1$） 层。
2.   利用空中通道在相邻的两栋楼之间水平移动，相邻是指在二维网格中的坐标（上下左右）相邻，即曼哈顿距离为 $1$。例如，$(i, j)$ 和 $(i+1, j)$ 是相邻的两栋楼，例如当前在 $(i, j)$ 楼的第 $x$ 层，就可以移动到 $(i + 1, j)$ 楼的第 $x$ 层（前提是 $F_{i + 1, j} \ge x$）。

有 $Q(1 \le Q \le 2 \times 10 ^ 5)$ 个询问，每个询问给你六个数字 $A_i, B_i, Y_i, C_i, D_i, Z_i$，你需要回答从 $(A_i, B_i)$ 楼的 $Y_i$ 层移动到 $(C_i, D_i)$ 楼的 $Z_i$ 层至少需要使用电梯移动多少次？

??? Note "解题思路"

如果 $(A_i, B_i) = (C_i, D_i)$，也就是在同一栋楼的情况，答案就是 $|Y_i - Z_i|$。下面考虑 $$(A_i, B_i) \neq (C_i, D_i)$$ 的情况。

显然，当前楼层越低，可用的空中通道就越多。很容易想到，移动的方式一定是先在 $(A_i, B_i)$ 楼的 $X$ 层向下走，然后水平移动到 $(C_i, D_i)$ 楼，再向上走一段移动到 $Z$ 层。向下走其实是相当于找到一个中间楼层 $M$，然后使得 $(A_i, B_i)$ 楼和 $(C_i, D_i)$ 楼可以通过高度为 $M$ 的空中通道连通，这样答案就是 $Y_i + Z_i - 2 \times M$，当然，为了让答案尽可能小，所以 $M$ 需要尽可能大。下面考虑如何找到适合的 $M$。

有两种做法：

1.   将所有建筑按照高度从大到小排序，维护一个并查集，假设现在遍历到了 $(i, j)$ 楼，周围的楼是 $(i+1, j)$ 的话，如果 $F_{i, j} \le F_{i+1, j}$，表明这两栋楼可以最多可以通过 $F_{i, j}$ 层的空中通道连通。因为现在维护的是并查集，所以实际含义就是 $(i, j)$ 所在的连通块和 $(i+1, j)$ 所在的连通块能通过 $F_{i, j}$ 层的空中通道连通。所以做法也很暴力，每个连通块关联相应的询问的 id，合并两个连通块的同时，如果两个连通块有相同的询问 id，说明这个询问已经找到了答案。这种做法的 id 可以用 `set` 或者 `unordered_set` 维护，相当, 启发式合并的规则就是连通块点的数量加上当前 id 的数量。
2.   可以处理出合并的生成树，即，在并查集中不使用路径压缩（只使用连通块大小的启发式合并），保留原始的路径，这样会得到一棵树，树的根节点是最终集合的代表节点，依次往下。因为保留了合并的路径，所以两个点（也就是两个建筑）对应的 $M$ 值就是树中路径的最小权值。找到树中任意两点路径中权值最小的边可以倍增 lca，也可以直接暴力算，因为这棵树是通过启发式合并构造出来的，所以深度和点的数量是对数关系。

两种做法里面，显然 法 2 比较块

??? Success "参考代码"

    === "C++"
    
        ```解法 1
        #include <algorithm>
        #include <array>
        #include <iostream>
        #include <unordered_set>
        #include <utility>
        #include <vector>
    
        using namespace std;
    
        class DSU
        {
        public:
            explicit DSU(int n, int q) : parent_or_size(n, -1), querys(n), lim(q, -1) {}
    
            void add_query(int u, int v, int id)
            {
                if (u == v)
                    return;
                querys[u].insert(id);
                querys[v].insert(id);
            }
    
            void merge_query(unordered_set<int> &qx, unordered_set<int> &qy, int h)
            {
                for (auto id : qy)
                {
                    auto it = qx.find(id);
                    if (it == qx.end())
                        qx.insert(id);
                    else
                    {
                        qx.erase(it);
                        lim[id] = h;
                    }
                }
            }
    
            int merge(int a, int b, int h)
            {
                int x = leader(a), y = leader(b);
                if (x == y)
                    return x;
                if (-parent_or_size[x] + querys[x].size() < -parent_or_size[y] + querys[y].size())
                    std::swap(x, y);
                merge_query(querys[x], querys[y], h);
                parent_or_size[x] += parent_or_size[y];
                parent_or_size[y] = x;
                querys[y].clear();
                return x;
            }
    
            int leader(int a) { return parent_or_size[a] < 0 ? a : parent_or_size[a] = leader(parent_or_size[a]); }
    
            bool same(int a, int b) { return leader(a) == leader(b); }
    
            int size(int a) { return -parent_or_size[leader(a)]; }
    
        private:
            vector<int> parent_or_size;
            vector<unordered_set<int>> querys;
    
        public:
            vector<int> lim;
        };
    
        int main()
        {
            int h, w;
            cin >> h >> w;
            vector<vector<int>> f(h, vector<int>(w));
            vector<pair<int, int>> buildings(h * w);
            for (int i = 0, t = 0; i < h; i++)
                for (int j = 0; j < w; j++, t++)
                {
                    cin >> f[i][j];
                    buildings[t] = {i, j};
                }
            sort(buildings.begin(), buildings.end(), [&f](pair<int, int> x, pair<int, int> y) -> bool
                 { return f[x.first][x.second] > f[y.first][y.second]; });
            int q;
            cin >> q;
            DSU dsu(h * w, q);
            vector<array<int, 6>> querys(q);
            for (int i = 0; i < q; i++)
            {
                array<int, 6> &qi = querys[i];
                for (auto &x : qi)
                    cin >> x;
                qi[0]--, qi[1]--, qi[3]--, qi[4]--;
                dsu.add_query(qi[0] * w + qi[1], qi[3] * w + qi[4], i);
            }
    
            const int dr[] = {-1, 1, 0, 0};
            const int dc[] = {0, 0, -1, 1};
            auto in_grid = [h, w](int r, int c) -> bool
            { return r >= 0 && r < h && c >= 0 && c < w; };
    
            vector<vector<bool>> vis(h, vector<bool>(w));
            for (auto [r, c] : buildings)
            {
                int h = f[r][c];
                vis[r][c] = true;
                for (int i = 0; i < 4; i++)
                {
                    int nr = r + dr[i], nc = c + dc[i];
                    if (in_grid(nr, nc) && vis[nr][nc])
                        dsu.merge(r * w + c, nr * w + nc, h);
                }
            }
            for (int i = 0; i < q; i++)
            {
                auto [a, b, x, c, d, y] = querys[i];
                if (a == c && b == d)
                    cout << max(x, y) - min(x, y) << endl;
                else
                    cout << x + y - 2 * min({dsu.lim[i], x, y}) << endl;
            }
            return 0;
        }
        ```

        ```解法 2
    	#include <algorithm>
        #include <iostream>
        #include <utility>
        #include <vector>
    
        using namespace std;
    
        struct DSU
        {
            explicit DSU(int n) : parent_or_size(n, -1), cost(n) {}
    
            void merge(int a, int b, int h)
            {
                int x = leader(a), y = leader(b);
                if (x == y)
                    return;
                if (-parent_or_size[x] < -parent_or_size[y])
                    std::swap(x, y);
                parent_or_size[x] += parent_or_size[y];
                parent_or_size[y] = x;
                cost[y] = h;
            }
    
            int leader(int a) const
            {
                while (parent_or_size[a] >= 0)
                    a = parent_or_size[a];
                return a;
            }
    
            vector<int> parent_or_size;
            vector<int> cost;
        };
    
        int main()
        {
            ios::sync_with_stdio(false);
            cin.tie(nullptr);
    
            int h, w;
            cin >> h >> w;
            int len = h * w;
            vector<vector<int>> f(h, vector<int>(w));
            vector<pair<int, int>> buildings;
            buildings.reserve(h * w);
            for (int i = 0; i < h; i++)
                for (int j = 0; j < w; j++)
                {
                    cin >> f[i][j];
                    buildings.push_back({i, j});
                }
            sort(buildings.begin(), buildings.end(), [&f](const pair<int, int> &x, const pair<int, int> &y)
                 { return f[x.first][x.second] > f[y.first][y.second]; });

            auto in_grid = [h, w](int r, int c) -> bool
            { return r >= 0 && r < h && c >= 0 && c < w; };
    
            const int dr[] = {1, 0, -1, 0};

            for (auto [r, c] : buildings)
            {

                for (int i = 0; i < 4; i++)
                {
                    int nr = r + dr[i], nc = c + dc[i];
                    if (in_grid(nr, nc) && f[r][c] <= f[nr][nc])
                    {
                        int v = nr * w + nc;
                        dsu.merge(u, v, f[r][c]);
                    }
                }

                int a, b, y, c, d, z;
                std::cin >> a >> b >> y >> c >> d >> z;
                a--;
                b--;
                c--;
                d--;
    
                int s = a * w + b;
                int t = c * w + d;
    
                for (int x = s; x >= 0; x = dsu.parent_or_size[x])
                    vis[x] = i;
                int lca = t;
                while (vis[lca] != i)
                    lca = dsu.parent_or_size[lca];

                while (s != lca)

                    ans = min(ans, dsu.cost[s]);
                    s = dsu.parent_or_size[s];
                }
                while (t != lca)
                {
                    ans = min(ans, dsu.cost[t]);
                    t = dsu.parent_or_size[t];
                }
    
                ans = y + z - 2 * ans;
        ```
