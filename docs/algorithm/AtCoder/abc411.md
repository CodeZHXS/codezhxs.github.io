## [C - Black Intervals](https://atcoder.jp/contests/abc411/tasks/abc411_c)

???+ Abstract "题目大意"

一排有 $N(1 \le N \le 5 \times 10^{5})$ 个格子，初始时所有格子均为白色。

给你 $Q(1 \le Q \le 5 \times 10^{5})$ 个查询。每个查询会给你一个整数 $A_i$，然后你需要反转第 $A_i$ 个格子的颜色。然后，统计当前所有连续的黑色格子区间的数量。

??? Note "解题思路"

分类讨论题，如果是黑变白：
- 如果左右都是白色，区间数减一。
- 如果当前格子是黑色区间的边界，区间数不变。
- 如果当前格子是黑色区间的内部，区间数加一。

如果是白变黑：
- 如果左右都是白色，区间数加一。
- 如果左边是黑色，右边是白色，区间数不变。
- 如果左右都是黑色，区间数减一。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <vector>

        using namespace std;

        int main()
        {
            int n, q;
            cin >> n >> q;
            vector<bool> black(n + 2);
            int now = 0;
            while(q--)
            {
                int a;
                cin >> a;
                black[a] = !black[a];
                bool l = black[a - 1];
                bool m = black[a];
                bool r = black[a + 1];
                if(m)
                {
                    if(l && r)
                        now--;
                    if(!l && !r)
                        now++;
                }
                else
                {
                    if(l && r)
                        now++;
                    if(!l && !r)
                        now--;
                }
                cout << now << '\n';
            }
            return 0;
        }
        ```

## [D - Conflict 2](https://atcoder.jp/contests/abc411/tasks/abc411_d)

???+ Abstract "题目大意"

你有一台服务器和 $N(1 \le N \le 2 \times 10^{5})$ 台个人电脑（PC）。服务器和每台 PC 各自都持有一个字符串，初始时，这些字符串均为空串。

给你 $Q(1 \le Q \le 2 \times 10^{5})$ 个操作，操作有三种类型：
- `1 p`：将第 $p$ 个 PC 的字符串替换成服务器的字符串。
- `2 p s`：在第 $p$ 个 PC 的字符串末尾追加字符串 $s$。
- `3 p`：将服务器的字符串用第 $p$ 个 PC 的字符串替换。
  
处理完所有操作后，输出最终的服务器字符串。

输入数据保证所有的操作 2 的字符串 $s$ 的长度之和不会超过 $10^{6}$。

??? Note "解题思路"

如果直接在每个服务器维护字符串的值，肯定会 TLE 和 MLE。

采用类似可持久化数据结构的思想，维护一个版本的概念，这样我们会发现操作 1 和操作 3 其实是复制版本，而操作 2 就可以描述为 $(i, s)$， 表示在第 $i$ 个版本的字符串后追加字符串 $s$。

处理完所有的询问之后，再回溯服务器的版本即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <string>
        #include <utility>
        #include <vector>

        using namespace std;

        int main()
        {
            int n, q;
            cin >> n >> q;
            vector<pair<int, string>> ver;
            vector<int> pc(n + 1, -1);
            int server = -1;
            for (int i = 1; i <= q; i++)
            {
                int op, p;
                cin >> op >> p;
                int &v = pc[p];
                if (op == 1)
                    v = server;
                else if (op == 2)
                {
                    string s;
                    cin >> s;
                    ver.emplace_back(v, s);
                    v = ver.size() - 1;
                }
                else
                    server = v;
            }

            auto print_ans = [&ver](auto &&self, int v) -> void
            {
                if (v == -1)
                    return;
                auto [last, s] = ver[v];
                self(self, last);
                cout << s;
            };

            print_ans(print_ans, server);
            return 0;
        }
        ```

## [E - E [max]](https://atcoder.jp/contests/abc411/tasks/abc411_e)

???+ Abstract "题目大意"

有 $N(1 \le N \le 10^{5})$ 个六面骰子，第 $i$ 个骰子的六个面分别写有数字 $A_{i,1}, A_{i,2}, A_{i,3}, A_{i,4}, A_{i,5}, A_{i,6}$。其中 $1 \le A_{i,j} \le 10^{9}$。

现在所有骰子同时被掷出，请你求出所有骰子向上的那面写有的数字的最大值的期望，答案对 $998244353$ 取模。

??? Note "解题思路"

首先对所有 $A_{i, j}$ 离散化，假设离散化之后骰子的序列是 $S = (S_1, S_2, ... S_K)$。定义投掷结果是 $X_1, X_2, ..., X_N$

定义 $P[\max\limits_j X_j=k]$ 表示 $N$ 个骰子的最大值是 $S_k$ 的概率。则所求的答案 $E = \sum\limits_{k=1}^{K} S_k \cdot P[\max\limits_j X_j=k]$。

不过 $P[\max\limits_j X_j=k]$ 并不好直接求。换一种方法，定义 $P[\max\limits_j X_j \le k]$ 表示 $N$ 个骰子的最大值小于等于 $S_k$ 的概率，这样的话 $P[\max\limits_j X_j=k] = P[\max\limits_j X_j \le k] - P[\max\limits_j X_j \le k-1]$。

而 $P[\max\limits_j X_j=k]$ 是很好求，假设第 $i$ 个骰子有 $c_{i, k}$ 个面小于等于 $S_k$，则 $P[\max\limits_j X_j \le k] = \prod\limits_{i=1}^{N} \frac{c_{i, k}}{6}$。

不妨令 $p_k = P[\max\limits_j X_j \le k]$，于是有：
$$
\begin{align*}
E & = \sum\limits_{k=1}^{K} S_k \cdot (P[\max\limits_j X_j \le k] - P[\max\limits_j X_j \le k-1]) \\
  & = \sum\limits_{k=1}^{K} S_k \cdot (p_k - p_{k-1}) \\
  & = S_1p_1 - S_1p_0 + S_2p_2 - S_2p_1 + S_3p_3 - S_3p_2 + ... + S_Kp_K - S_Kp_{K-1} \\
  & = -S_1p_0 - (S_2 - S_1)p_1 + (S_3 - S_2)p_2 - ... - (S_K - S_{K-1})p_{K-1} + S_Kp_K \\
\end{align*}
$$

不妨再假设 $S_0 = 0$，于是 $p_0 = 0$，又因为 $S_k$ 是最大值，所以 $p_K = 1$，因此有：
$$
\begin{align*}
E & = S_K - (S_2 - S_1)p_1 + (S_3 - S_2)p_2 - ... - (S_K - S_{K-1})p_{K-1}\\
  & = S_K - \sum\limits_{k=1}^{K-1} (S_{k+1} - S_k) p_k \\
  & = S_K - \sum\limits_{k=1}^{K-1} (S_{k+1} - S_k) \prod\limits_{i=1}^{N} \frac{c_{i, k}}{6} \\
\end{align*}
$$

显然，$S_k$ 都是常量，只需要考虑如何求出 $\prod\limits_{i=1}^{N} \frac{c_{i, k}}{6}$，分母其实是固定的 $6^N$，只需要考虑分子 $\prod\limits_{i=1}^{N} c_{i, k}$，这就很好做了，可以记录一下每个数字分别出现在哪些骰子上，记录一下每一个骰子有多少面小于等于 $S_k$ 就可以了。这里要注意，如果存在任何一个骰子的 $c_{i, k} = 0$，那么 $\prod\limits_{i=1}^{N} c_{i, k} = 0$，要把这种情况排除掉，具体看代码。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <array>
        #include <atcoder/modint.hpp>
        #include <iostream>
        #include <vector>

        using namespace std;
        using mint = atcoder::modint998244353;

        int main()
        {
            int n;
            cin >> n;
            vector<array<int, 6>> a(n);
            vector<int> s;
            s.reserve(6 * n);
            for (int i = 0; i < n; i++)
                for (auto &x : a[i])
                {
                    cin >> x;
                    s.push_back(x);
                }
            sort(s.begin(), s.end());
            s.erase(unique(s.begin(), s.end()), s.end());
            int len = s.size();
            vector<int> c(n);
            int zero = n;
            vector<vector<int>> ids(len);
            for (int i = 0; i < n; i++)
                for (auto &x : a[i])
                {
                    x = lower_bound(s.begin(), s.end(), x) - s.begin();
                    ids[x].push_back(i);
                }
            mint prod = 1;
            mint ans = 0;
            for (int i = 0; i < len - 1; i++)
            {
                for (auto j : ids[i])
                {
                    if (!c[j])
                        zero--;
                    else
                        prod /= c[j];

                    c[j]++;
                    prod *= c[j];
                }
                ans -= zero ? 0 : prod * (s[i + 1] - s[i]);
            }
            ans /= mint(6).pow(n);
            ans += s[len - 1];
            cout << ans.val() << endl;
            return 0;
        }
        ```

## [F - Contraction](https://atcoder.jp/contests/abc411/tasks/abc411_f)

???+ Abstract "题目大意"

给你一个 $N(2 \le N \le 3 \times 10^{5})$ 个点、$M(1 \le M \le 3 \times 10^{5})$ 条边的无向图 $G_0$，第 $i$ 条边连接 $(U_i, V_i)$ 这两个点。图中有 $N$ 个棋子，初始时，第 $i$ 个棋子放在点 $i$。 

给你 $Q(1 \le Q \le 3 \times 10^{5})$ 个操作。第 $i$ 次操作将给你一条边的编号 $X_i$，然后执行以下操作：

- 如果棋子 $U_{X_i}$ 和 $V_{X_i}$ 在不同点上并且这两个点在 $G$ 中由一条边连接，那么，将 $G$ 中的这条边进行“缩减”得到图 $G'$ 。如果 $G'$ 中存在重边或自环，将重复的边或自环删除。这条边所连接的两个点上面的所有棋子将被移动到“缩减”操作所创建的新点上。然后 $G \leftarrow G'$。
- 如果两个棋子在同一个点上或者它们所在的两个结点之间没有边，不进行操作。

边的缩减是对这条边连接的两个点 $u,v$ 进行合并操作。具体地：
- 创建一个新结点 $w$。
- 对于 $G$ 的每个结点 $x$，如果 $x \neq u$ 且 $x \neq v$，在 $x$ 和 $w$ 之间连边当且仅当 $x$ 在原图中与 $u$ 有连边，或与 $v$ 有连边。
- 删除 $u,v$ 与和它们两个相连的所有边。

每次执行操作后，输出图 $G$ 的边数。

??? Note "解题思路"

棋子其实是用来表明继承关系，意思是说缩后的点 $w$ 既可以认为是 $u$，也可以认为是 $v$（因为这两个点的棋子都移动过来了）。所以后面其实不用考虑棋子的问题。

那么缩点其实就相当于把 $u$ 的边移动给 $v$，为了判断 $u$ 的点被移动到 $v$ 上，可以用并查集，同时每个点维护一个哈希表，记录这个点的邻居有哪些。在去重的时候也能算出图中减少了多少条边。

还需要注意一点就是合并两个点的时候，需要同时考虑集合的大小和哈希表的大小（启发式合并）。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <unordered_set>
        #include <utility>
        #include <vector>

        using namespace std;

        class DSU
        {
        public:
            explicit DSU(int n) : parent_or_size(n, -1), edge(n) {}

            void add(int u, int v)
            {
                edge[u].insert(v);
                edge[v].insert(u);
            }

            int merge(int a, int b)
            {
                int x = leader(a), y = leader(b);
                if (x == y)
                    return 0;
                if (-parent_or_size[x] + edge[x].size() < -parent_or_size[y] + edge[y].size())
                    swap(x, y);
                edge[x].erase(y);
                edge[y].erase(x);
                int cnt = 1;
                for (auto z : edge[y])
                {
                    edge[z].erase(y);
                    auto it = edge[x].find(z);
                    if (it != edge[x].end())
                        cnt++;
                    else
                    {
                        edge[x].insert(z);
                        edge[z].insert(x);
                    }
                }
                parent_or_size[x] += parent_or_size[y];
                parent_or_size[y] = x;
                edge[y].clear();
                return cnt;
            }

            int leader(int a) { return parent_or_size[a] < 0 ? a : parent_or_size[a] = leader(parent_or_size[a]); }

            bool same(int a, int b) { return leader(a) == leader(b); }

            int size(int a) { return -parent_or_size[leader(a)]; }

        private:
            vector<int> parent_or_size;
            vector<unordered_set<int>> edge;
        };

        int main()
        {
            int n, m;
            cin >> n >> m;
            DSU dsu(n + 1);
            vector<pair<int, int>> edge(m);
            for (auto &[u, v] : edge)
            {
                cin >> u >> v;
                dsu.add(u, v);
            }
            int q;
            cin >> q;
            while (q--)
            {
                int x;
                cin >> x;
                x--;
                auto [u, v] = edge[x];
                m -= dsu.merge(u, v);
                cout << m << '\n';
            }
            return 0;
        }
        ```

## [G - Count Cycles](https://atcoder.jp/contests/abc411/tasks/abc411_g)

???+ Abstract "题目大意"

给你一个 $N(2 \le N \le 20)$ 个点、$M(2 \le M \le 2 \times 10^{5})$ 条边的无向图，图中可能有重边，但没有自环。点的编号为 $1,2,\cdots,N$，边的编号为 $1,2,\cdots,M$。第 $i$ 条边连接 $(U_i, V_i)$ 这两个点。

求出图中环的个数，答案对 $998244353$ 取模。

环的个数定义：形式化地，找出边集 $\{e_1, e_2, ..., eK\} \subseteq \{1, 2, ..., M\} (k \ge 2)$ 的个数，满足：
- 存在一个 $(e_1, e_2, ..., e_k)$ 的排列 $(e_1', e_2', ..., e_k')$ 和一个结点序列 $(v_1, v_2, ..., v_k)$，满足：
  - $v_1, v_2, ..., v_k$ 互不相同；
  - $\forall 1 \le i \le k, e_i'$ 连通点 $v_i$ 和点 $v_{(i \mod N) + 1}$。

??? Note "解题思路"

数据范围是 $N \le 20$，考虑状压 $dp$，先考虑一下点集为 $s$ 的环有多少个。发现最难搞的是重复的问题，题目是按边集来考虑环的，但一个环中的任意一个点都可以作为起点走完这个环，就会造成重复计数。所以我们不妨钦定，$s$ 集合中最大的点作为起点，这样还需要考虑每一步的终点，于是就可以定义 $dp[s][j]$ 表示已经访问过的点集为 $s$ 的方案数，且起点是 $s$ 中编号最大的点，终点在点 $j$ 的路径的个数。这个 dp 很好算。

然后考虑如何求答案。我们只考虑了路径，路径是没有点重复的，要形成环，只需要让路径回到起点，定义 $c[i][j]$ 表示点 $i$ 和点 $j$ 之间的边的数量，于是答案就是 $\sum dp[s][j] \times c[j][h(s)]$，其中 $h(s)$ 表示 $s$ 中编号最大的点。

然后还要注意两个问题：
- 对于长度为 $2$ 的环，因为我们不能复用边，所以要特判一下，长度为 $2$ 的环的个数就是 $\sum c[i][j] \times (c[i][j] - 1) / 2$。
- 这个做法会把同一个环算 $2$ 次，即顺时针一次，逆时针也算一次，所以最终的答案要除以 $2$。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <atcoder/modint.hpp>
        #include <bit>
        #include <iostream>
        #include <vector>

        using namespace std;
        using mint = atcoder::modint998244353;

        int main()
        {
            int n, m;
            cin >> n >> m;
            vector<vector<int>> c(n, vector<int>(n));
            while (m--)
            {
                int u, v;
                cin >> u >> v;
                u--, v--;
                c[u][v]++;
                c[v][u]++;
            }
            mint ans = 0;
            for (int i = 0; i < n; i++)
                for (int j = i + 1; j < n; j++)
                    ans += mint(c[i][j]) * (c[i][j] - 1);
            for (int s = 0; s < n; s++)
            {
                int len = 1 << (s + 1);
                vector<vector<mint>> dp(len, vector<mint>(s + 1));
                dp[1 << s][s] = 1;
                for (int bit = 1 << s; bit < len; bit++)
                {
                    for (int i = 0; i <= s; i++)
                    {
                        if ((bit >> i & 1) == 0 || dp[bit][i] == 0)
                            continue;
                        if (popcount((unsigned)bit) >= 3)
                            ans += dp[bit][i] * c[i][s];
                        for (int j = 0; j < s; j++)
                            if ((bit >> j & 1) == 0)
                                dp[bit | 1 << j][j] += dp[bit][i] * c[i][j];
                    }
                }
            }
            ans /= 2;
            cout << ans.val() << endl;
            return 0;
        }
        ```
