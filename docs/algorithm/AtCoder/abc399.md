## [A - Hamming Distance](https://atcoder.jp/contests/abc399/tasks/abc399_a)

???+ Abstract "题目大意"

给你两个等长的字符串 $S$ 和 $T$，求它们的汉明距离，即对应位置上不同字符的个数。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <string>

        using namespace std;

        int main()
        {
            int n;
            cin >> n;
            string s, t;
            cin >> s >> t;
            int ans = 0;
            for (int i = 0; i < n; i++)
                ans += (s[i] != t[i]);
            cout << ans << endl;
            return 0;
        }
        ```

## [B - Ranking with Ties](https://atcoder.jp/contests/abc399/tasks/abc399_b)

???+ Abstract "题目大意"

编号为 $1$ 到 $N$ 的 $N$ 个人参加了一场竞赛，其中第 $i$ 个人的得分为 $P_i$。

本竞赛的排名按照以下流程确定：

1. 准备变量 $r$ 并初始化为 $r=1$。初始时所有人的排名均为未确定状态。
2. 重复以下操作直到所有人的排名确定：
   - 设当前未确定排名的人中最高得分为 $x$，且得分为 $x$ 的人数为 $k$。将所有得分为 $x$ 的 $k$ 人的排名确定为 $r$ 位，然后将 $r$ 增加 $k$。

请输出这 $N$ 个人各自的排名。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <functional>
        #include <iostream>
        #include <map>
        #include <vector>

        using namespace std;

        int main()
        {
            int n;
            cin >> n;
            map<int, vector<int>, greater<int>> s;
            vector<int> rk(n + 1);
            for (int i = 1; i <= n; i++)
            {
                int p;
                cin >> p;
                s[p].push_back(i);
            }
            int r = 1;
            for (auto &[_, v] : s)
            {
                for (auto i : v)
                    rk[i] = r;
                r += v.size();
            }
            for (int i = 1; i <= n; i++)
                cout << rk[i] << endl;
            return 0;
        }
        ```

## [C - Make it Forest](https://atcoder.jp/contests/abc399/tasks/abc399_c)

???+ Abstract "题目大意"

给你一个无向图。问：至少删除多少条边，才能使得图中每个连通块都是森林（即无环图）？

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <vector>

        using namespace std;

        class DSU
        {
        public:
            explicit DSU(int n) : parent_or_size(n, -1) {}

            int merge(int a, int b)
            {
                int x = leader(a), y = leader(b);
                if (x == y)
                    return x;
                if (-parent_or_size[x] < -parent_or_size[y])
                    swap(x, y);
                parent_or_size[x] += parent_or_size[y];
                parent_or_size[y] = x;
                return x;
            }

            int leader(int a) { return parent_or_size[a] < 0 ? a : parent_or_size[a] = leader(parent_or_size[a]); }

            bool same(int a, int b) { return leader(a) == leader(b); }

            int size(int a) { return -parent_or_size[leader(a)]; }

        private:
            vector<int> parent_or_size;
        };

        int main()
        {
            int n, m;
            cin >> n >> m;
            int ans = 0;
            DSU dsu(n + 1);
            while (m--)
            {
                int u, v;
                cin >> u >> v;
                if (dsu.same(u, v))
                    ans++;
                else
                    dsu.merge(u, v);
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [D - Switch Seats](https://atcoder.jp/contests/abc399/tasks/abc399_d)

???+ Abstract "题目大意"

给你一个长度为 $2N$ 的序列 $A = (A_1, A_2, ... A_{2N})$，其中数字 $1, 2, ... N$ 恰好在 $A$ 中出现两次。求出满足以下条件的数对 $(a, b)$ 的数量：
- $1 \leq a < b \leq N$
- 数字 $a$ 在 $A$ 中的两个位置不相邻。
- 数字 $b$ 在 $A$ 中的两个位置不相邻。
- 可以通过执行以下操作（次数不限）使得 $a$ 的两个位置相邻，同时
  $b$ 的两个位置相邻：
  - 选择两个位置 $(i, j)$ 满足 $A_i = a$ 且 $A_j = b$，然后交换 $A_i$ 和 $A_j$。

??? Note "解题思路"

满足条件的的数对，其实只需要交换一次就可以。所以只需要检查每个数字的前一位和后一位就好。用数组映射以下每个数字的另一个配对数字的映射即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <vector>

        using namespace std;

        void solve()
        {
            int n;
            cin >> n;
            vector<int> a(2 * n), pos(2 * n);
            vector<vector<int>> st(n + 1);
            for (int i = 0; i < 2 * n; i++)
            {
                cin >> a[i];
                st[a[i]].push_back(i);
            }
            for (int a = 1; a <= n; a++)
            {
                int i = st[a][0];
                int j = st[a][1];
                pos[i] = j;
                pos[j] = i;
            }
            int ans = 0;
            for (int x1 = 0; x1 < 2 * n; x1++)
            {
                int x2 = pos[x1];
                if (abs(x1 - x2) == 1)
                    continue;
                if (x1)
                {
                    int y1 = x1 - 1, y2 = pos[y1];
                    if (a[x1] < a[y1] && abs(y1 - y2) != 1 && abs(x2 - y2) == 1)
                        ans++;
                }
                if (x1 + 1 < 2 * n)
                {
                    int y1 = x1 + 1, y2 = pos[y1];
                    if (a[x1] < a[y1] && abs(y1 - y2) != 1 && abs(x2 - y2) == 1)
                        ans++;
                }
            }
            cout << ans / 2 << endl;
        }

        int main()
        {
            int T;
            cin >> T;
            while (T--)
                solve();
            return 0;
        }
        ```

## [E - Replace](https://atcoder.jp/contests/abc399/tasks/abc399_e)

???+ Abstract "题目大意"

给你两个长度为 $N(1 \le N \le 2 \times 10 ^ 5)$ 的字符串 $S$ 和 $T$。你可以对字符串 $S$ 执行以下操作任意次：
- 选择两个字符 $a$ 和 $b$，然后将 $S$ 中所有的 $a$ 替换为 $b$。

问：至少需要多少次操作，才能使得 $S$ 和 $T$ 相等？如果无法使得 $S$ 和 $T$ 相等，输出 -1。

??? Note "解题思路"

按照如下方式，建立一个图：

- 如果 $S_i$ 和 $T_i$ 不同，则在图中添加一条边 $S_i \rightarrow T_i$。注意这里是用字符作为点。

先考虑无解的情况：
1. 如果某个点存在 $2$ 条边，就表示需要同时把一种字符替换为两种字符，这显然是无解的。
2. 如果这个有向图一共有 $26$ 个点，且存在环的话，那么答案就无解。

有解的情况，首先考虑无环图的答案，因为是无环图，这其实就是类似反过来的拓扑排序，即出度为 $0$ 的点不动，其他点先替换为出度为 $0$ 的点的字符，以此类推就可以。答案就是图中边的个数。

下面考虑有环图的答案，如果有环的话，需要把环中的某一个点先换成别的字符。然后其他点按照有向无环图，最后再把一开始换掉的点替换成正确的字符。所以如果图中有 $26$ 个点的话是无解的，因为找不到别的临时字符可以替换。

把这两种情况总结，答案就是边的数量加上环的数量。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <array>
        #include <iostream>
        #include <string>
        #include <vector>

        using namespace std;

        const int C = 26;

        class DSU
        {
        public:
            explicit DSU(int n) : parent_or_size(n, -1) {}

            int merge(int a, int b)
            {
                int x = leader(a), y = leader(b);
                if (x == y)
                    return x;
                if (-parent_or_size[x] < -parent_or_size[y])
                    swap(x, y);
                parent_or_size[x] += parent_or_size[y];
                parent_or_size[y] = x;
                return x;
            }

            int leader(int a) { return parent_or_size[a] < 0 ? a : parent_or_size[a] = leader(parent_or_size[a]); }

            bool same(int a, int b) { return leader(a) == leader(b); }

            int size(int a) { return -parent_or_size[leader(a)]; }

            vector<vector<int>> group()
            {
                int n = parent_or_size.size();
                std::vector<int> leader_buf(n), group_size(n);
                for (int i = 0; i < n; i++)
                {
                    leader_buf[i] = leader(i);
                    group_size[leader_buf[i]]++;
                }
                std::vector<std::vector<int>> result(n);
                for (int i = 0; i < n; i++)
                    result[i].reserve(group_size[i]);
                for (int i = 0; i < n; i++)
                    result[leader_buf[i]].push_back(i);
                result.erase(
                    std::remove_if(result.begin(), result.end(),
                                [&](const std::vector<int> &v)
                                { return v.empty(); }),
                    result.end());
                return result;
            }

        private:
            vector<int> parent_or_size;
        };

        int main()
        {
            int n;
            cin >> n;
            array<int, C> edge;
            edge.fill(-1);
            string s, t;
            cin >> s >> t;
            if (s == t)
            {
                cout << 0 << endl;
                return 0;
            }
            for (int i = 0; i < n; i++)
            {
                int u = s[i] - 'a';
                int v = t[i] - 'a';
                if(edge[u] != -1 && edge[u] != v)
                {
                    cout << -1 << endl;
                    return 0;
                }
                edge[u] = v;
            }

            auto is_perm = [](const array<int, C> &edge) -> bool
            {
                array<int, C> temp = edge;
                sort(temp.begin(), temp.end());
                for(int u = 0; u < C; u++)
                    if(temp[u] != u)
                        return false;
                return true;
            };

            if (is_perm(edge))
            {
                cout << -1 << endl;
                return 0;
            }

            DSU dsu(C);
            array<int, C> ind;
            ind.fill(0);

            int ans = 0;
            for(int u = 0; u < C; u++)
            {
                int v = edge[u];
                if(v == -1)
                    continue;
                ind[v]++;
                dsu.merge(u, v);
                if (u != v)
                    ans++;
            }
            vector<vector<int>> groups = dsu.group();
            for (const vector<int> &g : groups)
            {
                bool is_cycle = true;
                for (int i : g)
                {
                    is_cycle &= (ind[i] == 1);
                }
                if (is_cycle && g.size() > 1)
                {
                    ans++;
                }
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [F - Range Power Sum](https://atcoder.jp/contests/abc399/tasks/abc399_f)

???+ Abstract "题目大意"

给你两个正整数 $N(1 \le N \le 2 \times 10^5)$ 和 $K(1\ \le K \le 10)$。同时给你一个长度为 $N$ 的数组 $A = (A_1, A_2, ... A_N)$。求出 $\sum\limits_{1 \le l \le r \le N}(\sum\limits_{l \le i \le r}A_i)^K$。答案对 $998244353$ 取模。

??? Note "解题思路"

先换成前缀和形式，即求 $\sum\limits_{1 \le l \le r \le N}(S_r - S_{l-1})^K$。根据二项式定理，有 $(S_r - S_{l-1})^K = \sum\limits_{j=0}^{K}C_K^j(S_r)^{K-j}(-S_{l-1})^j$，这个式子就很好求了，首先预处理出所有的 $C_K^j$，然后对于一个 $j$，维护对应的前缀 $(-S_{l-1}) ^ j$ 的和。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include "atcoder/modint.hpp"
        #include <iostream>
        #include <vector>

        using namespace std;
        using mint = atcoder::modint998244353;

        int main()
        {
            int n, k;
            cin >> n >> k;
            vector<mint> s(n + 1);
            for (int i = 1; i <= n; i++)
            {
                int x;
                cin >> x;
                s[i] = s[i - 1] + x;
            }
            vector<mint> c(k + 1);
            c[0] = 1;
            for (int i = 1, j = k; i <= k; i++, j--)
                c[i] = c[i - 1] * j / i;
            vector<mint> total(k + 1, 0);
            total[0] = 1;
            mint ans = 0;
            for (int i = 1; i <= n; i++)
            {
                mint sk = 1;
                for (int j = k; j >= 0; j--)
                {
                    ans += c[j] * total[j] * sk;
                    sk *= s[i];
                }
                sk = 1;
                for (int j = 0; j <= k; j++)
                {
                    total[j] += sk;
                    sk *= -s[i];
                }
            }
            cout << ans.val();
            return 0;
        }
        ```
