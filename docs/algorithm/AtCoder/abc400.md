## [B - Sum of Geometric Series](https://atcoder.jp/contests/abc400/tasks/abc400_b)

???+ Abstract "题目大意"

给你两个整数 $N(1 \le N \le 10 ^ 9)$ 和 $M(1 \le M \le 100)$，设 $X = \sum\limits_{i=0}^{M} N^i$。如果 $X \le 10 ^ 9$，输出 $X$ 的值，否则输出 `inf`。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>

        using namespace std;
        using LL = long long;

        const LL LIM = 1E9;

        int main()
        {
            LL n, m;
            cin >> n >> m;
            LL now = 1, sum = 0;
            for (int i = 0; i <= m; i++)
            {
                sum += now;
                if (sum > LIM)
                {
                    cout << "inf" << endl;
                    return 0;
                }
                now *= n;
            }
            cout << sum << endl;
            return 0;
        }
        ```

## [C - 2^a b^2](https://atcoder.jp/contests/abc400/tasks/abc400_c)

???+ Abstract "题目大意"

一个数字 $X$ 如果满足以下条件，就称这个数字是好数：
- 存在正整数 $a$ 和 $b$，使得 $X = 2^a \times b^2$。

给你一个整数 $N(1 \le N \le 10^{18})$，求出 $1$ 到 $N$ 中有多少个好数。

??? Note "解题思路"

不妨枚举 $a$，对于一个 $a$，还有 $\frac{N}{2^a}$ 个完全平方数，也就是有 $\frac{N}{2^a}$ 个符合条件的 $b$。但是这样可能会算重，即 $2^ab^2 = 2^xy^2$。

观察发现，$2^2$ 也是一个平方数，所以有 $2^3b^2 = 2(2b)^2$，所以 $a = 1$ 已经代表了所有 $a$ 是奇数的情况。$a = 2$ 也代表了所有 $a$ 是偶数的情况。

所以只需要求出 $\lfloor\frac{N}{2}\rfloor + \lfloor\frac{N}{4}\rfloor$ 即可，注意使用 `sqrtl` 来计算平方根。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <cmath>
        #include <iostream>

        using namespace std;
        using LL = long long;

        int main()
        {
            LL x;
            cin >> x;
            LL ans1 = sqrtl(x / 2);
            LL ans2 = sqrtl(x / 4);
            cout << ans1 + ans2 << endl;
            return 0;
        }
        ```

## [D - Takahashi the Wall Breaker](https://atcoder.jp/contests/abc400/tasks/abc400_d)

???+ Abstract "题目大意"

给你一个 $H \times W(1 \le H, W \le 1000)$ 的二维网格，每个格子可能是 `.` 表示道路，也可能是 `#` 表示障碍物。你的起点是 $(A, B)$，终点是 $(C, D)$。你可以执行以下操作：

- 移动到上下左右相邻的格子，前提是那个格子是道路。
- 选择上下左右的其中一个方向，使用一个“前踢”，将这个方向上前 $1$ 格和前 $2$ 格的障碍物破坏掉（如果有的话），然后这个格子不再有障碍物，变成道路。

问：如何使用最少的“前踢”次数从起点走到终点？

??? Note "解题思路"

变体的 bfs，直接移动的权值是 $0$，使用“前踢”并移动到对应的格子的权值就是 $1$，把队列换成双端队列即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <deque>
        #include <iostream>
        #include <limits>
        #include <string>
        #include <utility>
        #include <vector>

        using namespace std;

        const int dr[] = {-1, 1, 0, 0};
        const int dc[] = {0, 0, -1, 1};

        int main()
        {
            int h, w;
            cin >> h >> w;
            vector<string> g(h);
            for (auto &s : g)
                cin >> s;
            int a, b, c, d;
            cin >> a >> b >> c >> d;
            a--, b--, c--, d--;
            vector<vector<int>> dis(h, vector<int>(w, numeric_limits<int>::max()));
            dis[a][b] = 0;
            deque<pair<int, int>> deq;

            auto in_lim = [h, w](int r, int c) -> bool
            { return r >= 0 && r < h && c >= 0 && c < w; };

            deq.emplace_back(a, b);
            while (!deq.empty())
            {
                auto [r, c] = deq.front();
                deq.pop_front();
                int d = dis[r][c];
                for (int i = 0; i < 4; i++)
                {
                    int nr = r + dr[i];
                    int nc = c + dc[i];
                    if (!in_lim(nr, nc) || g[nr][nc] == '#')
                        continue;
                    if (d < dis[nr][nc])
                    {
                        dis[nr][nc] = d;
                        deq.emplace_front(nr, nc);
                    }
                }
                for (int i = 0; i < 4; i++)
                {
                    for (int j = 1; j <= 2; j++)
                    {
                        int nr = r + dr[i] * j;
                        int nc = c + dc[i] * j;
                        if (!in_lim(nr, nc))
                            continue;
                        if (d + 1 < dis[nr][nc])
                        {
                            dis[nr][nc] = d + 1;
                            deq.emplace_back(nr, nc);
                        }
                    }
                }
            }
            cout << dis[c][d] << endl;
            return 0;
        }
        ```

## [E - Ringo's Favorite Numbers 3](https://atcoder.jp/contests/abc400/tasks/abc400_e)

???+ Abstract "题目大意"

一个数字 $N$ 如果满足以下条件，就称这个数字是好数：
- $N$ 恰好有 $2$ 个不同的质因数。
- 将 $N$ 质因数分解成 $N = p_1^{c_1} p_2^{c_2}$ 的形式后，$c_1$ 和 $c_2$ 都是偶数。

给你 $Q(1 \le Q \le 2 \times 10^5)$ 个询问，每个询问给你一个整数 $A(36 \le A \le 10 ^ {12})$，你需要回答在不超过 $A$ 的最大的好数是多少。

??? Note "解题思路"

因为 $c_1$ 和 $c_2$ 都是偶数，所以可以将 $N$ 写成 $N = p_1^{2a} p_2^{2b} = (p_1^a p_2^b)^2$ 的形式。这样的话只需要考虑其平方根，而 $\sqrt A \le 10^6$，接下来只需要保证恰好有 $2$ 个不同的质因数即可，在 $10^6$ 的范围内做一次埃氏筛，记录每个数字被质数标记的次数，次数为 $2$ 的数字取出来即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <cmath>
        #include <iostream>
        #include <set>
        #include <vector>

        using namespace std;
        using LL = long long;

        const int MAXA = 1E6;

        set<LL> filter(int n)
        {
            vector<int> cnt(n + 1);
            for (int i = 2; i <= n; i++)
            {
                if (!cnt[i])
                {
                    for (int j = i; j <= n; j += i)
                        cnt[j]++;
                }
            }
            set<LL> ans;
            for (int i = 2; i <= n; i++)
                if (cnt[i] == 2)
                    ans.insert(i);
            return ans;
        }

        int main()
        {
            set<LL> num = filter(MAXA);
            int q;
            cin >> q;
            while (q--)
            {
                LL x;
                cin >> x;
                x = sqrtl(x);
                x = *(--num.upper_bound(x));
                cout << x * x << endl;
            }
            return 0;
        }
        ```

## [F - Happy Birthday! 3](https://atcoder.jp/contests/abc400/tasks/abc400_f)

???+ Abstract "题目大意"

有 $N(1 \le N \le 400)$ 块蛋糕，编号为 $1$ 到 $N$，这 $N$ 块蛋糕组成一个环，第 $i$ 块蛋糕的（顺时针方向的）下一块蛋糕是第 $(i + 1)$ 块蛋糕（$i = N$ 时，下一块蛋糕是第 $1$ 块蛋糕）。

初始的时候，所有的蛋糕的颜色都为 $0$。

你可以执行以下操作任意次：
- 选择整数 $a, b$ 和 $c$ 满足 $1 \le a, b, c \le N$， 从第 $a$ 块蛋糕开始，顺时针方向连续取 $b$ 块蛋糕，将它们的颜色都变成 $c$。这个操作的费用是 $b + X_c$。

你的目标是让第 $i$ 块蛋糕的颜色为 $C_i(1 \le C_i \le N)$。问：至少需要多少费用，才能达到这个目标？

??? Note "解题思路"

可以推理出两个性质：
- 在某一次操作 $(a, b, c)$ 中，第 $a$ 和 第 $a+b-1$ 块蛋糕的目标颜色一定是 $c$。因为如果不是 $c$ 的话，就没有必要覆盖到这两块蛋糕，区间缩小开销会更小。
- 任意两次区间操作 $[l_1, r_1]$ 和 $[l_2, r_2]$，不会存在部分相交的情况。例如 $[1, 10]$ 和 $[5, 15]$，第一个区间操作的 $[5, 10]$ 的部分完全可以砍掉，结果会更好。所以任意两个区间操作，要么一个包含另一个，要么完全不相交。

处理环的问题可以将原序列扩展成 $2$ 倍，然后枚举环的断开点（因为根据第二个性质，第一次操作之后相当于给这个环剪开成两段了）。剩下的就是区间 DP 了。

处理区间 $[l, r]$ 时，考虑第 $l$ 块蛋糕是如何染色的，有两种情况：
- 第 $l$ 块蛋糕是单独染色染色，那么 $dp[l][r] = dp[l+1][r] + 1 + X_{C_l}$
- 第 $l$ 块蛋糕是区间染色的，因为性质 1 的存在，那么第 $l$ 块蛋糕一定是在右侧的某一次区间染色中扩展而来，枚举和他相同颜色的位置 $i$，那么有 $dp[l][r] = dp[l+1][i] + dp[i][r] + (i - l)$，这里不需要计算 $X_{C_l}$，因为 $X_{C_l}$ 已经在 $dp[i][r]$ 中计算过了，只是顺手在染色到 $i$ 的时候把 $l$ 也染色了。

显然转移是 $O(N)$ 的，总的复杂度是 $O(N^3)$。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <limits>
        #include <vector>

        using namespace std;
        using LL = long long;

        int main()
        {
            int n;
            cin >> n;
            int len = 2 * n;
            vector<int> c(len + 1), x(n + 1);
            for (int i = 0; i < n; i++)
            {
                cin >> c[i];
                c[i + n] = c[i];
            }
            for (int i = 1; i <= n; i++)
                cin >> x[i];
            vector<vector<LL>> dp(len + 1, vector<LL>(len + 1));
            for (int k = 1; k <= n; k++)
            {
                for (int l = 0, r = k; r <= len; l++, r++)
                {
                    dp[l][r] = dp[l + 1][r] + 1 + x[c[l]];
                    for (int i = l + 1; i < r; i++)
                        if (c[i] == c[l])
                            dp[l][r] = min(dp[l][r], dp[l + 1][i] + i - l + dp[i][r]);
                }
            }
            LL ans = numeric_limits<LL>::max();
            for (int i = 0; i < n; i++)
                ans = min(ans, dp[i][i + n]);
            cout << ans << endl;
            return 0;
        }
        ```
