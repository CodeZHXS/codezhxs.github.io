## [A - Strictly Increasing?](https://atcoder.jp/contests/abc395/tasks/abc395_a)

???+ Abstract "题目大意"

给你一个长度为 $N$ 的序列 $A = (A_1, A_2, ..., A_N)$，判断这个序列是否严格单调递增。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <vector>
    
        using namespace std;
    
        int main()
        {
            int n;
            cin >> n;
            vector<int> a(n);
            for (int i = 0; i < n; i++)
                cin >> a[i];
            for (int i = 1; i < n; i++)
                if (a[i] <= a[i - 1])
                {
                    cout << "No" << endl;
                    return 0;
                }
            cout << "Yes" << endl;
            return 0;
        }
        ```

## [B - Make Target](https://atcoder.jp/contests/abc395/tasks/abc395_b)

???+ Abstract "题目大意"

给你一个整数 $N$，打印一个 $N \times N$ 的如下图形：

```
###########
#.........#
#.#######.#
#.#.....#.#
#.#.###.#.#
#.#.#.#.#.#
#.#.###.#.#
#.#.....#.#
#.#######.#
#.........#
###########
```

备注：最外圈必须是 `#`

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <string>
        #include <vector>
    
        using namespace std;
    
        int main()
        {
            int n;
            cin >> n;
            vector<string> g(n, string(n, '.'));
            for(int t = 0; t < n; t += 2)
            {
                for(int i = t; i < n - t; i++)
                {
                    g[t][i] = g[n-t-1][i] = '#';
                    g[i][t] = g[i][n-t-1] = '#';
                }
            }
            for(auto &s : g)
                cout << s << endl;
            return 0;
        }
        ```

## [C - Shortest Duplicate Subarray](https://atcoder.jp/contests/abc395/tasks/abc395_c)

???+ Abstract "题目大意"

给你一个长度为 $N(1 \le N \le 2 \times 10 ^ 5)$ 的数组 $A = (A_1, A_2, ..., A_N)$，判断 $A$ 中是否存在（连续的）子数组，其中至少有一个数字重复出现了两次。若不存在这样的子数组输出 `-1`，否则，输出最短的满足条件的子数组长度。

??? Note "解题思路"

双指针维护滑动窗口就可以。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <unordered_set>
        #include <vector>
    
        using namespace std;
    
        int main()
        {
            int n;
            cin >> n;
            vector<int> a(n);
            unordered_set<int> vis;
            int l = 0;
            int ans = n + 1;
            for(int i = 0; i < n; i++)
            {
                cin >> a[i];
                if(!vis.count(a[i]))
                    vis.insert(a[i]);
                else
                {
                    while(a[i] != a[l])
                        vis.erase(a[l++]);
                    ans = min(ans, i - l + 1);
                    l++;
                }
            }
            if(ans == n + 1)
                ans = -1;
            cout << ans << endl;
            return 0;
        }
        ```

## [D - Pigeon Swap](https://atcoder.jp/contests/abc395/tasks/abc395_d)

???+ Abstract "题目大意"

有 $N(1 \le N \le 10 ^ 6)$ 个鸽子和 $N$ 个巢，初始的时候，第 $i$ 只鸽子在第 $i$ 个巢。

有 $Q(1 \le Q \le 3 \times 10 ^ 5)$ 个询问：

-   `1 a b`：将第 $a$ 只鸽子移动到第 $b$ 个巢中。
-   `2 a b`：将第 $a$ 个巢和第 $b$ 个巢的鸽子互相交换。
-   `3 a`：输出第 $a$ 个鸽子在第几个巢。

??? Note "解题思路"

比较难办的其实是操作 2，但其实可以做一个巢双向映射，这样就无需移动所有的鸽子。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <vector>
    
        using namespace std;
    
        int main()
        {
            int n, q;
            cin >> n >> q;
            vector<int> p(n + 1), pre(n + 1), nex(n + 1);
            for (int i = 1; i <= n; i++)
                p[i] = pre[i] = nex[i] = i;
            while (q--)
            {
                int op, a, b;
                cin >> op >> a;
                if (op == 1)
                {
                    cin >> b;
                    p[a] = pre[b];
                }
                else if (op == 2)
                {
                    cin >> b;
                    int pre_a = pre[a];
                    int pre_b = pre[b];
    
                    nex[pre_a] = b;
                    pre[b] = pre_a;
                    nex[pre_b] = a;
                    pre[a] = pre_b;
                }
                else
                    cout << nex[p[a]] << endl;
            }
            return 0;
        }
        ```

## [E - Flip Edge](https://atcoder.jp/contests/abc395/tasks/abc395_e)

???+ Abstract "题目大意"

给你一个 $N(2 \le N \le 2 \times 10 ^ 5)$ 个点 $M(1 \le M \le 2 \times 10 ^ 5)$ 的有向图。初始的时候你在点 $1$，你可以重复执行以下操作：

-   执行以下任意一种操作：
    -   假设你当前在点 $u$，如果存在一条从 $u$ 到 $v$ 的边，你可以移动到点 $v$。这种操作的花费是 $1$。
    -   反转所有有向边的方向。这种操作的花费是 $X(1 \le X \le 2 \times 10 ^ 5)$。

你的目的地是 $N$。输入数据保证可以通过有限次操作到达 $N$。问：到达 $N$ 的最小花费是多少？

??? Note "解题思路"

分层图最短路板子题。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <functional>
        #include <iostream>
        #include <limits>
        #include <queue>
        #include <utility>
        #include <vector>
    
        using namespace std;
        using LL = long long;
    
        struct Node
        {
            int u;
            LL dis;
            bool operator > (const Node &other) const {return dis > other.dis;};
        };
    
        int main()
        {
            int n, m, x;
            cin >> n >> m >> x;
            vector<LL> dis(2 * n + 1, numeric_limits<LL>::max() / 2);
            vector<vector<pair<int, int>>> edge(2 * n + 1);
            while(m--)
            {
                int u, v;
                cin >> u >> v;
                edge[u].push_back({v, 1});
                edge[n + v].push_back({n + u, 1});
            }
            for(int u = 1; u <= n; u++)
            {
                edge[u].push_back({n + u, x});
                edge[n + u].push_back({u, x});
            }
    
            priority_queue<Node, vector<Node>, greater<Node>> heap;
            heap.push({1, 0});
            dis[1] = 0;
            while(!heap.empty())
            {
                auto [u, d] = heap.top();
                heap.pop();
                if(dis[u] > d)
                    continue;
                for(auto [v, w] : edge[u])
                {
                    if(d + w < dis[v])
                    {
                        dis[v] = d + w;
                        heap.push({v, dis[v]});
                    }
                }
            }
            cout << min(dis[n], dis[2 * n]) << endl;
            return 0;
        }
        ```

## [F - Smooth Occlusion](https://atcoder.jp/contests/abc395/tasks/abc395_f)

???+ Abstract "题目大意"

有 $2N(2 \le N \le 2 \times 10 ^ 5)$ 个牙，上层牙和下层牙各有 $N$ 个。第 $i$ 个上层牙的长度是 $U_i(1 \le U_i \le 10 ^ 9)$，第 $i$ 个下层牙的长度是 $D_i(1 \le U_i \le 10 ^ 9)$。

如果这 $2N$ 个牙满足以下所有条件，就称这是“好牙”：

-   存在一个整数 $H$，使得对于任意的 $1 \le i \le N$，都有 $U_i + D_i = H$。
-   对于任意的 $1 \le i < N$，都有 $|U_i - U_{i+1}| \le X$。

你可以重复执行以下操作：

-   花费 $1$ 元，将任意一颗牙的长度减少 $1$。长度为 $0$ 的牙不能再减少。

问：为了使这 $2N$ 个牙成为“好牙”，至少需要花费多少元？

??? Note "解题思路"

无论如何，$|U_i - U_{i+1}| \le X$ 是一定需要满足的，所以我们可以先做一次处理，把所有的 $U_i$ 都满足这个条件。由于我们只能让牙的长度减小，所以如果有两颗相邻的牙不满足这个条件，一定是减小更长的牙。不难想到，维护一个小顶堆（懒删除），从小到大确定每一颗 $U_i$ 的最终长度即可，确定了 $U_i$ 的长度之后，尝试更新 $U_{i-1}$ 和 $U_{i+1}$。这个操作的时间复杂度是 $O(n\log n)$，可以得到上层牙的最小操作次数。

接下来满足条件 1，这时候类似一种短板效应，最终 $H$ 的值一定是 $H = \min\{U_i+D_i\}$，找出来 $H$ 的值，然后把多出来的部分砍掉就好了，因为 $U_i$ 需要满足条件 2，所以实际是优先砍掉下层的牙，这里可以证明，如果优先砍下层的牙，最终仍然会满足条件 2。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <functional>
        #include <iostream>
        #include <queue>
        #include <utility>
        #include <vector>
    
        using namespace std;
        using LL = long long;
    
        int main()
        {
            int n, x;
            cin >> n >> x;
            vector<int> u(n), d(n);
            for (int i = 0; i < n; i++)
                cin >> u[i] >> d[i];
            priority_queue<pair<int, int>, vector<pair<int, int>>, greater<>> heap;
            for (int i = 0; i < n; i++)
                heap.push({u[i], i});
            LL ans = 0;
            while (!heap.empty())
            {
                auto [ui, i] = heap.top();
                heap.pop();
                if (ui != u[i])
                    continue;
                if (i - 1 >= 0 && u[i - 1] - u[i] > x)
                {
                    ans += u[i - 1] - u[i] - x;
                    u[i - 1] = u[i] + x;
                    heap.push({u[i - 1], i - 1});
                }
                if (i + 1 < n && u[i + 1] - u[i] > x)
                {
                    ans += u[i + 1] - u[i] - x;
                    u[i + 1] = u[i] + x;
                    heap.push({u[i + 1], i + 1});
                }
            }
            int m = u[0] + d[0];
            for (int i = 1; i < n; i++)
                m = min(m, u[i] + d[i]);
            for (int i = 0; i < n; i++)
                ans += u[i] + d[i] - m;
            cout << ans << endl;
            return 0;
        }
        ```
