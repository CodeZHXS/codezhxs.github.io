## [A - Poisonous Oyster](https://atcoder.jp/contests/abc393/tasks/abc393_a)

???+ Abstract "题目大意"

有四种牡蛎 $1,2,3,4$。其中恰好有一种牡蛎被食用后会导致腹泻，其余种类的牡蛎食用后不会引发问题。

高桥君食用了牡蛎 $1,2$，青木君食用了牡蛎 $1,3$。两人是否因食用而腹泻的信息通过两个字符串 *S*1,*S*2 给出。具体来说，当 $S1=$ `sick` 时表示高桥君腹泻，$S1=$ `fine` 时表示高桥君未腹泻。同理，$S2=$ `sick` 时表示青木君腹泻，$S2=$ `fine` 时表示青木君未腹泻。

请根据给定的信息，确定导致腹泻的牡蛎种类。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
    
        using namespace std;
    
        int main()
        {
            string s1, s2;
            cin >> s1 >> s2;
            if (s1 == "sick")
            {
                if (s2 == "sick")
                    cout << 1 << endl;
                else
                    cout << 2 << endl;
            }
            else
            {
                if (s2 == "sick")
                    cout << 3 << endl;
                else
                    cout << 4 << endl;
            }
            return 0;
        }
        ```

## [B - A..B..C](https://atcoder.jp/contests/abc393/tasks/abc393_b)

???+ Abstract "题目大意"

给你一个字符串 $S$，计算 $S$ 中 `A`, `B`, `C` 按此顺序等间距排列的位置数量。

换言之，找出满足以下所有条件的三元组 $(i,j,k)$ 的数量。其中 $|S|$ 表示字符串 $S$ 的长度，$S_x$ 表示字符串 $S$ 的第 $x$ 个字符。

-   $1 \le i < j < k \le |S|$
-   $j - i = k - j$
-   $S_i = $ `A`
-   $S_j$ = `B`
-   $S_k$ = `C`

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
    
        using namespace std;
    
        int main()
        {
            string s;
            cin >> s;
            int n = s.size();
            int ans = 0;
            for (int i = 0; i < n; i++)
                for (int j = i + 1, k = j + 1; k < n; j++, k += 2)
                    if (s[i] == 'A' && s[j] == 'B' && s[k] == 'C')
                        ans++;
            cout << ans << endl;
            return 0;
        }
        ```

## [C - Make it Simple](https://atcoder.jp/contests/abc393/tasks/abc393_c)

???+ Abstract "题目大意"

给你一个无向图，至少要从图中移除多少条边，才能让这个图变成简单图。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <set>
        #include <utility>
    
        using namespace std;
    
        int main()
        {
            int n, m;
            cin >> n >> m;
            int ans = 0;
            set<pair<int, int>> vis;
            while (m--)
            {
                int u, v;
                cin >> u >> v;
                if (u == v || vis.count({u, v}) || vis.count({v, u}))
                    ans++;
                else
                    vis.insert({u, v});
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [D - Swap to Gather](https://atcoder.jp/contests/abc393/tasks/abc393_d)

???+ Abstract "题目大意"

给你一个长度为 $N(2 \le N \le 5 \times 10 ^ 5)$ 的 $01$ 字符串 $S$，$S$ 中至少有一个 $1$。你可以执行以下操作任意次：

-   选择 $S$ 中两个相邻的字符并交换两者。

问：至少要操作多少次，才能让 $S$ 中所有的字符 `1` 聚集在一起，成为一段连续的 `1` 区间？

??? Note "解题思路"

答案一定是某一个位置的 `1` 不用动，然后将所有其他的 `1` 聚拢过来。维护所有 `1` 初始坐标以及 `1` 的个数的前缀和，假设选定了 $i$ 不动，$i$ 之前有 $L[i]$ 个 `1`，$i$ 之后有 $R[i]$ 个 $1$。

因为 $i$ 之前有 $L[i]$ 个 `1`，所以最终的坐标和应该是 $(i-1)L[i] - \frac{L[i](L[i]-1)}{2}$，每一次操作会更加接近这个坐标和，所以直接用最终坐标和，减去当前的坐标和就是操作的次数。右侧同理。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <limits>
        #include <string>
        #include <vector>
    
        using namespace std;
        using LL = long long;
    
        int main()
        {
            int n;
            string s;
            cin >> n >> s;
            vector<int> a(n + 1), b(n + 1);
            for (int i = 1; i <= n; i++)
            {
                int ch = s[i - 1] - '0';
                if (ch)
                {
                    a[i] = i;
                    b[i] = 1;
                }
            }
            auto prefix = [n](const vector<int> &a) -> vector<LL>
            {
                vector<LL> sum(n + 1);
                for (int i = 1; i <= n; i++)
                    sum[i] = sum[i - 1] + a[i];
                return sum;
            };
    
            vector<LL> sum = prefix(a);
            vector<LL> cnt = prefix(b);
            LL ans = numeric_limits<LL>::max();
            for (int i = 1; i <= n; i++)
            {
                if(s[i-1] == '0')
                    continue;
                LL total = 0;
                LL lcnt = cnt[i - 1];
                LL lsum = sum[i - 1];
                total += i * lcnt - lsum - (lcnt + 1) * lcnt / 2;
                LL rcnt = cnt[n] - cnt[i];
                LL rsum = sum[n] - sum[i];
                total += rsum - i * rcnt - (rcnt + 1) * rcnt / 2;
                ans = min(ans, total);
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [E - GCD of Subset](https://atcoder.jp/contests/abc393/tasks/abc393_e)

???+ Abstract "题目大意"

给你 $N(1 \le N \le 1.2 \times 10^6)$ 个数 $A = (A_1, A_2, ..., A_N)$，其中 $1 \le A_i \le 10^6$，然后给你一个整数 $K(1 \le K \le N)$

对于 $i = 1, 2, ..., N$，回答以下问题：

-   从 $A$ 中挑选 $K$ 个数，挑选的数字必须包含 $A_i$，你需要最大化这 $K$ 个数字的 GCD。

??? Note "解题思路"

因为要计算出 $N$ 个答案的值，直接枚举必定超时。由于 $1 \le A_i \le 10^6$，考虑枚举出这个值域中所有的答案。

设 $cnt[i]$ 表示 $A$ 中数字 $i$ 出现的次数。对于数字 $x$，如果 $A$ 中存在至少 $K$ 个 $x$ 的倍数，则选择这 $K$ 个因数，GCD 之后的答案就一定大于等于 $x$（也可能更大，但保底会得到 $x$）。

因此设 $mul[i]$ 表示 $A$ 中有多少个 $i$ 的倍数，得到所有 $mul[i]$ 只需要按照调和级数的方式，枚举每一个数字 $j$ 的倍数 $i = j, 2j, 3j,...$ ，给 $mul[i] += cnt[j]$ 即可。

接下来考虑 “挑选的数字必须包含 $A_i$” 这个条件，设 $ans[i]$ 表示必须包含 $i$ 的情况下，挑选 $K$ 个数字能得到的最大的 GCD 值，如果针对 $i$ 分解出所有的因数，再统计的话时间复杂度会超。还是考虑用调和级数的方式，将 $mul[j]$ 的值更新到 $ans[i]$ 中。如果 $mul[j] \ge K$，则枚举每一个 $j$ 的倍数 $i = j, 2j, 3j,...$ ，更新 $ans[i] = \max(ans[i], j)$ 即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <iostream>
        #include <vector>
    
        using namespace std;
    
        int main()
        {
            int n, k;
            cin >> n >> k;
            vector<int> a(n);
            for(auto &x : a)
                cin >> x;
            int m = *max_element(a.begin(), a.end());
            vector<int> cnt(m + 1), mul(m + 1), ans(m + 1);
            for(auto x : a)
                cnt[x]++;
            for(int i = 1; i <= m; i++)
                for(int j = i; j <= m; j += i)
                    mul[i] += cnt[j];
            for(int i = 1; i <= m; i++)
            {
                if(mul[i] < k)
                    continue;
                for(int j = i; j <= m; j += i)
                    ans[j] = max(ans[j], i);
            }
            for(auto x : a)
                cout << ans[x] << endl;
            return 0;
        }
        ```

## [F - Prefix LIS Query](https://atcoder.jp/contests/abc393/tasks/abc393_f)

???+ Abstract "题目大意"

给你一个长度为 $N(1 \le N \le 2 \times 10 ^ 5)$ 的数组 $A = (A_1, A_2, ..., A_N)$，其中 $1 \le A_i \le 10 ^ 9$。有 $Q(1 \le Q \le 2 \times 10 ^ 5)$ 个询问，每个询问，每个询问给你两个数字 $R_i(1 \le R_i \le N)$ 和 $X_i(\min\{A_1, A_2, ..., A_N\} \le X_i \le 10 ^ 9)$，你需要在 $(A_1, A_2, ...A_{R_i})$ 中，找到最长的严格单调递增的子序列，且子序列的所有数字都不超过 $X_i$，问：满足这样条件的子序列的长度最大值是？

??? Note "解题思路"

考虑如果忽略掉 $R_i$ 这个条件，也就是认为所有的 $R_i = N$，如何求出每个询问的答案。只需要在原始数组上做一次常规的求 LCS 操作，最后会得到一个 $st$ 数组，$st[i]$ 表示所有长度为 $i$ 的 LCS 中最后一个元素的最小值。这样针对每一个 $X_i$，只需要在 $st$ 数组中二分就能得到最长的 LCS 的长度。

下面考虑加入 $R_i$ 条件，考虑将所有的询问离线并按照 $R_i$ 排序，然后分阶段的完成 LCS 操作，假设当前已经加入了 $A_{R_i}$，就开始处理 $R_i$ 对应的询问。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <iostream>
        #include <utility>
        #include <vector>
    
        using namespace std;
    
        int main()
        {
            int n, q;
            cin >> n >> q;
            vector<int> a(n + 1), ans(q);
            vector<vector<pair<int, int>>> qs(n + 1);
            for (int i = 1; i <= n; i++)
                cin >> a[i];
            for(int i = 0; i < q; i++)
            {
                int r, x;
                cin >> r >> x;
                qs[r].push_back({x, i});
            }
            vector<int> st = {0};
            for (int i = 1; i <= n; i++)
            {
                if (a[i] > st.back())
                    st.push_back(a[i]);
                else
                    *lower_bound(st.begin(), st.end(), a[i]) = a[i];
                for(auto [x, id] : qs[i])
                    ans[id] = upper_bound(st.begin(), st.end(), x) - st.begin() - 1;
            }
            for(auto x : ans)
                cout << x << endl;
            return 0;
        }
        ```
