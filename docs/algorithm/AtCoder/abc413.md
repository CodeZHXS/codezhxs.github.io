## [B - cat 2](https://atcoder.jp/contests/abc413/tasks/abc413_b)

???+ Abstract "题目大意"

给你 $N$ 个字符串 $S_1, S_2, \ldots, S_N$。你可以进行如下操作一次：

- 选择两个不同的整数 $i,j (1 \le i, j \le N)$，将 $S_i$ 和 $S_j$
  按顺序连接起来。

求出通过上述操作能够得到多少种不同的字符串。

需要注意的是，即使选择的 $(i,j)$ 不同，只要连接后的字符串相同，也只算作一种。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <string>
        #include <unordered_set>
        #include <vector>

        using namespace std;

        int main()
        {
            int n;
            cin >> n;
            vector<string> s(n);
            for (auto &si : s)
                cin >> si;
            unordered_set<string> vis;
            for (int i = 0; i < n; i++)
                for (int j = 0; j < n; j++)
                {
                    if (i == j)
                        continue;
                    vis.insert(s[i] + s[j]);
                }
            cout << vis.size() << endl;
            return 0;
        }
        ```

## [C - Large Queue](https://atcoder.jp/contests/abc413/tasks/abc413_c)

???+ Abstract "题目大意"

有一个空的整数序列 $A=()$。给你 $Q(1 \le Q \le 2 \times 10^{5})$ 个操作，操作有以下两种类型：

- `1 c x`: 向 $A$ 的末尾添加 $c(1 \le c \le 10^{9})$ 个 $x(1 \le x \le 10^{9})$。
- `2 k`: 删除 $A$ 的前 $k$ 个元素，并输出被删除的 $k$ 个整数的总和。保证此时 $k$ 不超过当前 $A$ 的长度。

??? Note "解题思路"

用一个 `deque<pair<int, int>>` 模拟就好，`pair<int, int>` 分别表示数字和剩余的数量。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <deque>
        #include <iostream>
        #include <utility>

        using namespace std;
        using LL = long long;

        int main()
        {
            int q;
            cin >> q;
            deque<pair<int, int>> deq;
            while (q--)
            {
                int op;
                cin >> op;
                if (op == 1)
                {
                    int c, x;
                    cin >> c >> x;
                    deq.push_back({c, x});
                }
                else
                {
                    int k;
                    cin >> k;
                    LL ans = 0;
                    while (k)
                    {
                        auto [c, x] = deq.front();
                        deq.pop_front();
                        LL t = min(c, k);
                        k -= t;
                        ans += t * x;
                        if (c > t)
                            deq.push_front({c - t, x});
                    }
                    cout << ans << '\n';
                }
            }
            return 0;
        }
        ```

## [D - Make Geometric Sequence](https://atcoder.jp/contests/abc413/tasks/abc413_d)

???+ Abstract "题目大意"

给你一个长度为 $N(2 \le N \le 2 \times 10^{5})$ 的整数序列 $A=(A_1, A_2, \ldots, A_N)$。其中 $-10^{9} \le A \le 10^{9}$ 且 $A_i \neq 0$。

判断是否存在一种方式可以将 $A$ 重新排列成一个等比数列。

??? Note "解题思路"

首先收集 $A$ 中所有的正数 $B$ 和负数 $C$，将 $B$ 升序排序， $C$ 降序排序，然后分类讨论：

- 如果 $C$ 为空，则全是正数，判断 $B$ 是不是等比数列即可，此时公比为正数。
- 如果 $B$ 为空，则全是负数，判断 $C$ 是不是等比数列即可，此时公比为正数。
- 否则， $B$ 和 $C$ 都不为空，则公比一定是负数，设 $B$ 和 $C$ 各有 $n$ 和 $m$ 个数字，然后，进一步分类讨论：
  - 如果 $0 \le n - m \le 1$，则可能的序列是 $(B_1, C_1, B_2, C_2, \ldots)$，判断这个序列是不是等比数列即可。
  - 如果 $0 \le m - n \le 1$，则可能的序列是 $(C_1, B_1, C_2, B_2, \ldots)$，判断这个序列是不是等比数列即可。

注意判断等比数列的时候要用乘法避免浮点数精度问题。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <functional>
        #include <iostream>
        #include <vector>

        using namespace std;

        int main()
        {
            int t;
            cin >> t;
            auto check = [](const vector<int> &a) -> bool
            {
                int n = a.size();
                for (int i = 2; i < n; i++)
                    if (a[i] * a[i - 2] != a[i - 1] * a[i - 1])
                        return false;
                return true;
            };
            while (t--)
            {
                int n;
                cin >> n;
                vector<int> pos, neg;
                for (int i = 0; i < n; i++)
                {
                    int x;
                    cin >> x;
                    x > 0 ? pos.push_back(x) : neg.push_back(x);
                }
                sort(pos.begin(), pos.end());
                sort(neg.begin(), neg.end(), greater<>());
                bool ans = false;
                if (pos.empty())
                    ans = check(neg);
                else if (neg.empty())
                    ans = check(pos);
                else
                {
                    int n1 = pos.size();
                    int n2 = neg.size();
                    vector<int> t;
                    t.reserve(n);
                    if (n1 == n2 || n1 - n2 == 1)
                    {
                        for (int i = 0; i < n1; i++)
                        {
                            t.push_back(pos[i]);
                            if (i < n2)
                                t.push_back(neg[i]);
                        }
                        ans = check(t);
                    }
                    t.clear();
                    if (!ans && (n1 == n2 || n2 - n1 == 1))
                    {
                        for (int i = 0; i < n2; i++)
                        {
                            t.push_back(neg[i]);
                            if (i < n1)
                                t.push_back(pos[i]);
                        }
                        ans = check(t);
                    }
                }
                cout << (ans ? "Yes" : "No") << '\n';
            }
            return 0;
        }
        ```

## [E - Reverse 2^i](https://atcoder.jp/contests/abc413/tasks/abc413_e)

???+ Abstract "题目大意"

给你一个数字 $N$ 和一个 $1$ 到 $2^N$ 的排列 $P = (P_0, P_1, \ldots, P_{2^N - 1})$。

你可以进行如下操作任意次（也可以一次都不做）：

- 选择满足 $0 \le a \times 2^b < (a+1) \times 2^b \le 2^N$ 的非负整数 $a,b$，将 $P_{a×2^b},P_{a×2^b+1},\ldots ,P_{(a+1)×2^b−1}$ 反转。

请你求出通过若干次操作后，能得到的 $P$ 的字典序最小的排列。

??? Note "解题思路"

可以翻转的区间其实是在一个大区间上不断二分的，例如 $[0, 8)$ 可翻转，进一步就是 $[0, 4)$ 和 $[4, 8)$，然后是 $[0, 2), [2, 4), [4, 6), [6, 8)$，依次类推。

因为 $P$ 是一个排列（所有的数字都不同），下面需要推一个性质：对于一个可反转的区间 $[l, r)$，一定存在某种方法可以将最小的数字放置在 $P[l]$ 上。

证明这个结论可以通过数学归纳法，首先考虑长度为 $2$ 的区间，即 $[l, l+2)$，这时要么最小的数字是 $P_l$，要么是 $P_{l+1}$，如果是 $P_{l+1}$，则翻转 $[l, l+2)$ 即可。进一步对于 $[l, l+4)$，如果最小的数字在 $[l+2, l+4)$，则翻转 $[l, l+4)$，就可以让最小的数字出现在 $[l, l+2)$。于是结论成立。

因此我们的策略是：对于一个可翻转的区间 $[l, r)$，找到最小值在前半段还是后半段，如果在后半段，则翻转 $[l, r)$，然后递归处理 $[l, (l+r)/2)$ 和 $[(l+r)/2, r)$。这个算法时间复杂度是 $O(N \times 2^N)$。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <iostream>
        #include <vector>

        using namespace std;

        int main()
        {
            int t;
            cin >> t;
            while (t--)
            {
                int n;
                cin >> n;
                n = 1 << n;
                vector<int> a(n);
                for (auto &x : a)
                    cin >> x;

                using IT = vector<int>::iterator;

                auto solve = [](auto &&self, IT beg, IT end) -> void
                {
                    if (beg + 1 == end)
                        return;
                    IT mid = beg + (end - beg) / 2;
                    int lm = *min_element(beg, mid);
                    int rm = *min_element(mid, end);
                    if (rm < lm)
                        reverse(beg, end);
                    self(self, beg, mid);
                    self(self, mid, end);
                };

                solve(solve, a.begin(), a.end());
                for (auto x : a)
                    cout << x << ' ';
            }
            return 0;
        }
        ```

## [F - No Passage](https://atcoder.jp/contests/abc413/tasks/abc413_f)

???+ Abstract "题目大意"

有一个 $H \times W$ 列的网格。有 $K(1 \le K \le min(HW, 3000))$ 个格子是“终点”。第 $i$ 个终点位于 $(R_i, C_i)$

高桥君和青木君正在进行游戏，首先，他们会在网格上放置一枚棋子，在棋子到达终点格子之前，两人会不断重复以下操作：

- 青木君选择一个 $1$ 到 4 之间的整数 $a$。
- 然后，高桥君选择一个 $1$ 到 $4$ 之间的整数 $b$，但要求 $a \neq b$
- 假设操作前棋子在 (i,j)，则根据 $b$ 的值和棋子的位置 $(i, j)$，按如下方式移动棋子：
    - 若 $b=1$：如果 $(i−1,j)$ 在网格内，则将棋子从 $(i,j)$ 移动到 $(i−1,j)$，否则不移动。
    - 若 $b=2$：如果 $(i+1,j)$ 在网格内，则将棋子从 $(i,j)$ 移动到 $(i+1,j)$，否则不移动。
    - 若 $b=3$：如果 $(i,j−1)$ 在网格内，则将棋子从 $(i,j)$ 移动到 $(i,j−1)$，否则不移动。
    - 若 $b=4$：如果 $(i,j+1)$ 在网格内，则将棋子从 $(i,j)$ 移动到 $(i,j+1)$，否则不移动。

高桥君的目标是让棋子以最少的步数到达终点。青木君的目标是让棋子无法到达终点，如果无法做到，则尽量让步数最大化。

对于所有满足 $1 \le i \le H,1 \le j \le W$ 的整数对 $(i,j)$，请解决以下问题，并求出所有解的总和：
- 如果棋子从格子 $(i,j)$ 开始游戏。两人都以各自的目标采取最优策略。如果高桥君能让棋子到达终点，则输出所需的最小步数，否则输出 $0$。

注：如果棋子从终点开始游戏，则直接结束，步数为 $0$。

??? Note "解题思路"

显然棋子是一定能移动到终点的，设 $f[i][j]$ 表示从棋子 $(i, j)$ 开始时游戏的解，则对于 $f[i-1][j]$，$f[i+1][j]$，$f[i][j-1]$，$f[i][j+1]$ 四个方向的格子，青木君一定是禁止掉其中最小的那个方向，所以高桥君就会从第二小的方向转移，设次小值是 $x$，则 $f[i][j] = x + 1$。这里可以用变种 bfs 来解决，每个点只有在第二次被访问的时候才更新值，加入队列。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <array>
        #include <iostream>
        #include <queue>
        #include <vector>

        using namespace std;
        using LL = long long;

        int main()
        {
            int h, w, k;
            cin >> h >> w >> k;
            vector<vector<int>> cnt(h, vector<int>(w));
            queue<array<int, 3>> q;
            while (k--)
            {
                int r, c;
                cin >> r >> c;
                r--, c--;
                cnt[r][c] = 2;
                q.push({r, c, 0});
            }
            LL ans = 0;

            const int dr[] = {-1, 1, 0, 0};
            const int dc[] = {0, 0, -1, 1};

            auto in_lim = [h, w](int r, int c) -> bool
            { return r >= 0 && r < h && c >= 0 && c < w; };

            while (!q.empty())
            {
                auto [r, c, d] = q.front();
                q.pop();
                for (int i = 0; i < 4; i++)
                {
                    int nr = r + dr[i];
                    int nc = c + dc[i];
                    if (in_lim(nr, nc) && cnt[nr][nc] <= 1)
                    {
                        cnt[nr][nc]++;
                        if (cnt[nr][nc] == 2)
                        {
                            ans += d + 1;
                            q.push({nr, nc, d + 1});
                        }
                    }
                }
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [G - Big Banned Grid](https://atcoder.jp/contests/abc413/tasks/abc413_g)

???+ Abstract "题目大意"

给你一个 $H \times W(1 \le H, W \le 2 \times 10^{5})$ 的网格，其中有 $K(1 \le K \le 2 \times 10^{5})$ 个格子有障碍物，第 $i$ 个障碍物位于 $(r_i, c_i)$。

你的初始位置在 $(1, 1)$，目标位置在 $(H, W)$。可以进行任意次移动，每一次移动到上下左右相邻的格子，你不能移动到有障碍物的格子。

问：是否可以从 $(1,1)$ 移动到 $(H,W)$？

输入数据保证 $(1,1)$ 和 $(H,W)$ 没有障碍物。

??? Note "解题思路"

数据范围显然不支持 $O(HW)$ 的做法，考虑怎样的图不支持从左下移动到右下。

1. 存在上方到左方的封锁线，例如：

```
OOXOO
OOXOO
XXOOO
OOOOO
OOOOO
```

2. 存在上方到下方的封锁线，例如：

```
OOXOO
OOXOO
OOOXO
OOXOO
OXOOO
```

3. 存在右方到左方的封锁线，例如：

```
OOOOO
OOOOO
XXXXX
OOOOO
OOOOO
```

4. 存在右方到下方的封锁线，例如：

```
OOOOO
OOOXX
OOXOO
OXOOO
OXOOO
```

显然，只需要针对所有上方和右方的障碍物开始做搜索，每次可以移动 $8$ 个方向，搜索过程中如果遇到左方或者下方的障碍物，则说明存在封锁线，输出 `No`。否则输出 `Yes`。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <queue>
        #include <set>
        #include <utility>

        using namespace std;

        int main()
        {
            int h, w, k;
            cin >> h >> w >> k;
            set<pair<int, int>> ban;
            set<pair<int, int>> vis;
            queue<pair<int, int>> q;

            while (k--)
            {
                int r, c;
                cin >> r >> c;
                ban.insert({r, c});
                if (c == w || r == 1)
                {
                    q.push({r, c});
                    vis.insert({r, c});
                }
            }

            auto in_lim = [h, w](int r, int c) -> bool
            { return r >= 1 && r <= h && c >= 1 && c <= w; };

            while (!q.empty())
            {
                auto [r, c] = q.front();
                if (r == h || c == 1)
                {
                    cout << "No" << endl;
                    return 0;
                }
                q.pop();
                for (int dr = -1; dr <= 1; dr++)
                    for (int dc = -1; dc <= 1; dc++)
                    {
                        if (dr == 0 && dc == 0)
                            continue;
                        int nr = r + dr;
                        int nc = c + dc;
                        if (in_lim(nr, nc) && ban.contains({nr, nc}) && !vis.contains({nr, nc}))
                        {
                            q.push({nr, nc});
                            vis.insert({nr, nc});
                        }
                    }
            }
            cout << "Yes" << endl;
            return 0;
        }
        ```
