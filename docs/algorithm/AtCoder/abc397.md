## [B - Ticket Gate Log](https://atcoder.jp/contests/abc397/tasks/abc397_b)

???+ Abstract "题目大意"

给你一个字符串 $S$，$S$ 由 `i` 和 `o` 组成。你可以在 $S$ 的任意位置插入一个 `i` 或 `o`，使得 $S$ 的长度是偶数，且奇数位置的字符都是 `i`，偶数位置的字符都是 `o`。问：至少插入多少个字符才能满足这个条件？

??? Note "解题思路"

插入一个字符，只会影响后面的字符的奇偶性。进一步发现，假设（原本的）字符 $i$ 之前插入了 $a$ 个字符，则（原本的）字符 $i$ 最终的位置是 $i + a$。因此，只需要遍历字符串，统计每个位置的最终奇偶性是否符合要求即可，如果不符合要求，则需要插入一个字符。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <string>

        using namespace std;

        int main()
        {
            string s;
            cin >> s;
            int n = s.size();
            int now = 0;
            for(int i = 0; i < n; i++)
            {
                if(s[i] == 'i')
                {
                    if((now + i) % 2 == 1)
                        now++;
                }
                else
                {
                    if((now + i) % 2 == 0)
                        now++;
                }
            }
            if((now + n) % 2 == 1)
                now++;
            cout << now << endl;
            return 0;
        }
        ```

## [C - Variety Split Easy](https://atcoder.jp/contests/abc397/tasks/abc397_c)

???+ Abstract "题目大意"

给你一个长度为 $N$ 的数组 $A = (A_1, A_2, \ldots, A_N)$，你需要将切割成 $2$ 个连续的非空子数组 $(A_1, A_2, \ldots, A_i)$，$(A_{i+1}, A_{i+2}, \ldots, A_N)$，使得这 $2$ 个子数组的不同元素个数之和最大。问：最大值是多少？

??? Note "解题思路"

最简单的办法就是维护一个前缀、后缀的 `set`。也可以用 `map` 记录每个数字出现的次数，枚举切割点动态维护前缀的 `set` 和后缀的 `map`。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <unordered_map>
        #include <unordered_set>
        #include <vector>

        using namespace std;

        int main()
        {
            int n;
            cin >> n;
            vector<int> a(n);
            unordered_map<int, int> cnt;
            for(int i = 0; i < n; i++)
            {
                cin >> a[i];
                cnt[a[i]]++;
            }
            unordered_set<int> left;
            int ans = 0;
            for(int i = 0; i+1 < n; i++)
            {
                int x = a[i];
                auto it = cnt.find(x);
                left.insert(it->first);
                if(--it->second == 0)
                    cnt.erase(it);
                ans = max(ans, (int)(left.size() + cnt.size()));
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [D - Cubess](https://atcoder.jp/contests/abc397/tasks/abc397_d)

???+ Abstract "题目大意"

给你一个整数 $N(1 \le N \le 10 ^ {18})$，是否存在正整数对 $(x, y)$ 使得 $x^3 - y^3 = N$？如果存在，输出任意一组 $(x, y)$，如果不存在，输出 `-1`。

??? Note "解题思路"

显然有 $x > y$，不妨设 $x = y + t$，则有 $x^3 - y^3 = (y + t)^3 - y^3 = 3y^2t + 3yt^2 + t^3 = t(3y^2 + 3yt + t^2) = N$。则 $t$ 一定是 $N$ 的因子，且由于 $y \ge 1$，另一个因子 $3y^2 + 3yt + t^2 \ge t^2 + 3t + 3$，也就是 $t^3 + 3t^2 + 3t \le N$，所以这里的 $t$ 不会超过 $\sqrt[3]{N}$。

因此，只需要枚举 $N$ 的因子 $t$，固定 $t$ 的值之后只需要解 $3y^2 + 3yt + \frac{t^3 - N}{t} = 0$ 方程即可。

因为有 $N - t^3 \ge 3t^2 + 3t \ge 0$，设 $n_1 = N - t^3$ ，方程变成 $3y^2 + 3yt - \frac{n_1}{t} = 0$，相当于 $y^2 + yt - \frac{n_1}{3t} = 0$。这里 $\frac{n_1}{3t}$ 显然也是一个整数，令 $n_2 = \frac{n_1}{3t} = \frac{N - t^3}{3t}$，则方程变成 $y^2 + ty - n_2 = 0$。

所以在枚举 $t$ 的时候，$N - t^3$ 必须是 $3t$ 的倍数。后面就是解二元一次方程了。解是 $\frac{\sqrt{t^2 + 4n_2} - t}{2}$，注意这里 $\sqrt{t^2 + 4n_2}$ 一定是整数，则 $\sqrt{t^2 + 4n_2} - t$ 是 $2$ 的倍数。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <cmath>
        #include <iostream>

        using namespace std;
        using LL = long long;

        int main()
        {
            LL n;
            cin >> n;

            for (LL t = 1; t * (t * t + 3 * t + 3) <= n; t++)
            {
                if (n % t != 0)
                    continue;
                LL n1 = n - t * t * t;
                if (n1 % (3 * t) != 0)
                    continue;
                LL n2 = n1 / 3 / t;
                LL delta = t * t + 4 * n2;
                LL sq_delta = sqrt(delta);
                if (sq_delta * sq_delta != delta || (sq_delta - t) % 2 != 0)
                    continue;
                LL y = (sq_delta - t) / 2;
                LL x = y + t;
                cout << x << ' ' << y << endl;
                return 0;
            }

            cout << -1 << endl;
            return 0;
        }
        ```

## [E - Path Decomposition of a Tree](https://atcoder.jp/contests/abc397/tasks/abc397_e)

???+ Abstract "题目大意"

给你一棵 $NK(1 \le NK \le 2 \times 10 ^ 5)$ 个点的树。问：这棵树能否分解成 $N$ 条路径，使得每条路径的长度等于 $K$？如果可以，输出 `Yes`，否则输出 `No`。

??? Note "解题思路"

可以用 dfs 在 $O(NK)$ 的时间内解决。dfs 的时候，假设当前节点 $u$，子节点是 $v$，有三种情况：

- $v$ 所在的子树可以凑成若干个 $K$ 的路径，则 $u$ 没有必要加入 $v$。
- $v$ 所在的子树有一部分节点可以凑成若干个 $K$ 的路径，还剩下一条 $v$ 所在的单链，需要和 $u$ 连接起来。
- $v$ 所在的子树无法凑成 $K$ 的路径。

显然对于第二种情况，需要知道 $v$ 所在的子树的长度，因此 dfs 的返回值就是 $v$ 所在的单链的长度。第一种情况可以返回 `0`，第三种情况可以返回 `-1`。

对于节点 $u$ 来说，至多连接 $2$ 个子节点的单链，否则一定是无解的。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <vector>

        using namespace std;

        int main()
        {
            int n, k;
            cin >> n >> k;
            vector<vector<int>> edge(n * k + 1);
            for (int i = 1; i < n * k; i++)
            {
                int u, v;
                cin >> u >> v;
                edge[u].push_back(v);
                edge[v].push_back(u);
            }

            auto dfs = [&edge, k](auto &self, int u, int fa) -> int
            {
                int sum = 1;
                int cnt = 0;
                for (auto v : edge[u])
                {
                    if (v == fa)
                        continue;
                    int sum_v = self(self, v, u);
                    if (sum_v == -1)
                        return -1;
                    if (sum_v > 0)
                    {
                        sum += sum_v;
                        cnt++;
                    }
                }
                if (cnt > 2 || sum > k)
                    return -1;
                if (sum == k)
                    return 0;
                if (cnt == 2)
                    return -1;
                return sum;
            };

            int sum = dfs(dfs, 1, 0);
            if(sum != 0)
                cout << "No" << endl;
            else
                cout << "Yes" << endl;
            return 0;
        }
        ```

## [F - Variety Split Hard](https://atcoder.jp/contests/abc397/tasks/abc397_f)

???+ Abstract "题目大意"

给你一个长度为 $N(3 \le N \le 3 \times 10 ^ 5)$ 的数组 $A = (A_1, A_2, \ldots, A_N)$，你需要将切割成 $3$ 个连续的非空子数组 $(A_1, A_2, \ldots, A_i)$，$(A_{i+1}, A_{i+2}, \ldots, A_j)$ 和 $(A_{j+1}, A_{j+2}, \ldots, A_N)$，使得这 $3$ 子数组的不同元素个数之和最大。问：最大值是多少？

??? Note "解题思路"

固定第一个子数组的末尾为 $x$，现在需要在 $[x+1, N]$ 中选择第二个子数组的末尾 $y$，考虑一下每个数字在后两个子数组中的贡献：
- 如果 $[x+1, N]$ 中有一个数字只出现了一次，那么无论 $y$ 选在哪里，这个数字的贡献都是 $1$。
- 如果 $[x+1, N]$ 中有一个数字出现了两次及以上，不妨设这个数字最后一次出现的位置是 $k$，只要 $y < k$，这个数字的贡献就是 $2$，否则就是 $1$。

因此可以维护一个线段树，倒序枚举 $x$，同时维护每一个数字的上一次出现的位置，设 $last_t$ 表示数字 $t$ 上一次出现的位置。枚举到位置 $x$ 的时候，给 $[x, last[a[x]] - 1]$ 的位置加上权值 $1$，查找 $[x, N-1]$ 的区间最大值即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <limits>
        #include <unordered_map>
        #include <vector>

        using namespace std;

        struct SegTree
        {
            struct Node
            {
                int max_val;
                int add;
            };

            int n;
            vector<Node> t;

            SegTree(int n) : n(n), t(4 * n) {}

            void push_down(int p)
            {
                if (t[p].add)
                {
                    int lch = p * 2, rch = p * 2 + 1;
                    t[lch].max_val += t[p].add;
                    t[rch].max_val += t[p].add;
                    t[lch].add += t[p].add;
                    t[rch].add += t[p].add;
                    t[p].add = 0;
                }
            }

            void add(int p, int beg, int end, int l, int r, int k)
            {
                if (end < l || beg > r)
                    return;
                if (beg >= l && end <= r)
                {
                    t[p].max_val += k;
                    t[p].add += k;
                    return;
                }
                push_down(p);
                int mid = (beg + end) / 2;
                int lch = p * 2, rch = p * 2 + 1;
                add(lch, beg, mid, l, r, k);
                add(rch, mid + 1, end, l, r, k);
                t[p].max_val = max(t[lch].max_val, t[rch].max_val);
            }

            int query(int p, int beg, int end, int l, int r)
            {
                if (end < l || beg > r)
                    return numeric_limits<int>::min();
                if (beg >= l && end <= r)
                    return t[p].max_val;
                push_down(p);
                int mid = (beg + end) / 2;
                int lch = p * 2, rch = p * 2 + 1;
                return max(query(lch, beg, mid, l, r), query(rch, mid + 1, end, l, r));
            }
        };

        int main()
        {
            int n;
            cin >> n;
            SegTree t(n);
            vector<int> a(n + 1);
            unordered_map<int, int> cnt;
            unordered_map<int, int> last;
            for (int i = 1; i <= n; i++)
            {
                cin >> a[i];
                cnt[a[i]]++;
            }
            int ans = 0;
            for (int i = n; i > 1; i--)
            {
                auto it = cnt.find(a[i]);
                auto x = it->first;
                if (--it->second == 0)
                    cnt.erase(it);
                it = last.find(x);
                if(it == last.end())
                    t.add(1, 1, n, 1, n, 1);
                else
                    t.add(1, 1, n, i, last[x] - 1, 1);
                ans = max(ans, (int)cnt.size() + t.query(1, 1, n, i, n-1));
                last[x] = i;
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [G - Maximize Distance](https://atcoder.jp/contests/abc397/tasks/abc397_g)

???+ Abstract "题目大意"

给你一个 $N(2 \le N \le 30)$ 个点 $M(1 \le M \le 100)$ 条边的有向图，保证可以从点 $1$ 到达点 $N$。

初始的时候，所有边的权值都是 $0$。你可以选择恰好 $K(1 \le K \le M)$ 条边，将它们的权值变成 $1$。问：在这种情况下，点 $1$ 到点 $N$ 的最短路径的长度最大是多少？

??? Note "解题思路"

答案的范围是 $[0, n - 1]$，可以二分答案，下面考虑能否使得点 $1$ 到点 $N$ 的最短路径的长度至少为 $d$。

直接判定其实很难，考虑 $d = 1$（也就是说，我们希望点 $1$ 到点 $N$ 的最短路径的长度至少为 $1$） 的时候怎么做。这等价于图中所有从点 $1$ 到点 $N$ 的路径中，每一条路径都得有至少一条边的权值为 $1$，可以把这条边权值的增加视为这条边被删除了（这很好理解，因为如果走了这条边，那么最短路一定大于等于 $1$，所以为了达到最短路为 $0$ 的目的，一定不走）

而删除边和最小割的定义类似。于是转而考虑，将每一条边的权值视为 $1$，然后求出原图的最小割，如果最小割的值小于等于 $K$，则说明可以使得点 $1$ 到点 $N$ 的最短路径的长度为 $1$。

下面将这个思路推广到任意的 $d$。建立一个 $d + 1$ 层的分层图，每一层 $N$ 个点，例如 $(i, u)$ 表示第 $i$ 层的第 $u$ 个点。$(i, u)$ 表示到达第 $u$ 个点且最短路为 $i$ 的状态。对于每一条边 $(u, v)$, 在分层图中都需要加入:
1. 从 $(i, u)$ 到 $(i, v)$ ，流量为 $1$ 的边
2. 从 $(i, u)$ 到 $(i + 1, v)$，流量为 $+\infty$ 的边

解释一下为什么加这条边，每条边要么割要么不割，如果不割的话，那么走 1 的边（也就是同一层）的边一定更好。而只有割了这条边的情况下才会有走第二条边的可能，这样就会进入下一层，也就意味着最短路增加了 $1$。第 2 中情况的边的权值是 $+\infty$，因此不可能被割。

此外，还需要连上形如 $(i, N)$ 到 $(i + 1, N)$，流量为 $+\infty$ 的边。意味着无论到达哪一层的 $N$，都可以直接进入下一层。源点 $s$ 需要和 $(0, 1)$ 连一条流量为 $+\infty$ 的边，汇点 $t$ 需要和 $(d, N)$ 连一条流量为 $+\infty$ 的边。

建完图之后，跑最小割，如果最小割小于等于 $K$，则说明可以使得点 $1$ 到点 $N$ 的最短路径的长度大于 $d$（因为第 $d$ 层已经不可达了）

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <limits>
        #include <queue>
        #include <utility>
        #include <vector>

        using namespace std;

        const int INF = numeric_limits<int>::max();

        struct Network
        {
            struct Edge
            {
                int to, flow, rev_idx;
            };

            int n;
            vector<vector<Edge>> edge;

            Network(int n) : n(n), edge(n) {}

            void add_edge(int u, int v, int w)
            {
                int ui = edge[u].size();
                int vi = edge[v].size();
                edge[u].push_back({v, w, vi});
                edge[v].push_back({u, 0, ui});
            }

            int dinic(int s, int t)
            {
                vector<int> dep(n);
                vector<size_t> cur(n);

                auto bfs = [&]() -> bool
                {
                    dep.assign(n, -1);
                    cur.assign(n, 0);
                    dep[s] = 0;
                    queue<int> q;
                    q.push(s);
                    while (!q.empty())
                    {
                        int u = q.front();
                        q.pop();
                        int d = dep[u];
                        for (auto e : edge[u])
                        {
                            int v = e.to;
                            if (e.flow && dep[v] == -1)
                            {
                                dep[v] = d + 1;
                                q.push(v);
                            }
                        }
                    }
                    return dep[t] != -1;
                };

                auto dfs = [&](auto &self, int u, int in) -> int
                {
                    if (u == t)
                        return in;
                    int out = 0;
                    for (size_t &i = cur[u]; i < edge[u].size(); i++)
                    {
                        Edge &e = edge[u][i];
                        int v = e.to;
                        if (dep[v] == dep[u] + 1 && e.flow)
                        {
                            Edge &r = edge[v][e.rev_idx];
                            int res = self(self, v, min(in, e.flow));
                            e.flow -= res;
                            r.flow += res;
                            in -= res;
                            out += res;
                            if (!in)
                                break;
                        }
                    }
                    return out;
                };

                int ans = 0;
                while (bfs())
                    ans += dfs(dfs, s, numeric_limits<int>::max());
                return ans;
            }
        };

        int main()
        {
            int n, m, k;
            cin >> n >> m >> k;
            vector<pair<int, int>> edge(m);
            for (auto &[u, v] : edge)
            {
                cin >> u >> v;
                u--, v--;
            }

            auto f = [n](int i, int u) -> int
            { return i * n + u; };

            auto check = [n, k, &edge, &f](int h) -> bool
            {
                int s = n * (h + 1), t = s + 1;
                Network g(t + 1);
                g.add_edge(s, f(0, 0), INF);
                g.add_edge(f(h, n - 1), t, INF);
                for (int i = 0; i <= h; i++)
                {
                    for (auto [u, v] : edge)
                    {
                        g.add_edge(f(i, u), f(i, v), 1);
                        if (i + 1 <= h)
                            g.add_edge(f(i, u), f(i + 1, v), INF);
                    }
                    if (i + 1 <= h)
                        g.add_edge(f(i, n - 1), f(i + 1, n - 1), INF);
                }
                return g.dinic(s, t) <= k;
            };

            int l = 0, r = n;
            while (l < r)
            {
                int mid = (l + r) / 2;
                if (check(mid))
                    l = mid + 1;
                else
                    r = mid;
            }
            cout << l << endl;
            return 0;
        }
        ```
