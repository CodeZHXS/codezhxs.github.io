## [A - Conflict](https://atcoder.jp/contests/abc409/tasks/abc409_a)

???+ Abstract "题目大意"

给你两个长度为 $N$ 的字符串 $T$ 和 $A$，判断是否存在一个位置 $i$，使得 $S_i = T_i =$  `o`。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <string>

        using namespace std;

        int main()
        {
            int n;
            cin >> n;
            string t, a;
            cin >> t >> a;
            bool flag = false;
            for(int i = 0; i < n; i++)
                if(t[i] == 'o' && a[i] == 'o')
                    flag = true;
            cout << (flag ? "Yes" : "No") << endl;
            return 0;
        }
        ```

## [B - Citation](https://atcoder.jp/contests/abc409/tasks/abc409_b)

???+ Abstract "题目大意"

给定一个长度为 $N$ 的非负整数序列 $A=(A_1,A_2,\ldots,A_N)$。找出满足以下条件的最大非负整数 $x$：

- 在 $A$ 中，大于等于 $x$ 的元素（允许重复）至少出现 $x$ 次。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <iostream>
        #include <vector>

        using namespace std;

        int main()
        {
            int n;
            cin >> n;
            vector<int> a(n);
            for(auto &x : a)
                cin >> x;
            sort(a.begin(), a.end());
            int ans = n;
            for(int i = 0; i < n; i++, ans--)
                if(a[i] >= ans)
                    break;
            cout << ans << endl;
            return 0;
        }
        ```

## [C - Equilateral Triangle](https://atcoder.jp/contests/abc409/tasks/abc409_c)

???+ Abstract "题目大意"

有一个周长为 $L(3 \le L \le 3 \times 10^{5})$ 的圆，圆周上分布着 $N(3 \le N \le 3 \times 10^{5})$ 个点，编号为 $1,2,...,N$。对于每个 $i=1,2,...,N−1$，点 $i+1$ 位于从点 $i$ 出发沿顺时针方向移动 $d_i$ 距离的位置。

统计满足以下两个条件的整数三元组 $(a,b,c)（1 \le a<b<c \le N）$的个数：

- 三个点 $a,b,c$ 的位置互不相同。
- 以 $a,b,c$ 为顶点的三角形是正三角形。

??? Note "解题思路"

三个点形成正方形，说明对应的弧长是 $L$，则任意两个点之间的最短弧长是 $\frac{L}{3}$。

首先把所有的点的在模 $L$ 下的位置求出来（把差分还原一下就可以了），然后统计每个位置有多少个点，这可以用 map 存，然后开始枚举，不妨枚举模 $L$ 意义下最小的位置 $i$，则构成三角形的另外两个点的位置一定是 $i+\frac{L}{3}$ 和 $i+\frac{2L}{3}$。假设分别有 $x, y, z$ 个，那么这一组答案就是 $x \times y \times z$。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <vector>

        using namespace std;
        using LL = long long;

        int main()
        {
            int n, l;
            cin >> n >> l;
            vector<int> cnt(l);
            int now = 0;
            cnt[now]++;
            for (int i = 1; i < n; i++)
            {
                int d;
                cin >> d;
                now = (now + d) % l;
                cnt[now]++;
            }
            if (l % 3 != 0)
            {
                cout << 0 << endl;
                return 0;
            }
            int t = l / 3;
            LL ans = 0;
            for (int i = 0; i + 2 * t < l; i++)
            {
                LL x = cnt[i];
                LL y = cnt[i + t];
                LL z = cnt[i + 2 * t];
                ans += x * y * z;
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [D - String Rotation](https://atcoder.jp/contests/abc409/tasks/abc409_d)

???+ Abstract "题目大意"

给定一个长度为 $N(1 \le N \le 10^{5})$ 的由小写字母组成的字符串 $S$
 。你需要对 $S$ 执行恰好一次以下操作：

- 选择 $S$ 的一个长度至少为 $1$ 的连续子串，将其向循环左移 $1$ 位。
请找出所有可能的操作后 $S$ 中字典序最小的字符串。

??? Note "解题思路"

显然选择长度为 $1$ 的子串循环左移不会改变 $S$，所以答案的上界是 $S$ 本身。下面考虑长度大于等于 $2$ 的子串。

可以肯定，子串的左边界一定是第一个 $S_l > S_{l+1}$ 的位置 $l$，因为这样一定可以使得 $S_l$ 更小。

下面考虑如何选择长度，假设目前已经选择了长度 $k$，也就是字串 $S_lS_{l+1}...S_{l+k-1}$，循环左移后就是 $S_{l+1}S_{l+2}...S_{l+k-1}S_l$。

而如果选择的长度为 $k+1$，那么循环左移后就是 $S_{l+1}S_{l+2}...S_{l+k-1}S_{l+k}S_l$。

那么如果 $S_{l+1}S_{l+2}...S_{l+k-1}S_{l+k}S_l \le S_{l+1}S_{l+2}...S_{l+k-1}S_lS_{l+k}$

去掉公共前缀，也就是 $S_{l+k}S_l \le S_{l}S_{l+k}$

这表明，如果 $S_{l+k} \le S_l$，那么应该将字串的长度继续扩展。

所以最终做法是：首先找到第一个 $S_l > S_{l+1}$ 的位置 $l$，然后不断向右扩展，找到第一个 $S_{r} > S_l$ 的位置 $r$ 停止，则左移的字符串就是 $[l, r)$

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <stack>
        #include <string>
        #include <vector>

        using namespace std;

        int main()
        {
            int t;
            cin >> t;
            while (t--)
            {
                int n;
                cin >> n;
                string s;
                cin >> s;
                stack<int> st;
                vector<int> r(n);
                for (int i = n - 1; i >= 0; i--)
                {
                    while (!st.empty() && s[i] >= s[st.top()])
                        st.pop();
                    r[i] = st.empty() ? n : st.top();
                    st.push(i);
                }
                int pos = n - 1;
                for (int i = 0; i < n - 1; i++)
                    if (s[i + 1] < s[i])
                    {
                        pos = i;
                        break;
                    }
                for (int i = 0; i < pos; i++)
                    cout << s[i];
                for (int i = pos + 1; i < r[pos]; i++)
                    cout << s[i];
                cout << s[pos];
                for (int i = r[pos]; i < n; i++)
                    cout << s[i];
                cout << '\n';
            }
            return 0;
        }
        ```

## [E - Pair Annihilation](https://atcoder.jp/contests/abc409/tasks/abc409_e)

???+ Abstract "题目大意"

给你一棵 $N(2 \le N \le 10^{5})$ 个点的树。每一条边有一个权值 $w_j(0 \le w_j \le 10^{4})$。此外，第 $i$ 个点上有一个整数 $x_i$。若 $x_i > 0$，表示第 $i$ 个点有 $x_i$ 个正电子；若 $x_i < 0$，表示有 −$x_i$ 个负电子；若 $x_i = 0$，则该顶点没有任何电子。题目保证 $\sum\limits_{i = 1}^N x_i = 0$。

每次可以沿着一条边移动 1 个正电子或电子，消耗能量等于边的权值。当正电子和负电子位于同一个点时，它们会相互抵消，此时正负电子都消失。

求使所有正电子和负电子完全消失所需的最小总能量。

??? Note "解题思路"

dfs 就可以，dfs 的流程：假设 $u$ 是当前节点，且有边 $(u, v, w)$，那么首先求出 $v$ 的子树中正负电子的数量，显然这些电子肯定是在 $v$ 的内部先进行抵消，最终剩下的电子再和 $u$ 的电子进行抵消即可。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <utility>
        #include <vector>

        using namespace std;
        using LL = long long;

        int main()
        {
            int n;
            cin >> n;
            vector<vector<pair<int, LL>>> edge(n + 1);
            vector<int> x(n + 1);
            for(int i = 1; i <= n; i++)
                cin >> x[i];
            for(int i = 0; i < n - 1; i++)
            {
                int u, v, w;
                cin >> u >> v >> w;
                edge[u].push_back({v, w});
                edge[v].push_back({u, w});
            }

            auto dfs = [&edge, &x](auto &&self, int u, int fa) -> pair<int, LL>
            {
                int e = x[u];
                LL c = 0;
                for(auto [v, w] : edge[u])
                {
                    if(v == fa)
                        continue;
                    auto [ev, cv] = self(self, v, u);
                    c += cv + abs(ev) * w;
                    e += ev;
                }
                return {e, c};
            };

            LL ans = dfs(dfs, 1, 0).second;
            cout << ans << endl;
            return 0;
        }
        ```

## [F - Connecting Points](https://atcoder.jp/contests/abc409/tasks/abc409_f)

???+ Abstract "题目大意"

在二维平面上有一个初始为 $N(2 \le N \le 1500)$ 个顶点、$0$ 条边的图 $G$。顶点 $i$ 的坐标为 $(x_i, y_i)$。

对于图 $G$ 中的顶点 $u$ 和 $v$，定义它们之间的距离 $d(u,v)$ 为曼哈顿距离：$d(u,v)=∣x_u−x_v∣+∣y_u−y_v∣$。

对于图 $G$ 的两个连通分量 $A$ 和 $B$，设它们的顶点集合分别为 $V(A)$ 和 $V(B)$，则定义 $A$ 和 $B$ 之间的距离 $d(A,B)$ 为：$d(A,B)=\min\{d(u,v)∣u\in V(A),v\in V(B)\}$。

有 $Q(1 \le Q \le 1500)$ 个查询，查询分为三种类型：

- `1 a b`：设当前图 $G$ 的顶点数为 $n$，在坐标 $(a,b)$ 处新增顶点 $n+1$，并将其加入图 $G$。
- `2`：设当前图 $G$ 的顶点数为 $n$，连通分量数为 $m$：
  - 若 $m=1$，输出 `-1`。
  - 若 $m≥2$，找到距离最小的连通分量对，并将它们合并（即在这些连通分量之间添加边，使得所有距离等于最小值的顶点对相连），然后输出该最小距离值。
- `3 u v`：若顶点 $u$ 和 $v$ 属于同一连通分量，输出 `Yes`，否则输出 `No`。

??? Note "解题思路"

询问 1 只需要维护当前点的数量就可以了，询问 3 可以用并查集轻松维护。

考虑询问 2 怎么做，由于 $N + Q \le 3000$，所以至多只有 $9 \times 10^6$ 个距离，这完全可以用一个堆来维护，每一次弹出距离最小的连通分量对，然后把它们合并。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <array>
        #include <functional>
        #include <iostream>
        #include <queue>
        #include <utility>
        #include <vector>

        using namespace std;

        class DSU
        {
        public:
            explicit DSU(int n) : parent_or_size(n, -1) {}

            int merge(int a, int b)
            {
                int x = leader(a), y = leader(b);
                if (x == y)
                    return x;
                if (-parent_or_size[x] < -parent_or_size[y])
                    swap(x, y);
                parent_or_size[x] += parent_or_size[y];
                parent_or_size[y] = x;
                return x;
            }

            int leader(int a) { return parent_or_size[a] < 0 ? a : parent_or_size[a] = leader(parent_or_size[a]); }

            bool same(int a, int b) { return leader(a) == leader(b); }

            int size(int a) { return -parent_or_size[leader(a)]; }

            void add() { parent_or_size.push_back(-1); }

        private:
            vector<int> parent_or_size;
        };

        int main()
        {
            int n, q;
            cin >> n >> q;
            vector<pair<int, int>> p(n);
            for (auto &[x, y] : p)
                cin >> x >> y;

            auto distance = [](const pair<int, int> &x, const pair<int, int> &y) -> int
            { return abs(x.first - y.first) + abs(x.second - y.second); };

            priority_queue<array<int, 3>, vector<array<int, 3>>, greater<>> heap;
            for (int i = 0; i < n; i++)
                for (int j = i + 1; j < n; j++)
                    heap.push({distance(p[i], p[j]), i, j});
            DSU dsu(n);
            while (q--)
            {
                int op;
                cin >> op;
                if (op == 1)
                {
                    int x, y;
                    cin >> x >> y;
                    dsu.add();
                    pair<int, int> np{x, y};
                    for (int i = 0; i < n; i++)
                        heap.push({distance(p[i], np), i, n});
                    p.push_back(np);
                    n++;
                }
                else if (op == 2)
                {
                    int k = -1;
                    while (!heap.empty())
                    {
                        auto [d, u, v] = heap.top();
                        heap.pop();
                        if (!dsu.same(u, v))
                        {
                            k = d;
                            dsu.merge(u, v);
                            while (!heap.empty() && heap.top()[0] == k)
                            {
                                auto [d, u, v] = heap.top();
                                heap.pop();
                                dsu.merge(u, v);
                            }
                            break;
                        }
                    }
                    cout << k << '\n';
                }
                else
                {
                    int u, v;
                    cin >> u >> v;
                    u--, v--;
                    cout << (dsu.same(u, v) ? "Yes" : "No") << '\n';
                }
            }
            return 0;
        }
        ```
