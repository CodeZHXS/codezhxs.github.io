## [B - Unauthorized](https://atcoder.jp/contests/abc401/tasks/abc401_b)

???+ Abstract "题目大意"

你需要模拟一个网站系统，一共有 $N$ 种操作，有四种类型的操作，由字符串 $S_i$ 给出：
- 如果 $S_i=$ `login`：表示网站当前是登录状态。
- 如果 $S_i=$ `logout`：表示网站当前是注销状态。
- 如果 $S_i=$ `public`：表示用户正在访问公共页面。
- 如果 $S_i=$ `private`：表示用户正在访问私人页面。

请注意，只有在登录状态下，用户才能访问私人页面。初始时，网站是注销状态。

后台的日志系统记录错误访问的次数。如果用户在注销状态下访问私人页面，则错误的次数会加 $1$。

回答 $N$ 次操作后，一共发生了多少次错误访问？

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <string>

        using namespace std;

        int main()
        {
            int n;
            cin >> n;
            string s;
            bool login = false;
            int ans = 0;
            while(n--)
            {
                cin >> s;
                if(s == "login")
                    login = true;
                else if (s == "logout")
                    login = false;
                else if(s == "private")
                    ans += !login;
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [C - K-bonacci](https://atcoder.jp/contests/abc401/tasks/abc401_c)

???+ Abstract "题目大意"

给你两个整数 $N$ 和 $K$，其中 $1 \le N, K \le 10^6$。定义一个长度为 $N + 1$ 的序列 $A = (A_0, A_1, \ldots, A_N)$，其中：
- 如果 $0 \le i < K$, 则 $A_i = 1$。
- 否则，$A_i = A_{i-1} + A_{i-2} + ... + A_{i-K}$。

求出 $A_N$，答案对 $10^9$ 取模。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <iostream>
        #include <queue>

        using namespace std;
        const int MOD = 1E9;

        int main()
        {
            int n, k;
            cin >> n >> k;
            int sum = k;
            queue<int> q;
            for (int i = 0; i < k; i++)
                q.push(1);
            for (int i = k; i <= n; i++)
            {
                q.push(sum);
                sum = (2 * sum % MOD - q.front() + MOD) % MOD;
                q.pop();
            }
            cout << q.back() << endl;
            return 0;
        }
        ```

## [D - Logical Filling](https://atcoder.jp/contests/abc401/tasks/abc401_d)

???+ Abstract "题目大意"

给你一个长度为 $N$ 的字符串 $S$，$S$ 仅由 `.`、`o` 和 `?` 组成。将所有 `?` 分别替换为 `.` 或 `o` 后得到的字符串中，满足以下所有条件的字符串集合记为 $X$：

- $o$ 的个数恰好为 $K$ 个。
- $o$ 不连续出现。

输入数据保证 $X$ 不是空集。

输出满足以下条件且长度为 $N$ 的字符串 $T$（其中 $T_i$ 表示 $T$ 的第 $i$ 个字符）：

- 若 $X$ 中所有字符串的第 $i$ 个字符都是 `.`，则 $T_i=$ `.`。
- 若 $X$ 中所有字符串的第 $i$ 个字符都是 `o`，则 $T_i=$ `o`。
- 若 $X$ 中既存在第 $i$ 个字符为 `.` 的字符串，也存在第 $i$ 个字符为 `o` 的字符串，则 $T_i = $ `?`。

??? Note "解题思路"

因为 `o` 不能连续出现，所以可以首先把 $S$ 中和 `o` 相邻的 `?` 替换为 `.`。统计 $S$ 中 `o` 的个数，记为 $a$。

注意到，一段连续的 `?`，至多可以提供 $\lfloor \frac{m + 1}{2} \rfloor$ 个 `o`，其中 $m$ 是这段连续的 `?` 的长度。遍历 $S$，算出每段连续的 `?` 至多能提供多少个 `o`，可以得到所有的 `?` 至多能提供的 `o` 的个数，记为 $b$。

因为输入保证 $X$ 不是空集，所以一定有 $a + b \ge K$，可以证明，如果 $a + b == k$，那么答案一定是唯一的。否则如果 $a + b > k$，那么任何一个 `?` 都不是必须替换成 `o` 的。所以所有的 `?` 在 $T$ 里面一定也是 `?`。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <iostream>
        #include <string>

        using namespace std;

        int main()
        {
            int n, k;
            cin >> n >> k;
            string s;
            cin >> s;
            for (int i = 0; i < n; i++)
            {
                if (s[i] == 'o')
                {
                    if (i)
                        s[i - 1] = '.';
                    if (i + 1 < n)
                        s[i + 1] = '.';
                }
            }
            string t = s;
            int m = count(s.begin(), s.end(), 'o');
            if (m == k)
            {
                replace(t.begin(), t.end(), '?', '.');
                cout << t << endl;
                return 0;
            }
            for (int i = 0; i < n; i++)
            {
                if (t[i] != '?')
                    continue;
                int j = i + 1;
                while (j < n && t[j] == '?')
                    j++;
                int len = j - i;
                m += (len + 1) / 2;
                if (len % 2 == 1)
                {
                    for (int x = i; x < j; x++)
                        t[x] = "o."[(x - i) % 2];
                }
                i = j;
            }
            if (m == k)
                cout << t << endl;
            else
                cout << s << endl;
            return 0;
        }
        ```

## [E - Reachable Set](https://atcoder.jp/contests/abc401/tasks/abc401_e)

???+ Abstract "题目大意"

给你一个包含 $N(1 \le N \le 2 \times 10 ^ 5)$ 个顶点和 $M(0 \le M \le 3 \times 10 ^ 5)$ 条边的无向图。顶点编号为 $1,2,…,N$。

对于每个 $k=1,2,…,N$，回答以下问题：

> 考虑以下操作：
> - 选择一个顶点，删除该顶点及其所有连接的边。
> 
> 通过重复上述操作，判断是否能够满足以下条件：
> 
> - 从顶点 $1$ 出发，通过边能够到达的顶点集合恰好为 $\{1,2,…,k\}$（共 $k$ 个顶点）。
> 
> 如果可能，求出满足条件所需的最少操作次数；否则输出 `-1`。

??? Note "解题思路"

维护三个集合：
- `S_0`：从点 $1$ 出发可达，且点的编号小于等于 $k$ 的点集。
- `S_1`：和 $S_0$ 中的点相邻的点集。
- `S_2`：其他点的集合。

初始的时候，$S_0$ 包含点 $1$，$S_1$ 就是所有和点 $1$ 相邻的点，$S_2$ 就是其他点的集合。

则 $k = 1$ 的答案就是 $S_1$ 集合的大小。

下面考虑 $k = 2$ 怎么做，点 $2$ 有两种情况：
- 点 $2$ 在 $S_1$ 中，那么显然点 $2$ 应该从 $S_1$ 中删除，加入 $S_0$。然后，将点 $2$ 在 $S_2$ 中的邻居加入到 $S_1$ 中。
- 点 $2$ 在 $S_2$ 中，那么什么都不做。但是点 $2$ 有可能被更大的 $k$ 的时候访问到，此时点 $2$ 由于编号小于等于 $k$，应该直接加入到 $S_0$ 中。

每一次操作结束后，首先查看 $S_0$ 的大小是否等于 $k$，等于 $k$ 答案就是 $S_1$ 的大小，否则答案就是 `-1`。

当然这个集合其实不用维护，用一个数组标记每个点的归属，再用一个变量维护集合的大小就可以了。时间复杂度仅仅是遍历所有图的复杂度，即 $O(N + M)$。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <array>
        #include <iostream>
        #include <vector>

        using namespace std;

        int main()
        {
            int n, m;
            cin >> n >> m;
            vector<vector<int>> edge(n + 1);
            while (m--)
            {
                int u, v;
                cin >> u >> v;
                edge[u].push_back(v);
                edge[v].push_back(u);
            }
            vector<int> col(n + 1, 2);
            col[1] = 1;
            array<int, 3> cnt = {0, 1, n - 1};

            auto dfs = [&edge, &col, &cnt](auto &&self, int u, int k) -> void
            {
                int &c = col[u];
                cnt[c]--;
                c = u <= k ? 0 : 1;
                if (c == 0)
                {
                    for (auto v : edge[u])
                    {
                        if (col[v] == 2)
                            self(self, v, k);
                    }
                }
                cnt[c]++;
            };

            for (int k = 1; k <= n; k++)
            {
                if (col[k] == 1)
                    dfs(dfs, k, k);
                cout << (cnt[0] == k ? cnt[1] : -1) << '\n';
            }
            return 0;
        }
        ```

## [F - Add One Edge 3](https://atcoder.jp/contests/abc401/tasks/abc401_f)

???+ Abstract "题目大意"

给你一棵 $N_1$ 个节点的树，和一棵 $N_2$ 个节点的树。其中 $1 \le N_1, N_2 \le 2 \times 10 ^ 5$，你可以在第一棵树中选择一个节点 $i$，在第二棵树中选择一个节点 $j$，然后添加一条边连接这两个节点。在添加之后，这两棵树合并成了一棵树。定义 $f(i, j)$ 表示这棵树的直径。求 $\sum\limits_{i=1}^{N_1} \sum\limits_{j=1}^{N_2} f(i, j)$，即所有可能的 $f(i, j)$ 的和。

??? Note "解题思路"

首先求出两棵树的直径 $d_1$ 和 $d_2$，同时令 $d = \max(d_1, d_2)$。在求树直径的同时还可以预处理出两个数组 $dep_1[i]$ 和 $dep_2[j]$，$dep_1[i]$ 表示从第一棵树的 $i$ 节点开始遍历所能得到的最大深度，$dep_2[j]$ 同理。

接下来我们考虑边 $(i, j)$ 添加后对 $f(i, j)$ 的影响，有两种情况：
- $dep_1[i] + dep_2[j] + 1 \le d$，这表明即使增加了边 $(i, j)$，仍然不影响答案，此时 $f(i, j) = d$。
- $dep_1[i] + dep_2[j] + 1 > d$，那么答案就会变成 $f(i, j) = dep_1[i] + dep_2[j] + 1$。

于是只需要将 $dep_1$ 和 $dep_2$ 排序，枚举所有的 $i$，然后通过二分或者双指针的方式在 $dep_2$ 中找到 $j$ 的分界线就好。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <iostream>
        #include <utility>
        #include <vector>

        using namespace std;
        using LL = long long;

        struct Graph
        {
            int n;
            vector<vector<int>> edge;

            Graph(int n) : n(n), edge(n) {}

            void add(int u, int v) { edge[u].push_back(v); }

            pair<int, vector<int>> diameter()
            {
                auto dfs = [&](auto &&self, int u, int fa, vector<int> &dep) -> pair<int, int>
                {
                    int max_dep = 0;
                    int max_son = u;
                    for (auto v : edge[u])
                    {
                        if (v == fa)
                            continue;
                        dep[v] = dep[u] + 1;
                        auto [d, s] = self(self, v, u, dep);
                        if (d + 1 > max_dep)
                        {
                            max_dep = d + 1;
                            max_son = s;
                        }
                    }
                    return {max_dep, max_son};
                };

                vector<int> dep1(n), dep2(n);
                auto [max_dep1, s1] = dfs(dfs, 0, -1, dep1);
                auto [max_dep2, s2] = dfs(dfs, s1, -1, dep2);
                dep1[s2] = 0;
                dfs(dfs, s2, -1, dep1);
                for (int i = 0; i < n; i++)
                    dep2[i] = max(dep1[i], dep2[i]);
                return {max_dep2, dep2};
            }
        };

        int main()
        {
            int n1;
            cin >> n1;
            Graph g1(n1);
            for (int i = 1; i < n1; i++)
            {
                int u, v;
                cin >> u >> v;
                u--, v--;
                g1.add(u, v);
                g1.add(v, u);
            }
            int n2;
            cin >> n2;
            Graph g2(n2);
            for (int i = 1; i < n2; i++)
            {
                int u, v;
                cin >> u >> v;
                u--, v--;
                g2.add(u, v);
                g2.add(v, u);
            }
            auto [d1, dep1] = g1.diameter();
            auto [d2, dep2] = g2.diameter();
            LL d = max(d1, d2);
            sort(dep1.begin(), dep1.end());
            sort(dep2.begin(), dep2.end());
            LL ans = 0;
            LL suf = 0;
            for (int i = 0, j = n2; i < n1; i++)
            {
                while (j && dep1[i] + 1 + dep2[j - 1] > d)
                    suf += dep2[--j];
                ans += d * j + (LL)(n2 - j) * (dep1[i] + 1) + suf;
            }
            cout << ans << endl;
            return 0;
        }
        ```

## [G - Push Simultaneously](https://atcoder.jp/contests/abc401/tasks/abc401_g)

???+ Abstract "题目大意"

平面上有 $N(1 \le N \le 300)$ 个机器人和 $N$ 个按钮，第 $i$ 个机器人的位置为 $(sx_i, sy_i)$，第 $i$ 个按钮的位置为 $(gx_i, gy_i)$。你的目的是控制机器人 **同时** 按下这 $N$ 个按钮。你可以命令任意机器人向任意方向移动，速度至多为 $1$ 单位每秒。你可以在任意时刻停下任意一个机器人。一个机器人只能按下一个按钮。问：至少需要多少时间才能让所有机器人同时按下按钮？

??? Note "解题思路"

显然是需要二分答案，至于能否判断是否可以在 $x$ 秒内完成，然后就转换成二分图最大匹配模板题了。

注意二分的时候，可以不二分时间，直接把所有的边收集起来，枚举边权的排名更好。

??? Success "参考代码"

    === "C++"
    
        ```c++
        #include <algorithm>
        #include <cmath>
        #include <iomanip>
        #include <iostream>
        #include <limits>
        #include <queue>
        #include <tuple>
        #include <vector>

        using namespace std;

        struct Network
        {
            struct Edge
            {
                int to, flow, rev_idx;
            };

            int n;
            vector<vector<Edge>> edge;

            Network(int n) : n(n), edge(n) {}

            void add_edge(int u, int v, int w)
            {
                int ui = edge[u].size();
                int vi = edge[v].size();
                edge[u].push_back({v, w, vi});
                edge[v].push_back({u, 0, ui});
            }

            int dinic(int s, int t)
            {
                vector<int> dep(n);
                vector<size_t> cur(n);

                auto bfs = [&]() -> bool
                {
                    dep.assign(n, -1);
                    cur.assign(n, 0);
                    dep[s] = 0;
                    queue<int> q;
                    q.push(s);
                    while (!q.empty())
                    {
                        int u = q.front();
                        q.pop();
                        int d = dep[u];
                        for (auto e : edge[u])
                        {
                            int v = e.to;
                            if (e.flow && dep[v] == -1)
                            {
                                dep[v] = d + 1;
                                q.push(v);
                            }
                        }
                    }
                    return dep[t] != -1;
                };

                auto dfs = [&](auto &self, int u, int in) -> int
                {
                    if (u == t)
                        return in;
                    int out = 0;
                    for (size_t &i = cur[u]; i < edge[u].size(); i++)
                    {
                        Edge &e = edge[u][i];
                        int v = e.to;
                        if (dep[v] == dep[u] + 1 && e.flow)
                        {
                            Edge &r = edge[v][e.rev_idx];
                            int res = self(self, v, min(in, e.flow));
                            e.flow -= res;
                            r.flow += res;
                            in -= res;
                            out += res;
                            if (!in)
                                break;
                        }
                    }
                    return out;
                };

                int ans = 0;
                while (bfs())
                    ans += dfs(dfs, s, numeric_limits<int>::max());
                return ans;
            }
        };

        int main()
        {
            int n;
            cin >> n;
            int s = 2 * n;
            int t = s + 1;
            vector<double> sx(n), sy(n), gx(n), gy(n);
            for (int i = 0; i < n; i++)
                cin >> sx[i] >> sy[i];
            for (int i = 0; i < n; i++)
                cin >> gx[i] >> gy[i];
            vector<tuple<double, int, int>> edges;
            edges.reserve(n * n);
            for (int i = 0; i < n; i++)
                for (int j = 0; j < n; j++)
                    edges.emplace_back(hypot(sx[i] - gx[j], sy[i] - gy[j]), i, j);
            sort(edges.begin(), edges.end());
            int l = 0, r = n * n - 1;
            while (l < r)
            {
                Network g(t + 1);
                int mid = (l + r) / 2;
                for (int i = 0; i <= mid; i++)
                {
                    auto [_, u, v] = edges[i];
                    g.add_edge(u, v + n, 1);
                }
                for (int i = 0; i < n; i++)
                {
                    g.add_edge(s, i, 1);
                    g.add_edge(i + n, t, 1);
                }
                if (g.dinic(s, t) == n)
                    r = mid;
                else
                    l = mid + 1;
            }
            cout << fixed << setprecision(7);
            cout << get<0>(edges[l]) << endl;
            return 0;
        }
        ```
