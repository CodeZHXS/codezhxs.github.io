    A - Task Failed Successfully¶

    题目大意

    给你 \(N\) 对数字 \((A_i, B_i)\)，问：有多少个数对满足 \(A_i \le B_i\)。

    参考代码 
    #include <iostream>

using namespace std;

int main()
{
    int n;
    cin >> n;
    int ans = 0;
    while(n--)
    {
        int a, b;
        cin >> a >> b;
        ans += b > a;
    }
    cout << ans << endl;
    return 0;
}

    B - Precondition¶

    题目大意

    给你两个字符串 \(S\) 和 \(T\)，它们仅由英文字母小写字母和大写字母组成。

    判断字符串 \(S\) 是否满足以下条件：

    • \(S\) 中除首字母外的每一个大写字母，其前一个字符都包含在 \(T\) 中。
    参考代码 
    #include <cctype>
#include <iostream>
#include <unordered_set>

using namespace std;

int main()
{
    string s, t;
    cin >> s >> t;
    unordered_set<char> vis(t.begin(), t.end());
    for (int i = 1, n = s.size(); i < n; i++)
        if (isupper(s[i]) && !vis.contains(s[i - 1]))
        {
            cout << "No" << endl;
            return 0;
        }
    cout << "Yes" << endl;
    return 0;
}

    C - Giant Domino¶

    题目大意

    有 \(N(2 \le N \le 2 \times 10^{5})\) 个多米诺骨牌。第 \(i\) 个多米诺骨牌的大小为 \(S_i\)

    如果有一些多米诺骨牌从左到右排成一行，然后推倒它们。当第 \(i\) 个多米诺骨牌向右倒下时，如果它右侧紧邻的多米诺骨牌的大小不超过 \(2S_i\)，那么这个右侧的多米诺骨牌也会向右倒下。

    你需要选择两个或更多的多米诺骨牌，从左到右排成一行，且排列必须满足以下条件：

    • 最左侧的多米诺骨牌是第 \(1\) 个。
    • 最右侧的多米诺骨牌是第 \(N\) 个。
    • 当只推倒第 \(1\) 个多米诺骨牌时，第 \(N\) 个多米诺骨牌最终也会倒下。

    是否存在满足上述条件的排列？如果存在，最少需要排列多少个多米诺骨牌？

    解题思路

    要想数量最少，每一次肯定选尽可能大的数字。把数字排序，或者用 set 就好。

    参考代码 
    #include <iostream>
#include <set>

using namespace std;

int main()
{
    int t;
    cin >> t;
    while(t--)
    {
        int n;
        cin >> n;
        set<int> d;
        int now;
        cin >> now;
        for(int i = 1; i < n - 1; i++)
        {
            int x;
            cin >> x;
            d.insert(x);
        }
        int target;
        cin >> target;
        int ans = 2;
        while(now * 2 < target)
        {
            auto it = d.upper_bound(now * 2);
            if(it == d.begin())
            {
                ans = -1;
                break;
            }
            it--;
            if(now >= *it)
            {
                ans = -1;
                break;
            }
            now = *it;
            ans++;
        }
        cout << ans << '\n';
    }
    return 0;
}

    D - Make 2-Regular Graph¶

    题目大意

    给你有一个 \(N(3 \le N \le 8)\) 个点 \(M(0 \le M \le \frac{N(N-1)}{2})\) 条边的简单无向图。

    你可以按任意顺序、任意次数重复以下两种操作：

    • 向 \(G\) 中添加一条无向边。
    • 从 \(G\) 中删除一条无向边。

    请你求出，将 \(G\) 变为所有顶点的度数都为 \(2\) 的简单无向图所需操作次数的最小值。

    解题思路

    最多 \(8\) 个点，也就是最多 \(28\) 条边。每条边要么有要么没有，状态数 \(2^{28}\)，可以直接暴力搜索。

    参考代码 
    #include <cstdlib>
#include <iostream>
#include <limits>
#include <vector>

using namespace std;

int main()
{
    int n, m;
    cin >> n >> m;
    vector<vector<int>> edge(n, vector<int>(n));
    while (m--)
    {
        int u, v;
        cin >> u >> v;
        u--, v--;
        edge[u][v]++;
        edge[v][u]++;
    }
    vector<int> deg(n);
    int ans = numeric_limits<int>::max();

    auto dfs = [n, &deg, &ans, &edge](auto &&self, int u, int cnt)
    {
        if (u == n)
        {
            ans = min(ans, cnt);
            return;
        }
        int s = 0;
        for (int v = u + 1; v < n; v++)
            s += edge[u][v];
        if (deg[u] == 0)
        {
            for (int v = u + 1; v < n; v++)
            {
                if (deg[v] + 1 <= 2)
                {
                    int dv = edge[u][v] ? -1 : 1;
                    deg[v]++;
                    for (int w = v + 1; w < n; w++)
                    {
                        if (deg[w] + 1 <= 2)
                        {
                            int dw = edge[u][w] ? -1 : 1;
                            deg[w]++;
                            self(self, u + 1, cnt + s + dv + dw);
                            deg[w]--;
                        }
                    }
                    deg[v]--;
                }
            }
        }
        else if (deg[u] == 1)
        {
            for (int v = u + 1; v < n; v++)
            {
                if (deg[v] + 1 <= 2)
                {
                    int dv = edge[u][v] ? -1 : 1;
                    deg[v]++;
                    self(self, u + 1, cnt + s + dv);
                    deg[v]--;
                }
            }
        }
        else if(deg[u] == 2)
            self(self, u + 1, cnt + s);
    };

    dfs(dfs, 0, 0);
    cout << ans << endl;
    return 0;
}

    E - LCM Sequence¶

    题目大意

    对于正整数 \(n\)，定义 \(A_n\) 为 \(1,2,...,n\) 的最小公倍数。

    给你两个正整数 \(L\) 和 \(R\)，其中 \((1 \le L \le R \le 10^{14})\)，且 \(0 \le R - L \le 10^{7}\) ，求出数列 \((A_L,A_{L+1},...,A_R)\) 中包含多少种不同的整数？

    解题思路

    可以发现 \(A_n\) 只在 \(n\) 是质数的幂时才会变化。也就是说，如果 \(n = p^c\)，则 \(A_n = A_{n-1} \times p\)，否则 \(A_n = A_{n-1}\)。

    于是问题等价于，求出 \(L+1\) 到 \(R\) 之间有多少个数字可以写成 \(p^c\) 的形式，设有 \(X\) 个这样的数字，则答案为 \(X+1\)。

    可以首先筛出 \(\sqrt{R}\) 以内的所有质数，利用这些质数就能筛出 \([L+1,R]\) 之间的所有 \(p^c\)，方法和埃氏筛类似，只需要注意最小值从 \(L+1\) 开始即可。不过这里要注意，在筛掉一个数字的时候，需要判断这个数字是不是 \(p^c\) 的形式，可以通过不断除以 \(p\) 来判断。然后再加上没有被筛过的数字（质数）即可。

    参考代码 
    #include <cmath>
#include <iostream>
#include <vector>

using namespace std;
using LL = long long;

vector<int> get_prime(int n)
{
    vector<bool> isp(n + 1, true);
    vector<int> prime;
    for (int i = 2; i <= n; i++)
    {
        if (isp[i])
            prime.push_back(i);
        for (auto p : prime)
        {
            if (i * (LL)p > n)
                break;
            isp[i * p] = false;
            if (i % p == 0)
                break;
        }
    }
    return prime;
}

int main()
{
    LL l, r;
    cin >> l >> r;
    vector<int> primes = get_prime(sqrt(r));
    int len = r - l + 1;
    vector<bool> tag(len);
    int ans = 1;
    for (auto p : primes)
    {
        for (LL i = (l / p + 1) * p; i <= r; i += p)
        {
            if (tag[i - l])
                continue;
            tag[i - l] = true;
            LL x = i;
            while (x % p == 0)
                x /= p;
            ans += x == 1;
        }
    }
    for (LL i = l + 1; i <= r; i++)
        ans += !tag[i - l];
    cout << ans << endl;
    return 0;
}

    F - Socks 4¶

    题目大意

    抽屉里有 \(N(1 \le N \le 3 \times 10^{5})\) 种颜色的袜子，第 \(i\) 种颜色的袜子有 \(A_i(1 \le A_i \le 3000)\) 只。

    一开始，在抽屉外还有一只颜色为 \(C\) 的袜子。接下来，你将重复以下操作，直到满足结束条件为止：

    • 从抽屉中等概率随机取出一只袜子。此时，如果抽屉外的两只袜子颜色相同，则操作结束。否则，从这两只袜子中选择一只放回抽屉。你总是选择能使今后取袜子次数的期望值最小的那只袜子放回抽屉。

    计算操作结束时取袜子的次数的期望值，答案对 \(998244353\) 取模。

    输入数据保证至少有一种颜色的袜子数量不少于 \(2\)。

    解题思路

    首先记录每种颜色的袜子数量。然后考虑放回哪只袜子的问题，显然，应该留下（抽屉中）数量较多的袜子，也就是说，假设当前有两种颜色的袜子 \(x\) 和 \(y\)，且抽屉中还有 \(X\) 只颜色为 \(x\) 的袜子，\(Y\) 只颜色为 \(y\) 的袜子，如果 \(X > Y\)，则应该留下颜色为 \(x\) 的袜子，否则留下颜色为 \(y\) 的袜子。

    定义 \(dp[x]\) 表示当颜色为 \(x\) 的袜子在抽屉外面时，取袜子次数的期望值。 假设 \(x_1\) 是数量最多的颜色，\(x_2\) 是第二多的颜色，依次类推。

    先考虑 \(dp[x_1]\)，因为 \(x_1\) 数量最多，那么无论如何都是留下颜色为 \(x_1\) 的袜子，假设还有 \(f[x_1]\) 只袜子还在抽屉中，则 \(dp[x_1] = \frac{f[x_1]-1}{S} + \frac{S - f[x_1] + 1}{S} (dp[x_1] + 1)\)，其中 \(S\) 表示所有袜子的数量（除去在抽屉外的那只），得到 \(dp[x_1] = \frac{S}{f[x_1] - 1}\)。

    然后考虑 \(dp[x_2]\)，\(x_2\) 只有在抽到 \(x_1\) 的袜子时才会留下 \(x_1\) 的袜子，则有 \(dp[x_2] = \frac{f[x_2] - 1}{S} + \frac{S - f[x_2] - f[x_1] + 1}{S} (dp[x_2] + 1) + \frac{f[x_1]}{S} (dp[x_1] + 1)\)，得到 \(dp[x_2] = \frac{S + f[x_1] dp[x_1]}{f[x_1] + f[x_2] - 1}\)。

    依次类推，可以得到： \(dp[x_i] = \frac{S + \sum\limits_{j=1}^{i-1} f[x_j] dp[x_j]}{\left(\sum\limits_{j=1}^{i} f[x_j]\right) - 1}\)。

    所以只需要从次数最多的颜色开始计算，维护 \(\sum\limits_{j=1}^{i-1} f[x_j] dp[x_j]\) 和 \(\sum\limits_{j=1}^{i} f[x_j]\) 即可。

    参考代码 
    #include <algorithm>
#include <atcoder/modint.hpp>
#include <functional>
#include <iostream>
#include <vector>

using namespace std;
using mint = atcoder::modint998244353;

int main()
{
    int n, c;
    cin >> n >> c;
    vector<int> cnt(n + 1);
    int sum = 0;
    for (int i = 1; i <= n; i++)
    {
        cin >> cnt[i];
        sum += cnt[i];
    }
    cnt[c]++;
    int target = cnt[c];
    sort(cnt.begin(), cnt.end(), greater<>());
    mint fs = 0, fds = 0;
    for (auto f : cnt)
    {
        fs += f;
        mint dp = (sum + fds) / (fs - 1);
        if (f == target)
        {
            cout << dp.val() << endl;
            break;
        }
        fds += dp * f;
    }
    return 0;
}
